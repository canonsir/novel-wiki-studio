# skills/review/

审查类技能（编辑 / 平台审核员 / 读者视角）：对已有方案、章节或整部作品做压力测试、合规审核、读者代入评估。

## 当前技能

- `grill-me/` — 不断追问的"方案压力测试"，用于重构方案、关键决策、人物弧设计前的逻辑漏洞发现。
  - 入口：`SKILL.md`
  - 典型调用场景：扩写前 / 决策定稿前（见 `AGENTS.md` 第 6 节与 `common/agents/editor-agent.md`）

## 规划中

- `platform-reviewer`（番茄 + 红果 + 国家红线综合体检）
- `continuity-auditor`（时间线 / 伤势 / 物件连续性）
- `reader-emulator`（代入主要用户画像评估爽点兑现、钩子效率）

## 加入新 skill 的最低要求

同 `writing/README.md`，且必须声明：
1. 评审对象（章节 / 方案 / 整书）。
2. 评审输出格式（打分表 / 问题清单 / 修复建议）。
3. 与 `common/constraints/` 下 checklist 的对应关系。
