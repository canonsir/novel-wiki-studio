# 来源与版权策略

## 来源类型

- `primary`：作者原稿、用户口述、正式决定、原创设定。
- `reference`：研究资料、历史资料、公开网页、图片、地图。
- `inspiration`：只用于抽象启发的作品，不得复制表达、人物组合或独特桥段。
- `generated`：AI 提案或生成文本，必须可追溯到任务与日期。

## 原则

1. 原始来源只读，保存原文件名、导入时间、来源 URL、许可/版权状态。
2. 待重构小说必须是用户自有作品或已获覆盖改编、发布用途的合法授权；权利状态未确认时不得进入面向发布的正文生产。
3. 原创重构的目标是形成独立的主题表达、人物选择、因果结构、场景组织和语言表达，不以复刻来源文本为目标。
4. 不将他人小说整篇放入仓库后改写或“洗稿”，也不以同义词替换、调序、拼接或规避查重作为原创方法。
5. 不要求模仿在世作者的可识别独特文风；改为抽象特征组合，如“短句、冷峻、克制、环境先于情绪”。
6. 引用事实资料时保留链接和访问日期；引用表达时控制必要长度并注明出处。
7. 使用真实人物、公司、案件或地点时，区分事实与虚构，审查隐私、名誉和误导风险。
8. 图片、字体、音乐和视频参考必须记录授权条件；“网上找到”不等于可商用。

## 文件命名建议

`SRC-YYYYMMDD-序号-简短标题.ext`，并在同目录 `README.md` 或来源清单登记来源、许可和用途。
