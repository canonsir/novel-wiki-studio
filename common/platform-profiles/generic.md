# 通用发布前检查

- 先执行 `common/safety-compliance.md`。
- 获取目标平台最新官方用户协议、内容规范、作者规则、版权规则和 AI 内容要求。
- 检查对象包括标题、简介、封面、正文、作者说、评论互动、个人主页和外链。
- 记录核验日期、URL、频道、作品版本和审核人。
- 不用竞品作品是否存在来判断规则；存量作品不代表当前允许。
- 如果平台规则与公共规则冲突，采用更严格者；如涉及法律疑问，暂停发布并寻求专业意见。
