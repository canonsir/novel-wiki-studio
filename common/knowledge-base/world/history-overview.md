# 世界史分期（跨境线必读）

## 定位

小说跨境线不能把"外国"写成模糊符号。本页提供简洁时间轴 + 关键节点，方便查用。

## 一、西方主线（供欧美线）

### 古代

- **古希腊**（前 8-前 4 世纪）：城邦文明、哲学诞生（苏格拉底 / 柏拉图 / 亚里士多德）、民主起源。
- **罗马共和 / 帝国**（前 509-公元 476 西罗马灭亡）：法律、工程、拉丁语。
- **拜占庭**（330-1453）：东罗马，君士坦丁堡（今伊斯坦布尔）。

### 中世纪（约 500-1500）

- 封建制、骑士、教皇与国王对立。
- 十字军东征（1096-1291）。
- 黑死病（1347-1351 杀死欧洲 1/3 人口）。
- 文艺复兴（14-17 世纪，起于意大利）。

### 近代

- **大航海**（15-16 世纪）：葡萄牙 / 西班牙 / 荷兰 / 英国殖民扩张。
- **宗教改革**（1517 马丁·路德）：新教诞生。
- **启蒙运动**（17-18 世纪）：伏尔泰 / 卢梭 / 康德。
- **工业革命**（18-19 世纪）：英国起步。
- **法国大革命**（1789）、**美国独立**（1776）。
- **拿破仑**（1799-1815 执政）。

### 现代

- **一战**（1914-1918）。
- **俄国革命**（1917）：苏联建立。
- **大萧条**（1929）。
- **二战**（1939-1945）：欧洲战场 + 太平洋战场。
- **冷战**（1945-1991）：美苏对抗。
- **苏联解体**（1991）。
- **9·11**（2001）：反恐时代。
- **全球金融危机**（2008）。

## 二、东亚主线

### 日本

- **古坟→奈良→平安**（4-12 世纪）：天皇朝廷。
- **镰仓→室町→战国**（12-16 世纪）：武士时代、幕府。
- **江户**（1603-1868）：德川家康起，锁国。
- **明治维新**（1868-）：脱亚入欧、工业化、军国化。
- **二战**（1937 侵华 / 1941 珍珠港 / 1945 投降）。
- **战后**（1945-）：美军托管 → 经济奇迹 → 失落三十年。

### 韩国

- **三国时代**（高句丽 / 新罗 / 百济）。
- **高丽**（918-1392）。
- **朝鲜王朝**（1392-1897）：李氏朝鲜。
- **日据**（1910-1945）。
- **南北分裂**（1948-）：朝鲜战争（1950-1953）。

### 东南亚

- **安南 / 占城 / 真腊**（古越南 / 柬埔寨）。
- **暹罗 / 兰纳 / 阿瑜陀耶**（泰国）。
- **缅甸 / 蒲甘 / 东吁 / 贡榜王朝**。
- **南洋华人**（宋以后至清，大量下南洋）。

## 三、中东主线

### 古代

- **美索不达米亚**：苏美尔 / 巴比伦 / 亚述。
- **古埃及**：法老 / 金字塔 / 象形文字。
- **波斯帝国**（阿契美尼德 / 萨珊）。

### 伊斯兰时代

- **先知时代**（570-632）：穆罕默德。
- **正统哈里发**（632-661）。
- **倭马亚哈里发**（661-750）。
- **阿拔斯哈里发**（750-1258）：巴格达黄金时代。
- **奥斯曼帝国**（1299-1922）：横跨欧亚非。

### 现代

- **一战后奥斯曼解体** → 英法委任统治。
- **1948 以色列建国** → 中东四次战争。
- **石油经济** → 海湾合作委员会。
- **伊朗伊斯兰革命**（1979）。
- **9·11 后反恐战争**（阿富汗 / 伊拉克）。
- **阿拉伯之春**（2010-）。

## 四、南亚

- **哈拉帕**（印度河文明，前 2600-前 1900）。
- **吠陀时代**（前 1500-前 500）。
- **孔雀王朝**（阿育王，前 322-前 185）。
- **莫卧儿帝国**（1526-1857）：伊斯兰统治印度。
- **英属印度**（1858-1947）。
- **印巴分治**（1947）：印度 / 巴基斯坦 / 后来孟加拉。

## 五、美洲

### 原住民

- **玛雅 / 阿兹特克 / 印加**：中南美古文明。
- **北美印第安各部**：殖民前。

### 殖民到建国

- **哥伦布**（1492）。
- **北美十三殖民地** → **美国独立**（1776）。
- **南美独立**（19 世纪）：玻利瓦尔 / 圣马丁。
- **美国南北战争**（1861-1865）。

### 现代

- **二战后超级大国**。
- **冷战代理战争**（朝鲜 / 越南）。
- **古巴革命**（1959）。
- **9·11 后反恐**。

## 六、非洲

- **古埃及** / **迦太基** / **撒哈拉以南**。
- **大航海时期的奴隶贸易**。
- **殖民瓜分**（19 世纪末柏林会议）。
- **二战后独立潮**（1950s-1970s）。
- **种族隔离**（南非，1948-1994）。
- **卢旺达大屠杀**（1994）。

## 跨境线常用背景

| 小说场景 | 时代底色 |
|---|---|
| 东瀛黑帮 | 战后 → 山口组兴衰 |
| 高丽财阀 | 朴正熙 → 全斗焕 → 现代财阀 |
| 暹罗（泰）金三角 | 冷战代理 + 毒品经济 |
| 骠国（缅）跨境 | 军政府 + 果敢 + 少数民族 |
| 罗刹远东华人 | 苏联解体 + 哈尔滨 → 符拉迪沃斯托克 |
| 花旗唐人街 | 排华法案 + 洪门海外 + 福建移民 |

## 常见误用

| 误用 | 正确 |
|---|---|
| 把二战日本 = 军国主义全体 | 日本内部有反战派 / 平民受害 |
| 把苏联 = 共产主义唯一面孔 | 苏联内部斯大林 / 赫鲁晓夫 / 戈尔巴乔夫差异大 |
| 把中东全部 = 阿拉伯 | 伊朗 / 土耳其 / 以色列不是阿拉伯 |
| 把印度 = 落后 | 印度有悠久哲学 / 科技 / 文化传统 |
| 把非洲 = 一个国家 | 非洲 54 个国家，差异极大 |
