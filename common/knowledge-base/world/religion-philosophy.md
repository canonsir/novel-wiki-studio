# 世界宗教与哲学（跨文化底盘）

## 定位

当小说涉及跨境线（南洋 / 西洋 / 中东 / 东瀛）时，必须对其他主要宗教和哲学传统有常识级准确理解。本页提供可引用的事实清单与禁区。

## 一、西方三大一神教

### 1. 犹太教 (Judaism)

- **核心**：唯一真神（YHWH）、十诫、安息日、割礼。
- **经典**：希伯来圣经（旧约）、塔木德。
- **节日**：逾越节、赎罪日、光明节。
- **流派**：正统派、改革派、保守派。
- **写作禁区**：涉犹反犹、犹太阴谋论、集中营戏谑化。

### 2. 基督教 (Christianity)

- **核心**：三位一体（圣父圣子圣灵）、耶稣基督救赎、原罪、复活。
- **经典**：旧约 + 新约。
- **节日**：圣诞、复活节、圣灵降临节。
- **流派**：
  - **天主教**（罗马教廷）：教皇、主教、神父、修女；弥撒；告解。
  - **新教**：路德宗 / 加尔文宗 / 圣公会 / 浸信会 / 福音派等。
  - **东正教**：俄 / 希腊 / 塞尔维亚 / 东欧。
- **中国天主教**：中国天主教爱国会，政治敏感，不涉罗马教廷管辖讨论。
- **写作禁区**：亵渎十字架 / 耶稣戏谑 / 真实教皇诽谤。

### 3. 伊斯兰教 (Islam)

- **核心**：真主独一、穆罕默德是先知、五功（信、拜、斋、课、朝）。
- **经典**：古兰经、圣训。
- **流派**：
  - **逊尼派**：全球多数（85%+）。
  - **什叶派**：伊朗 / 伊拉克 / 黎巴嫩真主党。
  - **苏非主义**：神秘主义。
- **节日**：开斋节、宰牲节、斋月。
- **习俗**：清真饮食（禁猪 / 禁酒）、礼拜（一日五次）、朝觐（有生之年去麦加）。
- **中国穆斯林**：主要是回族、维吾尔族、哈萨克族等 10 个民族。
- **写作红线（极高）**：
  - 禁止亵渎穆罕默德 / 古兰经 / 清真。
  - 禁止把恐怖主义与伊斯兰教等同。
  - 中国境内民族宗教政策极敏感，涉具体地区（新疆 / 宁夏）必须虚构化。

## 二、印度传统

### 1. 印度教 (Hinduism)

- **核心**：梵我合一、轮回、业、解脱（Moksha）。
- **三大主神**：梵天（创造）、毗湿奴（维护）、湿婆（毁灭）。
- **经典**：吠陀、奥义书、薄伽梵歌、罗摩衍那、摩诃婆罗多。
- **种姓**：婆罗门 / 刹帝利 / 吠舍 / 首陀罗 + 不可接触的"贱民"（印度宪法已废除但现实仍存在）。
- **瑜伽**：源自印度教的身心训练。
- **写作禁区**：种姓制度戏谑化、恒河病菌嘲笑。

### 2. 耆那教 (Jainism)

- **核心**：严格非暴力（Ahimsa）、不杀生、素食。
- 影响圣雄甘地的"非暴力不合作"。

### 3. 锡克教 (Sikhism)

- **创始**：古鲁那纳克（16 世纪）。
- **五大标志**："5K"：Kesh（不剪发）、Kangha（木梳）、Kara（铁手镯）、Kachera（短裤）、Kirpan（短剑）。
- **性格**：锡克人以战斗民族著称；加拿大 / 英国有大量锡克裔。

## 三、东亚传统（中国外延）

### 1. 日本神道教 (Shinto)

- **核心**：万物有灵（八百万神）、祖先崇拜、天皇神裔。
- **神社**：鸟居、神主、巫女、御守、绘马。
- **节日**：新年、七五三、祇园祭。
- **二战后**：政教分离，神道变文化传统。

### 2. 日本佛教

- 与中国佛教同源但本土化：
  - **禅宗**：曹洞、临济。
  - **净土**：净土宗、净土真宗。
  - **日莲宗**：日莲、创价学会（现代影响大）。
  - **真言宗**：空海、密宗。
- **武士道**：禅 + 儒 + 神道的合流，代表作《叶隐》《武士道》新渡户稻造。

### 3. 韩国儒教 / 基督教

- 韩国儒家传统深厚（朝鲜王朝独尊儒术）。
- 近代天主教 / 新教传入强势，现代韩国 30% 基督徒。

## 四、其他

### 1. 犹太教以外的中东古代

- 琐罗亚斯德教（拜火教）：伊朗古代国教。
- 诺斯替教：早期基督教异端。

### 2. 非洲 / 美洲原住民

- **伏都教** (Voodoo)：海地 / 西非，不等于黑魔法。
- **萨满教** (Shamanism)：中亚 / 西伯利亚 / 东北亚原住民。

### 3. 新兴宗教

- 摩门教 / 耶和华见证人 / 山达基 / 奥修运动等（写作谨慎，有宗教争议）。

## 跨宗教常见误用

| 误用 | 正确 |
|---|---|
| 把穆斯林 = 恐怖分子 | 严重错误；穆斯林世界 85% 以上是普通信徒 |
| 把犹太人 = 吝啬 | 中世纪偏见，不得用 |
| 认为"天主教 vs 基督教是两个宗教" | 基督教是大类，天主教是其中一支 |
| 让神道教满街鬼神作祟 | 神道以祭祀为主，不是鬼神满街 |
| 伊斯兰教只有阿拉伯人 | 全球伊斯兰 60% 以上在亚洲（印尼 / 巴 / 孟 / 中亚） |

## 小说应用建议

### 跨境线常用场景

- **南洋**：华人 + 伊斯兰 + 印度教融合（马来 / 新 / 印尼）。
- **中东**：伊斯兰为主，有基督徒 / 犹太人小众。
- **欧洲**：天主教 / 新教 / 东正教。
- **俄罗斯**：东正教主流 + 伊斯兰 / 佛教少数民族。
- **北美**：新教主流 + 天主教 / 犹太教 / 其他。

### 可用的"宗教底色"情节

- 不同宗教信徒结盟 / 冲突。
- 宗教圣物 / 神职人员的保密线。
- 跨宗教恋情 / 婚姻（强戏剧性）。
- 宗教节日为背景的事件。

### 禁区

- 不把任何现有宗教写成"邪教"。
- 不编造宗教真实人物的黑料。
- 不描写具体宗教仪轨到可亵渎程度。
