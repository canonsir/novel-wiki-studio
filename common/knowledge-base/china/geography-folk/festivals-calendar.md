# 节气 / 农历 / 节日民俗

## 定位

小说要让时间"有真实感"，节气 / 节日 / 民俗是最有效的锚点。春节团圆、清明扫墓、七夕告白、中元烧纸——每个节日都是情节的现成支点。

## 农历与公历换算要点

- 农历一年 354 天，比公历少 11 天。
- 每 19 年加 7 个闰月。
- 春节在公历 1 月 21 日 - 2 月 20 日之间浮动。

## 传统节日（情节高频）

### 春节 / 新年

- **腊八**（腊月初八）：喝腊八粥。
- **祭灶 / 小年**（腊月二十三 / 二十四）：灶王爷上天汇报。
- **除夕**（腊月三十）：年夜饭 / 守岁 / 放鞭炮（现代多数禁放）。
- **春节**（正月初一）：拜年 / 红包 / 新衣。
- **元宵**（正月十五）：汤圆 / 猜灯谜 / 看灯。

**情节用途**：家族团聚 / 感情表白 / 命运转折。

### 清明

- 公历 4 月 4-6 日。
- 扫墓 / 踏青 / 吃青团。
- **情节用途**：旧账浮出 / 怀念 / 父辈伏笔。

### 端午

- 农历五月初五。
- 吃粽子 / 赛龙舟 / 挂艾草 / 戴香囊。
- 纪念屈原。
- **情节用途**：竞争 / 水乡剧情。

### 七夕

- 农历七月初七。
- 牛郎织女鹊桥会。
- 中国情人节（都市文最常用）。
- **情节用途**：告白 / 分手 / 相聚。

### 中元 / 鬼节

- 农历七月十五。
- 烧纸钱、放河灯、祭祖、不出远门、不走夜路。
- **情节用途**：悬疑 / 怪力乱神 / 旧日恩怨。

### 中秋

- 农历八月十五。
- 月饼 / 赏月 / 团圆。
- **情节用途**：异地思念 / 家族团聚 / 兄弟团圆。

### 重阳

- 农历九月初九。
- 登高 / 敬老 / 插茱萸。
- **情节用途**：敬老 / 怀旧 / 身体力行。

### 冬至

- 公历 12 月 21-23 日。
- 吃饺子（北方）/ 汤圆（南方）/ 羊肉。
- **情节用途**：年终清算 / 大事将至。

### 腊八

- 腊月初八。
- 喝腊八粥。
- **情节用途**：年末准备期。

## 民俗禁忌（可做情节）

### 正月

- 初一不扫地（扫走财气）、不洗头（洗走福气）。
- 初五破五，可做任何事。
- 初七人日，吃面条。

### 其他

- 腊月二十三 / 二十四不睡觉。
- 鬼节不走夜路、不出远门。
- 结婚不选 "八四" "七七" 等不吉数字。
- 送礼不送钟（送终）、不送伞（散）、不送鞋（邪）。
- 住酒店 "敲门三声" 的说法。

## 占卜 / 风水 / 命理（专见下页，这里略提）

- 农历与生肖、生辰八字、黄历（吉凶 / 忌 / 宜）。
- **写作建议**：可引用增加氛围，不作为剧情裁决。

## 常见误用

| 误用 | 正确 |
|---|---|
| 把节气混同节日 | 节气是气候，节日是文化习俗 |
| 春节都在"过年期" | 春节正月初一到正月十五不同节点 |
| 每个民族节日都一样 | 傣族泼水和蒙古那达慕完全不同 |
| 鬼节都写"闹鬼" | 中元节本质是祭祖，不是恐怖片 |

## 小说应用建议

- **情节节奏锚点**：每一卷至少用一两个节日 / 节气作时间锚。
- **文化厚度**：主角家族习俗 / 师父辈的老传统。
- **跨文化冲突**：主角和外国女朋友过春节 / 圣诞节的差异。
- **节日悬疑**：鬼节 / 清明做悬疑题材的现成背景。
