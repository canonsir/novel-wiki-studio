# 茶 / 酒 / 饮食文化

## 定位

饮食是中国文化最直接的身份符号。小说中"喝什么茶 / 什么酒 / 吃什么菜"直接决定人物阶层、地域、品位。写错会露馅。

## 一、茶（文人 / 老派 / 商务）

### 六大茶类

| 类别 | 发酵度 | 代表 | 适用场景 |
|---|---|---|---|
| 绿茶 | 不发酵 | 龙井 / 碧螺春 / 毛峰 / 竹叶青 | 清雅 / 日常 |
| 白茶 | 微发酵 | 白毫银针 / 白牡丹 / 寿眉 | 文艺 / 养生 |
| 黄茶 | 微发酵 | 君山银针 / 蒙顶黄芽 | 稀有 / 高雅 |
| 乌龙 | 半发酵 | 铁观音 / 大红袍 / 凤凰单枞 | 商务 / 老派 |
| 红茶 | 全发酵 | 金骏眉 / 正山小种 / 滇红 | 热情 / 女性 |
| 黑茶 | 后发酵 | 普洱 / 六堡 / 安化黑茶 | 收藏 / 老派 |

### 顶级名茶（显富 / 显品）

- **西湖龙井**（明前狮峰）：高端绿茶，万元一斤。
- **金骏眉**：顶级红茶，万元级。
- **大红袍母树**：极稀少（只有六棵），市场炒作到百万一斤。
- **铁观音**（魏荫 / 王说原种）：铁观音顶级。
- **普洱老茶**（50-70 年代印级 / 号级）：收藏级，百万元一饼。
- **白毫银针**（福鼎顶级）：极品白茶。

### 泡茶器具

- **紫砂壶**（宜兴）：顶级泥料 / 老工匠作品，万元起。
- **盖碗**（景德镇青花 / 粉彩）。
- **玻璃壶**：观赏绿茶 / 白茶。
- **铁壶 / 银壶**：日式 / 现代。

### 茶道礼节（商务 / 江湖都用）

- **主宾位**：客人靠主，陪宾错开。
- **分茶**：先客后主，先长后幼。
- **叩指礼**：茶被倒时轻叩桌面三下致谢（典故：乾隆下江南 "君臣叩首")。
- **七分满**：茶要留三分空，取"茶满欺人"的反义。
- **换茶**：三道水后更换茶叶。

### 场景应用

- **老爷子 / 师父茶盘**：常年摆铁观音 / 普洱 / 大红袍。
- **商务洽谈**：铁观音 / 金骏眉。
- **江湖拜会**：主家泡茶讲究显身份。
- **文人雅集**：龙井 / 碧螺春。

## 二、白酒（男频核心）

### 中国名酒十二家

| 酒 | 产地 | 定位 |
|---|---|---|
| 茅台 | 贵州仁怀 | 顶级 / 国宴 |
| 五粮液 | 四川宜宾 | 顶级 / 商务 |
| 泸州老窖（国窖 1573）| 四川泸州 | 顶级 / 老派 |
| 剑南春 | 四川绵竹 | 二线顶级 |
| 洋河（海之蓝 / 梦之蓝）| 江苏宿迁 | 江浙首选 |
| 郎酒（青花郎 / 红花郎）| 四川古蔺 | 商务 |
| 汾酒 | 山西汾阳 | 清香型顶级 |
| 古井贡 | 安徽亳州 | 中原 |
| 西凤 | 陕西凤翔 | 关中 |
| 水井坊 | 四川 | 高端 |
| 董酒 | 贵州遵义 | 药香型 |
| 全兴大曲 | 四川成都 | 川派老牌 |

### 香型

- **酱香**：茅台、郎酒青花郎；复杂厚重。
- **浓香**：五粮液、泸州老窖、剑南春；最大流派。
- **清香**：汾酒；清爽直接。
- **米香**：桂林三花酒。
- **凤香**：西凤。
- **药香**：董酒。
- **豉香**：广东玉冰烧。

### 顶级 / 稀有

- **茅台飞天 53 度**：旗舰款。
- **茅台 15 / 30 / 50 年陈酿**：拍卖级。
- **茅台生肖酒**：收藏炒作。
- **五粮液经典 / 30 年 / 50 年**。
- **汉帝茅台 / 丝路茅台**：礼品级。
- **国窖 1573 典藏 / 30 年**。

### 价格参考（新品）

- 普通飞天茅台：1500-3000 元 / 瓶。
- 普通五粮液：900-1500 元 / 瓶。
- 国窖 1573：800-1500 元 / 瓶。
- 老酒收藏：1980s 茅台一瓶可拍卖到数十万。

### 饭桌规矩

- **敬酒顺序**：主人先敬最大辈分，然后依次。
- **回敬**：单杯回敬，不能一次敬两人。
- **挡酒**：陪客替主家挡酒。
- **酒品**：量力而行，装醉 / 装死 都是江湖技巧。
- **"干杯"**：对等饮尽；对方不干你不干要有理由。

### 场景应用

- **江湖拜会**：茅台 / 五粮液开场。
- **商务宴请**：茅台 / 五粮液 + 一瓶红酒。
- **私人聚会**：剑南春 / 洋河。
- **老派世家**：陈年茅台 / 老汾酒。

## 三、洋酒 / 其他（都市 / 跨境）

### 威士忌

- **苏格兰**：麦卡伦 / 格兰菲迪 / 格兰威特 / 云顶 / 波摩。
- **日本**：山崎 / 响 / 白州（极度炒作）。
- **美国**：杰克丹尼 / 美格 / 水牛足迹（Bourbon）。
- **爱尔兰**：尊美醇 / 布什米尔斯。

### 白兰地 / 干邑

- **路易十三** Louis XIII：顶级干邑，一瓶 2-5 万。
- **人头马 XO** / **轩尼诗 XO** / **马爹利 XO**：商务常见。
- **拿破仑**：中端。

### 葡萄酒

- **波尔多五大酒庄**：拉菲 / 玛歌 / 拉图 / 木桐 / 奥比昂。
- **勃艮第**：罗曼尼康帝（DRC），顶级中的顶级，一瓶 20-100 万。
- **意大利**：萨西凯亚 / 嘉雅 / 福图思 / 奥纳亚。
- **新世界**：澳 / 美 / 智利 / 阿根廷。

### 香槟

- **顶级**：唐培里侬（Dom Pérignon）、库克（Krug）、沙龙（Salon）。
- **常见**：酩悦 / 凯歌 / 保罗杰 / 玛姆。

### 啤酒

- 国产：青岛 / 燕京 / 雪花 / 哈尔滨。
- 进口：喜力 / 嘉士伯 / 百威 / 科罗娜。
- 精酿：京 A / 高大师 / 熊猫精酿 / 跳东湖。

## 四、中国八大菜系

### 1. 鲁菜（山东）

- 特点：咸香醇厚、重火候。
- 代表：九转大肠、糖醋鲤鱼、葱烧海参、糟溜鱼片。
- **人物挂法**：北派武馆师父 / 山东商帮。

### 2. 川菜（四川）

- 特点：麻辣鲜香、味型复杂（24 味型）。
- 代表：麻婆豆腐、宫保鸡丁、水煮鱼、回锅肉、鱼香肉丝、担担面。
- 火锅：麻辣 / 清汤 / 冒菜 / 串串。
- **人物挂法**：江湖气 / 川渝市井。

### 3. 粤菜（广东）

- 特点：清淡精细、本味为先、食材昂贵。
- 代表：白切鸡、烧鹅、乳猪、点心（虾饺 / 烧卖 / 肠粉）。
- 煲汤文化：老火汤讲究两小时以上。
- **人物挂法**：岭南商人 / 港澳背景。

### 4. 苏菜（江苏）

- 特点：清爽甘甜、刀工精细。
- 代表：松鼠鳜鱼、水晶肴肉、盐水鸭、金陵烧鸭。
- **人物挂法**：江南文人 / 老派世家。

### 5. 浙菜（浙江）

- 特点：清鲜脆嫩。
- 代表：西湖醋鱼、龙井虾仁、东坡肉、宋嫂鱼羹。
- **人物挂法**：江南雅士 / 文艺青年。

### 6. 闽菜（福建）

- 特点：山海鲜兼得。
- 代表：佛跳墙、海蛎煎、荔枝肉、沙茶面。
- **人物挂法**：海商 / 华侨。

### 7. 徽菜（安徽）

- 特点：重火工、重油盐。
- 代表：臭鳜鱼、毛豆腐、徽州一品锅。
- **人物挂法**：徽商 / 内陆世家。

### 8. 湘菜（湖南）

- 特点：辣酸香。
- 代表：剁椒鱼头、辣椒炒肉、腊味合蒸、口味虾。
- **人物挂法**：湘军遗韵 / 性格火辣。

## 五、地方特色

- **北京菜**：烤鸭、涮羊肉、炸酱面。
- **天津菜**：狗不理包子、煎饼果子、十八街麻花。
- **西北菜**：手抓羊肉、羊肉泡馍、兰州拉面、烤馕、新疆大盘鸡。
- **东北菜**：锅包肉、杀猪菜、酸菜炖粉条、小鸡炖蘑菇。
- **云南**：过桥米线、普洱茶、鲜花饼、汽锅鸡。
- **贵州**：酸汤鱼、丝娃娃、肠旺面。
- **西藏**：酥油茶、糌粑、牦牛肉（谨慎民族处理）。

## 六、常见饭桌场景

### 商务宴请

- 中式包间 / 落地窗 / 服务员专配。
- **座次**：主位（面门）→ 副主位（背门）→ 陪客两侧。
- **菜品**：冷盘 → 热菜 → 大菜（鲍参翅肚）→ 主食 → 汤 → 水果。
- **酒**：茅台 / 五粮液 + 一瓶红酒 + 冰饮备用。
- **结账**：主家结，客人抢单是客套。

### 江湖饭局

- 包间 / 老店小馆。
- **规矩**：大哥坐主位，兄弟按辈分围坐。
- **菜品**：家常硬菜（红烧肉 / 排骨 / 鱼 / 大虾）+ 下酒菜。
- **酒**：白酒为主，不喝啤酒（除非年轻帮众）。
- **氛围**：豪爽但有礼节，不吵不闹。

### 家宴

- 家中厨房或私人会所。
- 母亲 / 嫂子 / 妻子做菜。
- 气氛比外场轻松。

## 七、常见误用

| 误用 | 正确 |
|---|---|
| 让所有人都喝茅台 | 不同场景不同酒；年轻一代多数喝红酒 / 洋酒 |
| 川菜 = 麻辣 | 川菜 24 味型，麻辣只是一部分 |
| 粤菜 = 清淡无味 | 粤菜追求"本味"而非无味 |
| 让"老爷子"喝冰啤酒 | 老派多喝茶 / 白酒，不喝冰啤 |
| 顶级红酒随便开 | 顶级酒要醒酒 / 温度 / 杯子都讲究 |
| 把普洱写成"陈越好" | 普洱有新茶 / 老茶，不是越老越好 |
| 让女性全部不懂酒 | 现代女性懂酒的大量存在 |

## 八、小说应用建议

- **用茶 / 酒区分阶层**：主角初期 → 街头饭馆啤酒；主角成熟 → 商务茅台 / 顶级红酒；主角终局 → 老茶 / 老酒收藏家。
- **用饭桌推进关系**：第一次家宴 / 第一次拜会老爷子 / 结拜兄弟喝下的那杯酒。
- **用菜系点明地域**：主角去魔都吃本帮红烧肉；去雾都吃江湖火锅。
- **用酒品看人**：装醉 / 真醉 / 挡酒 / 替酒都是戏剧性手段。
