# 中国地理 / 方言 / 民俗（分区速查）

## 定位

小说要让角色在真实空间里行走时，必须准确抓住每个地域的**地理 / 方言 / 民俗 / 性格刻板**（谨慎使用刻板印象）。本页给常用场景提供速查，与 `real-to-fictional-map.md` 搭配使用。

## 东北（辽吉黑 → 盛京 / 吉林 / 冰城）

- **地理**：平原 + 林区 + 边境；黑土地；冬季 -20°C 以下。
- **方言**：东北话（唠嗑、咋地、整个事儿、嘎嘎）。
- **民俗**：炕 / 杀年猪 / 二人转 / 大澡堂文化。
- **性格刻板**（谨慎）：豪爽、能喝、黑色幽默。
- **江湖底色**：
  - 清末闯关东移民 → 民国张作霖奉系 → 建国重工业 → 下岗潮 → 1990s 黑帮兴起。
  - 著名案例：铁岭 / 哈尔滨 / 长春的早期黑帮。
- **饮食**：锅包肉 / 杀猪菜 / 粘豆包 / 冻梨 / 得莫利炖鱼。

## 华北（京津冀 + 鲁晋 → 帝都 / 津门 / 泉城 / 并州）

- **地理**：华北平原 + 太行 + 燕山；四季分明。
- **方言**：
  - 北京话（儿化音、"甭 / 您 / 得")。
  - 天津话（曲艺腔、相声底）。
  - 山东话（憨厚、"俺 / 哈 / 咋")。
  - 山西话（音调独特）。
- **民俗**：相声 / 京剧 / 曲艺 / 老字号。
- **江湖底色**：
  - 清末八旗 / 民国北洋 / 建国首都 / 改开权力中心。
  - 山东鲁菜 / 青帮齐鲁堂口。
- **性格刻板**：京城爷气（礼节）、天津卫幽默、山东直率。

## 江浙沪（魔都 / 临安 / 姑苏 / 甬城）

- **地理**：长江下游 + 太湖 + 东海；温带湿润。
- **方言**：
  - 上海话（沪语，侬 / 阿拉）。
  - 苏州话（吴侬软语）。
  - 宁波话（商帮口音）。
- **民俗**：茶馆 / 评弹 / 园林 / 水乡。
- **江湖底色**：
  - 清末宁波帮 / 青帮三大亨 / 江浙财阀 / 现代金融中心。
- **性格刻板**：精明、懂规矩、商业头脑。
- **饮食**：本帮菜 / 杭帮菜 / 江南甜咸。

## 华南（珠三角 → 南都 / 鹏城 / 鹭岛 / 榕城 / 港岛 / 濠江）

- **地理**：珠江流域 + 福建丘陵；亚热带。
- **方言**：
  - 广东话（粤语）。
  - 潮汕话。
  - 客家话。
  - 闽南话 / 闽东话。
- **民俗**：早茶 / 功夫茶 / 龙船 / 妈祖信仰。
- **江湖底色**：
  - 下南洋华人 / 洪门海外 / 改开最早 / 走私 / 跨境贸易。
- **性格刻板**：务实、低调、重商、重宗族。
- **饮食**：粤菜 / 潮菜 / 闽菜 / 早茶 / 糖水。

## 川渝（蓉城 / 雾都）

- **地理**：盆地 + 山地；湿润多雾。
- **方言**：
  - 四川话（成都 / 乐山）。
  - 重庆话（码头腔，带江湖气）。
- **民俗**：茶馆 / 麻将 / 川剧 / 变脸 / 火锅。
- **江湖底色**：
  - 清末袍哥会 / 民国川军 / 建国西南大区 / 改开休闲产业。
- **性格刻板**：乐观、麻辣、江湖气、不服输。
- **饮食**：川菜 / 麻辣 / 小面 / 卤味 / 兔头。

## 两湖（江城 / 湘都）

- **地理**：长江中游 + 洞庭 + 鄱阳。
- **方言**：武汉话 / 长沙话。
- **民俗**：九省通衢 / 湘军遗韵 / 戏剧文化。
- **江湖底色**：清末湘军 / 曾国藩 / 洋务运动工业。
- **性格刻板**：火辣（湘）、精明（鄂）。
- **饮食**：鄂菜 / 湘菜（辣中带酸）。

## 关中（长安 / 咸阳）

- **地理**：渭河平原 + 秦岭 + 黄土高原。
- **方言**：关中话（倒装句、"冷娃")。
- **民俗**：秦腔 / 窑洞 / 面食文化。
- **江湖底色**：古都 / 军事要地 / 兵马俑考古。
- **饮食**：面食 / 肉夹馍 / 凉皮 / 泡馍。

## 东南与边境

- **云南（春城）**：少数民族多、金三角接壤、普洱茶。
- **贵州**：山地、酒文化（茅台）、少数民族。
- **广西**：壮族 / 瑶族 / 跨境线。

## 塞北与西部（**慎用，必须虚构化**）

### 西陲（新疆）

- 真实不写具体民族，统称"西部商队 / 边郡货商"。
- 可提及：葡萄 / 哈密瓜 / 丝绸之路底色、戈壁 / 天山 / 塔克拉玛干。
- **禁区**：具体民族冲突、恐怖事件、宗教。

### 雪域（西藏）

- 真实不写具体寺院 / 活佛。
- 可提及：高原反应、藏香、经幡、牦牛。
- **禁区**：政治、宗教、具体寺庙系统。

### 北漠（内蒙）

- 可提及：草原 / 蒙古包 / 奶茶 / 那达慕。
- 相对敏感度低，但避免写蒙汉冲突。

## 刻板印象使用的红线

- **严禁**用刻板印象做"地域黑"（例：XX 省人都是骗子）。
- **可以**用正面刻板丰富角色（东北豪爽、广东精明）。
- **应避免**：少数民族被标签化（新疆人 / 维族 / 藏族都不能挂犯罪 / 落后标签）。

## 常见误用

| 误用 | 正确 |
|---|---|
| 北京人全是"胡同大爷" | 北京混合多元 |
| 上海人全是"精明鬼" | 分代际 / 分区域 |
| 东北人全部喝大酒 | 东北年轻一代也戒酒 |
| 新疆人全部载歌载舞 | 严重错误，必须避免 |
| 把方言写成"听不懂的话" | 可提特点，不要戏谑 |
