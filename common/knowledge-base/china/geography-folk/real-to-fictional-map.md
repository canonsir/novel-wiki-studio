# 真实地名 → 虚构地名映射（全局硬约束）

本页是所有小说的**顶层地名硬约束**：真实中国城市、省份、重要地景出现在正文时，一律使用此映射的虚构代号。
Reviewer agent 发现未按本表虚构的地名，视为合规风险 L2，必须退回修改。

## 使用规则

1. 首次出现一律用虚构名；在角色对白中可偶尔用"北边"、"南方"等模糊词补色。
2. 虚构名作为小说内的"真实"存在，二次出现保持拼写一致（见 `continuity-agent`）。
3. 跨国 / 真实国家首次出现在正文需评估：
   - 必要时虚构化为"东瀛 / 高丽 / 暹罗 / 不列颠 / 法兰西"等文化通俗称；
   - 不必要时可直接使用但不与现代真实国政直接挂钩。
4. 关键地景（长城 / 黄河 / 珠峰）可以保留原名但避免具体精确位置写作。

## 三级：少数民族地区（谨慎处理）

**红线**：涉及新疆、西藏、内蒙等少数民族地区，一律虚构化到"西陲"、"雪域"、"北漠"级别的通称。
禁止把真实民族名与反派、犯罪挂钩；禁止把真实宗教仪轨写入猎奇场景。

| 真实区域 | 虚构 | 使用约束 |
|---|---|---|
| 新疆 | 西陲 | 不涉具体民族，不与恐怖挂钩 |
| 西藏 | 雪域 | 不涉具体寺院、不嘲讽宗教 |
| 内蒙 | 北漠 | 可写草原风土、不涉民族冲突 |
| 云南边境 | 边郡 | 金三角线路可借用但不指实 |
| 青海 | 高原 | 自然风景可引、不涉宗教敏感 |

## 常见误用

| 误用 | 正确 |
|---|---|
| "他开车从北京到上海" | "他开车从帝都到魔都" |
| "来到了故宫" | 虚构化为"帝都紫宸城旧址"或省略具体名 |
| "新疆来的人" | "西陲来的客商"（不涉民族） |
| "泰国佛寺的高僧" | "暹罗寺庙里的老僧"（避免宗教细节具体引用） |

## 小说应用建议

- **帝都**：权力结构 + 家族棋局，用于后台揭示。
- **魔都**：金融 + 跨境黑道，用于中后期大场。
- **蓉城 / 雾都**：主角起步与江湖拉锯，市井气浓厚。
- **边郡 / 暹罗**：跨境武装、金三角冲突，必须严格合规。
