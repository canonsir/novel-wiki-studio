# 山海经 / 山海传

## 定位

《山海经》是先秦地理 + 神话 + 博物的集大成之书，是**玄幻 / 仙侠 / 都市玄幻 / 异兽设定 / 人物外号 / 组织命名**最常被取法的真实典籍。本页提供可直接用于小说人物外号、组织代号、功法、灵兽、地名的常识级清单与误用边界。

与 `mythology-and-folk-belief.md` 的分工：那边是神话总览，本页专攻《山海经》及其现代派生物（"山海传"是今人对山海经体系的扩写与改编总称，不是单一真实典籍）。

## 合规红线（最高）

- **真实典籍不改原文**：《山海经》原文公认版本以明代毛扆校本、清代郝懿行《山海经笺疏》为主；引用原文时保留原字，不虚构"原文"。
- **现代改编不冒充真迹**：所谓"山海传"是现代作者对山海经体系的二次创作总称，小说内不要暗示它是出土典籍。
- **不要造"真实在世的高人**"：涉及山海经的现代人物（专家、学者）全部虚构化。
- **异兽拟真度**：描写时可借典籍形貌，但不写"真实存在于某地"的位置信息（例外：青城山、昆仑等已成文化符号的名山可用）。
- **巫 / 蛊 / 符箓细节**：不写可操作教程；只写文化象征。

## 一、典籍结构速览

《山海经》共十八卷，分 **山经**（五藏山经，卷 1-5）与 **海经**（卷 6-13）+ **大荒经 / 海内经**（卷 14-18）。

| 分卷 | 内容速览 |
|---|---|
| 南山经 / 西山经 / 北山经 / 东山经 / 中山经 | 五方山系；每条山脉记山形、河流、矿产、神祇、异兽、植物、祭祀仪 |
| 海外南 / 西 / 北 / 东经 | 四海外奇国异族（如三首国、长臂国、羽民国） |
| 海内南 / 西 / 北 / 东经 | 四海内方国、神兽、神话事件 |
| 大荒东 / 南 / 西 / 北经 | 创世神话、帝俊 / 羲和 / 常羲等上古神祇 |
| 海内经 | 补遗与总结 |

**典籍属性**：杂糅地理志、博物志、巫书三者；没有统一叙事，是**词条式**结构——极适合从中挑单一词条来命名人物或组织。

## 五、《山海经》派生体系（二次创作）

- **山海传**：当代网络玄幻 / 国风 CG 对《山海经》体系的扩展统称；不是单一真实典籍。
- **白泽图**：传说中由白泽向黄帝口述的万物图谱，原书已佚；现代一般指对异兽的分类图册。
- **太平御览·兽部**：《太平御览》对山海经异兽的二次收录，是研究历代异兽释读的重要节点。
- **异兽录 / 异鱼图赞**：明清学者对山海经的注本（胡文焕《山海经图》、郝懿行《山海经笺疏》等）。

## 七、常见误用

| 误用 | 正确 |
|---|---|
| 把《山海经》写成"仙侠修炼教科书" | 它是地理 + 博物 + 巫书，不是功法书；取意象而非直接当武学教材 |
| 让"真实历史人物"研究山海经并给出结论 | 真实在世学者的言论不虚构；现代研究者用虚构人物名 |
| 把山海经异兽放在真实现代地名的某山 | 异兽放在虚构或已为文化符号的山（青城、昆仑、不周）；不要指向真实现代景区 |
| 滥用"山海经原文" | 引用用加引号的典籍原文，不虚构"原文"；可做小说内"今人编撰的山海传"虚构典籍 |
| 让异兽拥有现代可操作的"能力教程" | 只写文化象征和形貌，不写习得流程 |
