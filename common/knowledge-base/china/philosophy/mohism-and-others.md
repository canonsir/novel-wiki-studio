# 墨家 / 名家 / 阴阳家 / 杂家 / 纵横家 / 农家 / 小说家

## 定位

先秦诸子除了儒释道法外，还有"六家"或"九流"更冷门的学派。本页覆盖这些传统，供创作时需要"非主流哲学底色"的角色挂靠。

## 一、墨家

### 创始

- 墨翟（墨子），战国前期（约前 468-前 376）。
- 鲁国人，出身手工业者。

### 核心主张

- **兼爱**：无差别的爱，与儒家"亲亲"相对。
- **非攻**：反对侵略战争。
- **尚贤**：任人唯贤，不论出身。
- **尚同**：上下思想一致。
- **节用 / 节葬 / 非乐**：反对奢侈。
- **天志 / 明鬼**：承认天与鬼神。
- **非命**：反对宿命论，强调人力。

### 组织

- 墨家不是哲学团体，而是**武装组织**。
- 领袖称"**巨子**"，有严格纪律。
- 擅长**守城术**和**器械制造**（木鸢 / 云梯 / 守城器具）。
- 墨家弟子被称作"墨者"，为理想不惜生命。

### 著作

- 《墨子》存 53 篇，含《经上》《经下》《大取》《小取》等**墨辩**（中国古代形式逻辑）。

### 历史影响

- 战国时期与儒家并称"显学"（孟子"杨朱墨翟之言盈天下"）。
- 秦汉后几乎失传，直到清代被重新发掘。
- 近代被重估：是中国古代最接近"科学 + 民主"的学派。

### 小说应用

- **墨家传人**：隐居的手工巧匠 / 守城高手 / 工程师。
- **墨侠**：行侠仗义但纪律严明的刺客 / 游侠。
- **墨辩**：擅长逻辑辩论的智谋型配角。
- **墨家机关**：机关术 / 守城术 / 自动化装置。

## 二、名家（辩者）

### 代表

- **惠施**（与庄子论辩）、**公孙龙**（白马非马）、**邓析**。

### 核心主张

- **形名之辩**：名实关系的研究。
- 公孙龙"白马非马"、惠施"历物十事"（卵有毛 / 鸡三足 / 郢有天下）。
- 实质是**中国古代逻辑学 / 诡辩术**。

### 著作

- 《公孙龙子》《邓析子》《惠施》残篇。

### 历史

- 战国时期显赫，秦汉后衰落。
- 被视作"诡辩"而不受重视。

### 小说应用

- **辩士 / 说客**：擅长颠倒黑白、以辞服人。
- **名家传人**：现代律师 / 外交官 / 谈判专家。
- **逻辑题 / 诡辩题**：可做谜题线索。

## 三、阴阳家

### 代表

- **邹衍**（战国齐国）。

### 核心主张

- **阴阳**：宇宙二元对立统一。
- **五行**：金木水火土相生相克。
- **五德终始说**：王朝更替按五行顺序（秦为水德 / 汉为火德等）。
- **大九州**：地理学的拓展想象。

### 影响

- 阴阳五行被所有学派吸收：儒 / 道 / 医 / 兵 / 风水 / 命理 / 中医。
- 阴阳家本身消失，但思想渗透一切。

### 小说应用

- **阴阳师**（日本 "阴阳道" 实源于此，但本土化）。
- **医生 / 风水 / 命理**背景的角色。
- **五行相克**作为玄幻武学 / 修炼体系。

## 四、杂家

### 代表

- **吕不韦**《吕氏春秋》。
- **刘安**《淮南子》。

### 核心主张

- 兼综儒 / 道 / 法 / 阴阳诸家。
- 没有自己的核心主张，整合为用。

### 著作

- 《吕氏春秋》：吕不韦门客编纂，先秦百科。
- 《淮南子》：汉代，道家为主，兼综诸子。

### 小说应用

- **博学多识的智囊**：不执着某一派，灵活应用。
- **顶级谋士角色**。

## 五、纵横家

### 代表

- **苏秦**（合纵）、**张仪**（连横）、**鬼谷子**（师父）。

### 核心主张

- 外交策略：**合纵**（弱者联合抗强）vs **连横**（强者分化弱者）。
- 游说 / 辩论 / 心战 / 情报战。

### 著作

- 《鬼谷子》：游说与心战秘籍。
- 《战国策》：合纵连横案例集。

### 小说应用

- **顶级说客 / 外交家**。
- **情报战 / 心战**专家。
- **跨境谈判 / 政治游说**角色。
- 《鬼谷子》原文可做关键道具（师门秘籍）。

### 鬼谷子传人（文化符号）

- 相传：苏秦 / 张仪 / 孙膑 / 庞涓都是鬼谷子弟子（真实存疑）。
- 民间：鬼谷子是"谋略 + 兵法 + 相术 + 医术"的综合祖师。
- 可做：隐居山中的神秘老师，教主角心战之术。

## 六、农家

### 代表

- **许行**。

### 核心主张

- 君臣并耕，共同劳作。
- 等粟而炊，一视同仁。

### 影响

- 中国古代"大同"思想源头之一。
- 后世影响不大。

### 小说应用

- **农家传人**：现代农业 / 乡村振兴角色。
- **乌托邦色彩**。

## 七、小说家

### 定位

- 《汉书·艺文志》列"九流十家"，小说家为"十家"末位。
- 不是现代意义的小说，而是**街谈巷议、民间故事、异事记录**。

### 代表

- 东方朔、班固整理的民间故事。

### 影响

- 中国小说传统的渊源：街谈巷议 → 魏晋志怪 → 唐传奇 → 宋话本 → 明清章回。

### 小说应用（元叙事）

- 对本仓所有创作者的提醒：**我们本身就是现代"小说家"**。

## 九、医家（独立于九流之外）

### 代表

- **扁鹊**（春秋，脉学祖师）。
- **张仲景**（东汉，《伤寒论》作者，医圣）。
- **华佗**（东汉末，外科祖师）。
- **孙思邈**（唐，药王，《千金方》）。
- **李时珍**（明，《本草纲目》）。

### 核心

- 阴阳五行 / 脏腑经络 / 四诊八纲（望闻问切 / 阴阳表里寒热虚实）。
- 中药：君臣佐使。
- 针灸：十二正经 + 奇经八脉。

### 小说应用

- **中医世家**：祖传医术，可做治伤 / 下毒 / 救急。
- **江湖郎中**：游走各地。
- **宫廷御医 / 名医**：现代可对应三甲医院专家。

## 十一、小说应用建议

### 师门渊源

- 主角 / 配角可挂靠九流十家中的"失落学派"，增加神秘感。
- 例：主角意外得到"墨家守城术"的残卷。

### 隐士高人

- 隐居的"诸子传人"是老派武侠 / 都市玄幻的经典角色。
- 例：山中老师父是"鬼谷子传人第 72 代"。

### 冲突张力

- 不同学派之间的辩论 / 对立。
- 例：儒家 vs 墨家 / 法家 vs 道家 / 名家辩士挑战主角。

### 文化厚度

- 用冷门学派的典故 / 术语增加作品厚度。
- 例：主角引用《墨子》"兴天下之利"做核心价值观。
