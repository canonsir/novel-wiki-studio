# 王阳明与阳明心学

## 定义

明代王守仁（号阳明，1472–1529）继陆九渊之后集大成的儒家心学体系，以"心即理 / 知行合一 / 致良知"三纲领为核心，是宋明理学的终极形态，也是日本明治维新与现代"行动哲学"的重要思想源头。

## 关键事实清单

### 人物生平

- 浙江余姚人，官至南京兵部尚书 / 新建伯。
- 青年：溺于辞章与骑射，佛道兼修。
- 中年：**龙场悟道**（贵州龙场驿，1508），顿悟"圣人之道，吾性自足"。
- 事功：**平定宁王朱宸濠之乱**（1519，仅 43 天）、征剿南赣山贼、广西思田乱。
- 晚年：讲学于绍兴稽山书院、天泉桥"四句教"（无善无恶心之体 / 有善有恶意之动 / 知善知恶是良知 / 为善去恶是格物）。

### 核心思想

#### 1. 心即理
- 道理不在外物，在人心本有；朱熹"格物致知"向外求是误。
- "心外无物，心外无事，心外无理"。

#### 2. 知行合一
- 知与行是一回事的两面；真知必能行，不行只是未真知。
- 反对"先知后行"的两段论。

#### 3. 致良知
- 良知是"是非之心"的本能判断；人人皆有。
- "致"是把良知的判断贯彻到每件事上。
- 恶是良知被遮蔽，而非没有良知。

#### 4. 四句教
```
无善无恶心之体，
有善有恶意之动，
知善知恶是良知，
为善去恶是格物。
```

### 历史影响

- **日本幕末**：吉田松阴、西乡隆盛、大久保利通、伊藤博文深受阳明学影响。
- **近代中国**：曾国藩、梁启超、孙中山、蒋介石、毛泽东都读阳明；蒋号"介石"取自"介于石，不终日，贞吉"。
- **现代**：日本经营之神稻盛和夫自述受阳明学启发。

## 常见误用

| 误用 | 正确 |
|---|---|
| 把"心学"写成"心灵鸡汤" | 心学是极严肃的哲学体系，强调"事上磨练" |
| 认为"知行合一"= 言出必行 | 更深层：知与行同时发生；"知而不行只是未知" |
| 让心学家只谈心不做事 | 阳明本人是明代最成功的军事家之一 |
| 把"致良知"等同于"听良心" | 良知是本能判断 + 不断事上磨练出来的智慧 |

## 小说应用建议

- **主角内心弧的理论支架**：从"向外求"（我要赢、我要钱）到"向内求"（我要什么样的我）。
- **精神导师角色**：隐居的老人家 / 退休的高人用阳明学点拨主角。
- **"事上磨练"**：主角不是坐而论道，是在江湖事件中磨出判断力。
- **知行冲突的戏剧**：主角"明明知道"该放手却放不下，这就是"未真知"的体现。
- **反派也可以读阳明**：恶人读了阳明仍作恶，是良知被欲望遮蔽，不是良知消失。
