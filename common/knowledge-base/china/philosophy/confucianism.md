# 儒家

## 定义

以孔子为宗、以仁义礼智信为核心、以修齐治平为路径的中国主流思想传统，自汉武帝"独尊儒术"后成为两千年来的制度与伦理底盘。

## 关键事实清单

- **始祖**：孔子（公元前 551–479），《论语》为核心语录；孟子（亚圣）主"性善"，荀子主"性恶"。
- **四书五经**：《论语》《孟子》《大学》《中庸》 + 《诗》《书》《礼》《易》《春秋》。
- **核心概念**：仁（爱人）、义（宜）、礼（规范）、智、信；忠恕；中庸；修身齐家治国平天下。
- **人伦**：五伦——君臣、父子、夫妇、兄弟、朋友；三纲五常是汉儒加工后的政治化版本。
- **宋明理学**：周敦颐、二程、朱熹（理学）、陆九渊 → 王阳明（心学）。
- **礼制**：丧服制、宗族、祠堂、科举、冠婚丧祭。
- **现代遗存**：家族观念、长幼有序、以德治国话语、仁政理想、文人气节。

## 常见误用

| 误用 | 正确 |
|---|---|
| 把儒家写成"保守压抑的礼教集合" | 儒家含有强烈改革冲动；朱熹、阳明都在重构时代 |
| 认为儒家 = 封建迷信 | 儒家是伦理 + 政治哲学，不等于鬼神崇拜 |
| 让"读书人"只会之乎者也 | 儒生讲究"六艺"：礼乐射御书数，并非文弱 |
| 把"中庸"写成"没立场" | 中庸是"过与不及之间的恰到好处"，是极高难度的平衡 |

## 小说应用建议

- 主角父辈 / 师长 / 老爷子等"旧派人"可挂儒家底色（礼义、忍让、家族优先、天下为公）。
- 江湖门派中"白道"大门派（如忠信帮、白袍会原型）天然带儒底色。
- 冲突张力：儒家"仁"vs 法家"刑"vs 道家"退"。
- 现代场景可用：祠堂谒祖、家训告诫、师门礼节、"长幼有序"引发的代际矛盾。
