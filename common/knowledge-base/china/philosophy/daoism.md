# 道家 / 道教

## 定义

**道家**指先秦老子、庄子为代表的哲学传统；**道教**指东汉以后以道家思想为底、融合民间信仰、方术与神仙系统的本土宗教。小说多数场景混用，但两者并不等同。

## 关键事实清单

### 道家哲学

- **始祖**：老子（《道德经》 5000 言）、庄子（《南华经》）、列子。
- **核心概念**：
  - **道**：天地万物的本源与规律，不可名、不可言尽。
  - **无为**：顺应自然，不妄为（不是不作为）。
  - **自然**：事物本来的样子。
  - **柔弱胜刚强**：以退为进、水的智慧。
  - **齐物**：万物平等，无绝对标准（庄子）。
  - **逍遥**：精神绝对自由（庄子"北冥有鱼"）。
- **政治态度**：小国寡民、不尚贤、无为而治、"治大国若烹小鲜"。

### 道教宗教

- **祖师**：张道陵（东汉，创五斗米道/天师道）、丘处机（全真道）。
- **主要门派**：
  - **正一道**（天师道）：符箓派，可娶妻生子，世袭天师。
  - **全真道**（王重阳创，丘处机光大）：丹鼎派，出家戒律严格。
- **神仙体系**：三清（元始天尊、灵宝天尊、道德天尊）、玉皇、三官、四御、八仙、五岳大帝、城隍、土地。
- **修炼**：外丹（炼矿物药，隋唐盛行，多出毒）→ 内丹（炼精气神，宋以后主流）。
- **主要名山**：武当（真武祖庭）、龙虎（天师祖庭）、青城、崂山、茅山。
- **方术**：符咒、风水、堪舆、占卜（易经八卦）、相面、斋醮。

## 常见误用

| 误用 | 正确 |
|---|---|
| 把老子写成"白胡子神仙" | 老子是哲人，道教后期才神化为"太上老君" |
| 道士满街作法 | 现代道士多数守观、做法事时才披法衣 |
| 把"无为"写成"躺平" | 无为是"顺势而为"，不是不动 |
| 让道家 = 阴阳五行 = 风水先生 | 道家哲学 ≠ 道教方术 ≠ 民间风水，应区分 |
| 全真道随便破戒 | 全真守五戒十戒，出家不娶 |

## 小说应用建议

- **道家底色**：主角"退一步海阔天空"、"大智若愚"、"水满则溢"的处世哲学。
- **道教道士**：常作世外高人 / 测字先生 / 风水师 / 奇门遁甲师出场。
- **武学挂钩**：太极（张三丰原型）、八极、形意、八卦（见 `crafts/martial-arts.md`）常挂道家底，强调以柔克刚、后发先至。
- **冲突张力**：道家"退"vs 儒家"进"vs 佛家"空"；三者可作主角三位老师、三条路径。

## 命理与方术在小说中的使用

- 可用于"氛围渲染"：香炉、符纸、测字摊、测八字。
- 慎用于"剧情裁决"：不能让一卦断定胜负，必须辅以证据链。
- **合规**：禁止把具体符咒 / 风水 / 占卜 / 看相当做可直接复制的"真理"，必须以虚构框架包装。
