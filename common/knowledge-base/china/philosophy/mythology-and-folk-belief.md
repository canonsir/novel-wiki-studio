# 神话 / 民间信仰 / 风水命理

## 定位

玄幻 / 仙侠 / 都市玄幻 / 鉴宝 / 悬疑等题材绕不开的"民间精神世界"。涵盖神话体系、民间神祇、风水、命理、梦兆、占卜。本页规定可写与禁区。

## 一、中国神话体系

### 核心典籍

- 《山海经》：先秦地理 + 神话 + 博物。
- 《淮南子》：汉代，补天 / 奔月 / 二十四节气来源。
- 《楚辞》：九歌 / 天问 / 离骚（南方楚神）。
- 《神异经》《搜神记》《聊斋志异》：汉魏晋到清的异事集。
- 《封神演义》（明）：道教封神体系。
- 《西游记》（明）：佛道融合。

### 创世神话

- **盘古开天辟地**：《三五历纪》。
- **女娲造人 / 补天**：《淮南子》。
- **伏羲画八卦 / 神农尝百草**：三皇传说。

### 三皇五帝

- **三皇**：伏羲、女娲、神农（或燧人、伏羲、神农）。
- **五帝**：黄帝、颛顼、帝喾、尧、舜。

### 主要神祇体系

#### 道教封神体系

- **三清**：元始天尊 / 灵宝天尊 / 道德天尊（太上老君）。
- **四御**：玉皇大帝 / 紫微大帝 / 勾陈大帝 / 后土皇地祇。
- **五方帝**：东方青帝 / 南方赤帝 / 西方白帝 / 北方黑帝 / 中央黄帝。
- **二十八宿**：天上群星。
- **四灵**：青龙（东）/ 白虎（西）/ 朱雀（南）/ 玄武（北）。
- **八仙**：李铁拐 / 汉钟离 / 吕洞宾 / 张果老 / 何仙姑 / 蓝采和 / 韩湘子 / 曹国舅。

#### 佛教诸佛

- **三世佛**：燃灯古佛（过去）/ 释迦牟尼（现在）/ 弥勒佛（未来）。
- **四大菩萨**：观音（南海普陀）/ 文殊（五台）/ 普贤（峨眉）/ 地藏（九华）。
- **四大天王**：持国 / 增长 / 广目 / 多闻。
- **罗汉**：十八罗汉 / 五百罗汉。

#### 民间神祇

- **财神**：赵公明（武财神）/ 范蠡 / 关公。
- **门神**：秦琼 / 尉迟恭。
- **灶神 / 灶王爷**：家庭守护。
- **土地 / 山神 / 河伯 / 龙王**：地方神。
- **城隍**：城市守护。
- **妈祖 / 天后**：海上保护（闽台南洋）。
- **关帝 / 关老爷**：忠义象征，各行各业的祖师神（商人 / 江湖人尤其供奉）。

### 异兽 / 妖怪

#### 《山海经》经典

- **饕餮**：贪食之凶兽。
- **穷奇**：形似虎有翅膀。
- **梼杌**：凶神。
- **混沌**：浑沌之兽。
- **九尾狐**：祥瑞 / 妖异两极化。
- **凤凰 / 麒麟**：祥瑞。
- **夔**：独足牛。
- **烛阴 / 烛龙**：北方神。

#### 《封神》《西游》

- 大量妖王 / 魔尊 / 道人 / 散仙。

## 二、民间信仰（都市文可用）

### 老百姓常拜

- **财神**：春节 / 初五迎财神。
- **关公**：江湖人 / 商人必拜。
- **妈祖**：沿海渔民 / 海商。
- **土地公 / 城隍**：地方保护。
- **送子观音**：求子。
- **月老**：求姻缘。
- **文殊 / 文昌**：求学业。
- **药王 / 保生大帝**：求健康。

### 常见宗教场所

- 寺庙 / 道观 / 关帝庙 / 城隍庙 / 土地庙 / 妈祖庙。
- 都市文常用场景：主角拜拜 / 老爷子请神。

### 民间仪式

- **开光**：法师加持物件。
- **做法事 / 超度 / 还愿**：道士 / 和尚主持。
- **祭祖**：清明 / 中元 / 冬至 / 年节。
- **搬家 / 开业 / 结婚**：择吉日。

## 三、风水与堪舆

### 核心概念

- **气**：风水的核心能量。
- **龙 / 砂 / 水 / 穴 / 向**：风水五要素。
- **阴阳**：阴阳平衡。
- **五行**：金木水火土相生相克。
- **八卦**：乾坤震巽坎离艮兑。
- **二十四山**：方位细分。

### 阳宅风水（活人居所）

- **朝向**：坐北朝南最佳。
- **大门**：财气入口。
- **财位**：客厅特定角落。
- **厨房 / 卫生间 / 卧室**：各有讲究。
- **形煞 / 气煞**：犄角 / 高压线 / 医院 / 坟地等。

### 阴宅风水（墓地）

- **风水宝地**：藏风聚气，后代兴旺。
- **龙脉**：山脉走势。
- **朝向 / 水口**：风水师勘察重点。

### 流派

- **形势派**（峦头派）：看山水形势。
- **理气派**：用罗盘 / 八卦。
- **玄空派**：三元九运。

### 风水器具

- **罗盘**：堪舆主要工具。
- **铜钱 / 五帝钱**：化煞。
- **八卦镜 / 山海镇**：挡煞。
- **泰山石敢当**：街角石碑。
- **金蟾 / 貔貅 / 招财猫**：招财。

### 著名风水师（历史）

- 郭璞（晋）：《葬书》。
- 杨筠松（唐）：风水祖师，形势派开创。
- 蒋大鸿（明）：玄空派。

## 四、命理 / 占卜

### 四柱八字

- 出生年月日时 + 天干地支 = 四柱八字。
- 推算五行平衡、大运小运、十神（正印 / 偏财等）。
- 可写：排盘 / 测命 / 流年。

### 紫微斗数

- 以紫微星为主，星曜落宫推命。
- 比八字复杂，详细到工作 / 婚姻 / 子女等。

### 奇门遁甲

- 兵家 / 道家秘术，天干地支 + 八卦 + 九宫。
- 民间传说可用于选时 / 布阵。

### 六壬

- 古代占卜术，用 "大六壬" "小六壬"。

### 周易八卦占卜

- 《易经》占卜，起卦 → 看爻 → 解卦。
- 现代"文王卦"、"金钱卦"常见。

### 塔罗牌 / 星座（西式）

- 都市文女性角色常用。
- 塔罗 78 张（22 大阿卡纳 + 56 小阿卡纳）。
- 星座 12 宫：白羊 / 金牛 / ... / 双鱼。

### 相术

- **面相**：五官 / 气色 / 骨骼。
- **手相**：掌纹（感情线 / 事业线 / 生命线）/ 指纹 / 掌丘。
- **骨相**：骨骼形制。

### 梦兆

- 周公解梦 / 民间梦兆。
- 可做情节暗示：主角梦见未来 / 梦见过去。

## 五、文化合规（极重要）

### 写作红线

- **不把具体占卜 / 风水 / 命理当做剧情裁决工具**：可做氛围、不作判决。
- **不写具体 "开光 / 作法 / 下咒"流程教学**：避免被视作迷信传播。
- **不以具体真实宗教场所做犯罪 / 不堪事件背景**。
- **不虚构具体神职人员的具体不堪行为**。

### 可以写

- 民间信仰氛围（拜拜 / 求签 / 看风水）。
- 虚构仙 / 妖 / 道士 / 和尚人物。
- 山海经妖怪引用（典故使用）。
- 占卜 / 风水的概念 / 术语自然带出。

## 六、小说应用建议

### 玄幻 / 仙侠

- 以道教封神体系做底盘。

### 言情 / 都市情感

## 七、常见误用

| 误用 | 正确 |
|---|---|
| 让道士 / 和尚满街作法 | 真实世界修行者低调 |
| 风水先生百发百中 | 风水是概率优势，不是神力 |
| 把 "八字" 和 "星座" 混用 | 两套不同体系，别混 |
| 让主角 "一算一个准" | 命理需要有背景 + 代价 |
| 用具体真实场所写负面情节 | 必须虚构化 |
