# 佛教（中国化）

## 定义

公元前 6-5 世纪由释迦牟尼在古印度创立，公元 1 世纪前后沿丝绸之路传入中国，经过魏晋南北朝到唐宋的本土化，形成了与印度佛教不同的"中国佛教"面貌。

## 关键事实清单

- **四圣谛**：苦、集、灭、道。
- **三法印**：诸行无常、诸法无我、涅槃寂静。
- **八正道**：正见、正思惟、正语、正业、正命、正精进、正念、正定。
- **汉传八大宗派**：天台、华严、法相（唯识）、三论、律宗、净土、禅宗、密宗。
  - **禅宗**（南宗，六祖慧能）影响最深远，强调"直指人心，见性成佛"。
  - **净土宗**群众基础最大，念"南无阿弥陀佛"求生西方极乐。
- **三武一宗灭佛**：北魏太武、北周武、唐武宗、后周世宗，四次大规模佛教迫害。
- **汉地佛教组织**：丛林制度、方丈 / 住持 / 监院 / 维那等执事。
- **藏传佛教**：另成体系，格鲁、宁玛、萨迦、噶举四大派；活佛制度；达赖、班禅不是本页讨论对象（小说若涉及一律虚构化）。
- **南传上座部**：云南傣族地区 / 东南亚；黄袍、托钵、南传戒律与汉传不同。

## 常见误用

| 误用 | 正确 |
|---|---|
| 把"禅"写成"打坐冥想" | 禅宗核心是"顿悟 / 见性"，打坐是方法之一 |
| 让武僧满山飞 | 少林武僧真实存在，但不等于会武功的和尚满街跑；多数僧人只研经不习武 |
| 和尚可以喝酒吃肉 | 汉传严持荤酒戒；藏传部分教派有饮酒 / 肉食，但有仪轨 |
| "阿弥陀佛"直接当问候语 | 僧人问候用"阿弥陀佛"合十，但不是任意搭讪 |
| 把"业"写成"报应" | 业是因果机制，不是神罚；强调自作自受、无外在裁判者 |

## 小说应用建议

- 老僧 / 隐者可作主角的"精神导师"，不走神通路线，用"开示"推动主角内在转变。
- 寺庙可作主角创伤修复 / 关键情报交换 / 退隐之地。
- 禅宗公案可做隐喻（赵州"吃茶去"、南泉斩猫、德山棒）。
- 武学中"佛门心法"（易筋经、般若功原型）要有节制，别到处挂少林。
- 冲突张力：佛家"放下"vs 江湖"复仇"。

## 戒律与称谓

- **出家戒**：沙弥 10 戒 → 比丘 250 戒 / 比丘尼 348 戒。
- **称谓**：法师 / 师父 / 大德；在小说里对老僧的尊称"老衲"、"贫僧"是自称，不是别人称呼。
- **汉传服装**：僧衣（褐、黄、黑）、袈裟（披在左肩）。
