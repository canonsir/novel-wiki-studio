# 兵家与谋略

## 定义

以战争与权谋为研究对象的中国古代思想传统，涵盖军事、外交、商业、江湖、政治博弈的全部对抗场景。核心文本是《孙子兵法》《三十六计》《六韬》《吴子》等。

## 关键事实清单

### 核心文本

- **《孙子兵法》**（孙武，春秋）：13 篇，始计 / 作战 / 谋攻 / 军形 / 兵势 / 虚实 / 军争 / 九变 / 行军 / 地形 / 九地 / 火攻 / 用间。
- **《三十六计》**（汉以后托名）：胜战 / 敌战 / 攻战 / 混战 / 并战 / 败战六套。
- **《孙膑兵法》《吴子》《六韬》《尉缭子》《司马法》《李卫公问对》**。
- **《鬼谷子》**：纵横家与说客的辩术与心战。

### 核心原则

- **知己知彼，百战不殆**。
- **上兵伐谋，其次伐交，其次伐兵，其下攻城**。
- **以正合，以奇胜**。
- **兵者，诡道也**（孙子）：避实击虚、以静制动、以逸待劳。
- **善战者，致人而不致于人**（我控制战场节奏）。
- **道、天、地、将、法**（五事七计）：政治正当性、天时、地利、将领、军制。

## 常见误用

| 误用 | 正确 |
|---|---|
| 把计策当魔法 | 计策是概率优势，不是必胜 |
| 让主角一直用奇袭 | "正奇相合"，无"正"做底，"奇"是赌 |
| 对手永远接招 | 高手会预判反计，连环博弈 |
| 把兵家写成"算无遗策" | 真实战争 70% 是不确定性，兵家是"降低输率" |

## 小说应用建议

- 主角从"街头斗殴"到"组织博弈"的升级，就是兵家思维介入的过程。
- 每一卷主冲突应至少用 2-3 计串起；一计一场戏。
- **写计策的黄金节奏**：预埋 → 读者疑惑 → 揭示 → 爽点兑现。
- **代价感**：好的计策必须"看起来需要牺牲"才让读者心疼。
