# 现代扫黑除恶与涉黑案件程序

## 定义

当前中国司法体系对"黑社会性质组织"犯罪的认定、侦查、起诉、审判流程。都市 / 江湖 / 黑帮题材必读；写错了既不真实也可能触碰合规红线。

## 法律框架

### 核心法条

- **《中华人民共和国刑法》第 294 条**：组织、领导、参加黑社会性质组织罪 / 入境发展黑社会组织罪 / 包庇、纵容黑社会性质组织罪。
- **《反有组织犯罪法》**（2022 年 5 月 1 日施行）：
  - 第 2 条定义"有组织犯罪 / 恶势力 / 黑社会性质组织"。
  - 第 3 条确立"打早打小"原则。
  - 第 15 条"软暴力"手段也构罪。
  - 第 45 条涉案财产没收 / 处置。
- **《治安管理处罚法》**：轻度违法由公安处治安拘留。
- **《监察法》**：涉"保护伞"问题走监察委。

### "黑社会性质组织"四特征（判决必查）

1. **组织特征**：形成较稳定的犯罪组织，人数较多，有明确的组织者 / 领导者。
2. **经济特征**：有组织地通过违法犯罪 / 其他手段获取经济利益，具有一定经济实力，以支持该组织的活动。
3. **行为特征**：以暴力 / 威胁 / 其他手段，有组织地多次进行违法犯罪活动。
4. **危害特征**：在一定区域 / 行业形成非法控制或重大影响。

**少一个都不是"黑社会性质组织"**，只能定"恶势力"或"犯罪集团"。

## 司法程序（供真实化情节用）

```
线索发现 → 立案侦查 → 采取强制措施 → 侦查终结 → 审查起诉 → 一审 → 二审 → 执行
```

### 1. 立案与侦查

- 公安机关 / 监察委（涉保护伞）/ 检察院（涉职务犯罪）分别管辖。
- 立案后 2 个月基本侦查期；重大案件可延长至 2 年以上。
- 常用措施：**拘传、取保候审、监视居住、刑事拘留、逮捕**。

### 2. 强制措施层级

| 措施 | 期限 | 条件 |
|---|---|---|
| 拘传 | 12-24 小时 | 一般传唤不到 |
| 取保候审 | 最长 12 月 | 轻罪或患病 / 怀孕 |
| 监视居住 | 最长 6 月 | 比取保严格、指定居所 |
| 刑事拘留 | 一般 3-37 天 | 现行犯 / 重大嫌疑 |
| 逮捕 | 侦查羁押最长 7 个月 | 可能判有期以上 |

### 3. 审查起诉

- 检察院审查 1 个月（可延长半月）。
- 可退侦（2 次为限，每次 1 月）。
- 不起诉 / 起诉 / 存疑不起诉三种结果。

### 4. 审判

- 一审：基层法院 / 中级法院；黑社会性质组织案件通常**中级法院一审**。
- 可能被扣押资产：公司股权、房产、车辆、金融账户。
- 死刑案件必经**最高法院死刑复核**。

### 5. 涉案财产处置

- 判决生效后依法没收 / 追缴 / 返还被害人。
- "打财断血"是扫黑除恶常规动作：**掐断组织经济基础**。

## 常用手段（公安 / 检察官使用）

- **电子侦查**：手机定位、通讯监听（需审批）、银行流水。
- **技术侦查**：秘密录音、录像、便衣跟踪。
- **特情**：线人 / 卧底。
- **技侦结果不作庭审证据**：但可引导取证。
- **指定居所监视居住**：异地指定管理。

## 常见"保护伞"查办

- 涉及派出所 / 公安局 / 政法委 / 法院 / 检察院的保护伞走监察委。
- 高级干部"双规"是旧说法，现在是"留置"。

## 对小说的用处

### 做真实压制

- 主角做大后必然被扫黑逻辑盯上，是全书重要外部压力。
- "家族被查"的桥段必须符合程序：先监察介入 → 保护伞落马 → 组织被端。

### 做反派覆灭

- 大 Boss 的真实下场多数是**司法程序 + 财产没收**，不是江湖决斗。
- 可以借主角之手给司法提供证据链 → 比血腥报仇更有力度。

### 做主角困境

- 主角自身不违法但身边人涉案 → 被配合调查 → 两难选择。

## 合规红线（小说必守）

1. **不写可直接复刻的犯罪方法**（枪械改装、毒品合成、炸药配比）。
2. **不美化黑社会**（可写复杂人性，但不能把反派塑造成"没错只是选错时代"）。
3. **反派必有法律后果**（即使被兄弟弄死，也要有司法后续或家族崩塌）。
4. **公安 / 检察官不写成反派**（可写个别保护伞被查办，但主体公权力立场正）。
5. **具体真实案件不直接套用**（扫黑案、刑案的真实名字 / 地名 / 当事人不得使用）。

## 常见误用

| 误用 | 正确 |
|---|---|
| 让警察"动手就动"没程序 | 必须有程序、有审批 |
| 一提黑社会就"直接枪毙" | 中级法院一审、二审上诉、死刑复核，流程长 |
| 公安 24 小时找得到所有线索 | 真实侦查 2-24 个月才成案 |
| 保护伞随便 "处理掉" | 必须经监察委 / 纪委 / 检察院 |
