# 公安日常 / 治安 / 户籍 / 常见执法

## 定位

与 `anti-mafia.md`（扫黑程序）互补。本页覆盖**日常警务** / **普通刑事治安** / **户籍 / 身份管理** / **交通执法** 等场景，是都市 / 社会 / 悬疑小说的硬设定底盘。

## 一、公安组织架构

### 层级（从上到下）

```
公安部 → 省公安厅 → 市公安局 → 区 / 县分局 → 派出所
```

### 核心警种

| 警种 | 职责 |
|---|---|
| 治安 | 日常治安管理 / 户籍 |
| 刑侦 | 刑事案件侦查 |
| 经侦 | 经济犯罪 |
| 网安 | 网络犯罪 |
| 禁毒 | 毒品案件 |
| 技侦 | 技术侦查 |
| 国保 | 国家安全保卫 |
| 交警 | 道路交通 |
| 特警 | 突发事件 / 反恐 |
| 消防 | 原消防，2018 转应急管理 |
| 出入境 | 签证 / 护照 |

### 职级（现代人民警察）

- **一级总警监 / 副总警监 / 警监（一 / 二 / 三级）**
- **警督（一 / 二 / 三级）**
- **警司（一 / 二 / 三级）**
- **警员（一 / 二 / 三级）**

### 行政职务（容易写错）

- **厅长 / 市局长 / 分局长 / 所长**是行政职务，不等同警衔。
- **局长通常是副市长 / 常委兼任**（市局长）。
- **教导员 / 政委**：党政双配。

## 二、派出所日常

### 民警业务

- **户籍业务**：户口迁入 / 迁出 / 身份证办理 / 居住证。
- **治安调解**：邻里纠纷 / 家庭纠纷 / 轻微打架。
- **行政处罚**：治安拘留 / 罚款 / 警告。
- **刑事初查**：发现有刑事嫌疑后立案或移交刑侦。
- **接处警**：110 报警后处置。

### 处警常见流程

```
110 报警 → 接警员录入 → 派警 → 民警到现场 → 处置（调解 / 拘留 / 带回所）→ 记录 → 回访
```

### 治安拘留

- 期限：1-20 天（合并执行最长 20 天）。
- 适用：轻微打架 / 寻衅滋事 / 吸毒 / 卖淫嫖娼 / 赌博。
- 执行：拘留所 / 戒毒所。

## 三、刑事侦查流程（普通刑案）

### 流程

```
立案 → 侦查 → 预审 → 移送起诉 → 审判 → 执行
```

### 时限（可做情节紧迫感）

- **刑事拘留**：3-7 天 / 特殊情形 30 天。
- **逮捕后侦查羁押期**：2 个月 / 可延长至 7 个月。
- **审查起诉**：检察院 1 个月（可延长半月）。
- **一审**：2-3 个月 / 复杂案件可延长。
- **二审**：2-3 个月。

### 强制措施（见 `anti-mafia.md` 详表）

- 传唤 / 拘传 / 取保候审 / 监视居住 / 刑事拘留 / 逮捕。

## 四、常见刑事案件（可做情节）

### 1. 盗窃

- 普通盗窃：3 年以下。
- 入室盗窃 / 扒窃 / 携带凶器盗窃：加重。

### 2. 诈骗

- 普通诈骗 3 年起步；大额（50 万+）10 年起。
- 电信网络诈骗：10 年以上 / 无期（特别严重）。

### 3. 抢劫

- 3-10 年；加重情节（持凶器 / 入户）10 年以上 / 无期 / 死刑。

### 4. 故意伤害

- 轻伤：3 年以下。
- 重伤：3-10 年。
- 致死：10 年 / 无期 / 死刑。

### 5. 故意杀人

- 情节严重 10 年 / 无期 / 死刑。
- 情节较轻 3-10 年。

### 6. 强奸

- 3-10 年；加重情节（多人 / 重伤 / 死亡）10 年以上 / 死刑。

### 7. 贩卖毒品

- 鸦片 / 海洛因 / 冰毒 50 克以上：无期 / 死刑。
- 50 克以下：3-15 年。

### 8. 洗钱 / 职务犯罪

- 洗钱：5 年以下；特别严重：5-10 年。
- 贪污受贿：按金额分档，百万起步重刑。

## 五、户籍 / 身份管理（可做情节细节）

### 居民身份证

- **18 位**：地区（6）+ 出生（8）+ 顺序（3）+ 校验（1）。
- **初次办证**：16 周岁。
- **挂失 / 补办**：各地程序略不同。
- **临时身份证**：有效期 3 个月。

### 户籍迁移

- **投靠**：子女投靠父母 / 配偶投靠。
- **工作迁移**：工作调动。
- **人才引进**：高学历 / 高技能。
- **买房落户**：部分城市。
- **农转非**：农业转非农业。

### 居住证

- **非户籍人口在居住地申办**。
- 可享受教育 / 医疗 / 社保部分权利。
- 居住证满 N 年可申请户籍（部分城市）。

### 护照 / 签证

- **普通护照**：出入境管理局办理。
- **因公护照**：公务 / 外派。
- **港澳通行证**：港澳办事。
- **台湾通行证**：赴台。

## 六、交通执法

### 常见违章

- 超速 / 闯红灯 / 不系安全带 / 酒驾 / 醉驾 / 毒驾 / 疲劳驾驶。
- 不礼让行人 / 违规变道 / 占用应急车道。

### 酒驾 / 醉驾

- 酒驾：20-80 mg/100ml，暂扣驾照 6 个月 + 罚款 1000-2000 + 记 12 分。
- 醉驾：80 mg+，吊销驾照 5 年 + 拘役 + 罚金 + 终生禁驾（营运）。
- 现实事例：醉驾入刑是刚性标准。

### 事故处理

- **轻微事故**：快处快赔。
- **一般事故**：交警到场 / 定责 / 保险。
- **重大事故（人员伤亡）**：刑事立案 + 吊销驾照。

## 七、公安常见误用

| 误用 | 正确 |
|---|---|
| 让警察"闯进来就抓人" | 必须有程序 / 证件 / 手续 |
| "一秒查手机 / 身份证" | 查询需要程序 + 系统权限 |
| "警察办案不走程序" | 真实办案程序严格 |
| 所长 / 局长"随便指使手下杀人" | 现实公安层级严明，重大指令需书面 |
| 女警只做文秘 | 现代女警大量在一线 |
| 便衣可以随时亮枪 | 便衣亮枪必有程序 |

## 八、民警 vs 协警 vs 辅警

- **民警**：公务员编制，有执法权。
- **协警 / 辅警**：公安雇佣协助人员，无独立执法权，只能辅助。
- **保安**：企业 / 社区雇佣，无执法权。

## 九、国家安全机构（谨慎处理）

- **国家安全部 / 省厅 / 市局**：反间谍 / 国家安全。
- **情报战 / 反渗透**：极度敏感，建议不碰或虚构化。
- **解放军总参 / 二部 / 三部**：军事情报，不写。

## 十、监察 / 纪检（反腐）

- **中央纪委国家监委**：党政监督最高机关。
- **省 / 市 / 区监委**：下属机构。
- **"留置"**：取代"双规"，可留置 3-6 个月。
- 对象：公职人员贪腐 / 失职 / 渎职。

## 十一、法院 / 检察院 / 律师（配套系统）

### 法院

- 最高法 → 高级法 → 中级法 → 基层法。
- 刑事 / 民事 / 行政 / 执行 四类庭。

### 检察院

- 最高检 → 省检 → 市检 → 区检。
- 职责：审查起诉 / 公诉 / 法律监督。

### 律师

- 刑事辩护律师 / 民商事律师 / 公司法律顾问 / 涉外律师。
- 律所：京都、金杜、方达、中伦、锦天城、大成（国内顶级）。
- 费用：顶级律师万元 / 小时。

## 十二、写作建议

### 让警察有真实感

- **不是全知全能**：很多案件靠线索 / 举报 / 技术。
- **走程序**：每一步都有记录和审批。
- **有人情世故**：老刑警 / 新警 / 老滑头 / 愣头青。
- **有生活**：加班 / 家庭 / 身体 / 心理压力。

### 让主角合法化

- **主角做大后面对的最大对手不是对手帮派，而是公检法司**。
- **主角合法化**是终局必答题。
- **主角 / 对手配合司法 = 爽点兑现**。

### 让反派有后果

- 反派不能"永远逍遥法外"。
- 可以写"司法暂时够不到"，但不能永远。
