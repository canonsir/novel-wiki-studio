# 江湖礼节 / 黑帮规矩

## 定位

现代都市 / 江湖 / 黑帮题材中，角色的"身份感"主要靠**礼节 / 规矩 / 切口**撑起。本页集中整理可以直接用的礼节模板。

## 结拜 / 入会

### 传统结拜

- 焚香三炷、歃血（刺指滴酒）、拜天地父母。
- 誓词模板："不求同年同月同日生，但求同年同月同日死。"
- 排辈分：年龄为先，入道次序为次。

### 现代改良（都市文可用）

- 不见血、改为倒酒三杯 / 换酒碗。
- 餐厅包间 / 老店小馆 / 办公室闭门拜把子。
- "大哥 / 二哥 / 三哥"的称呼在结拜后立刻生效。

## 见面礼

### 旧式

- **抱拳礼**：左掌贴右拳背，拇指扣入。江湖通礼。
- **三指礼**：拇、食、中三指并出，青帮 / 洪门暗号。
- **七指礼**：七指分开，隐示本门。

### 现代

- 握手 / 点头，但有层级：
  - 下级先伸手，上级可以不伸。
  - 握手力度和时长暗示态度。
- 对老爷子辈 / 师门长辈仍行传统礼。

## 请客规矩

### 座次

- 主位：面对门口 / 风景最好 / 墙面有装饰的位置。
- 副主位：主位对面。
- 陪客：主位两侧。
- 新丁 / 最晚辈：靠门或角落。

### 点菜 / 敬酒

- 东道主点大菜，客人加素 / 甜点。
- 敬酒先敬最大辈分 → 平辈 → 晚辈。
- 回敬必须单杯，不能一次敬两人。
- 敬酒时站起，杯沿低于对方以示尊敬。

### 结账

- 东道主结，不能让客人抢单。
- 高段位的"抢单"是客人表示"我有能耐"的信号。
- 现代常用"二维码扫一下"但重要场合仍现金 / 卡。

## 江湖切口（旧式，供古风场景）

- **茶碗阵**：三碗分别代表不同询问（身份、来历、师承），放置位置暗示态度。
- **问人**："贵脚踏哪条道？" → "混口饭吃。"
- **问派**："在哪座山下走动？"
- **问师承**："家师是……"（给出暗号 / 字辈）。
- **求助**："路遇风雪，想借个暖。"（标准求帮暗语）

## 现代"规矩"（都市黑帮常见）

### 入道

- 老大点头 → 老人介绍 → 办事考察 → 定级。
- 新人常从"看场子"、"跑腿"、"接送"开始。

### 办事规矩

- **不碰朋友的女人**。
- **不出卖兄弟**。
- **不欠账超过约定期限**。
- **血债血偿但不滥杀无辜**（现代改良，老派仍有"连根拔"版本）。
- **不与警察 / 军人 / 政要正面冲突**（有脑子的）。
- **讲规矩的人才能长久，不讲规矩的只能逞一时**。

### 利益分配

- "三七开"、"四六分"、"抽成" —— 规矩明码挂在前面。
- 分不平不是分少，是没规矩。

### 退出 / 下场

- 老了想退：传位 / 遣散费 / 异地安置。
- 做错事：轻则赔罪、重则断手指 / 流放 / 极少数处决。
- 现代都市文多以"失踪"、"车祸"、"健康问题"外化。

## 师门礼节（武馆 / 江湖门派）

- **拜师**：三跪九叩或改良"三鞠躬"。贽敬（见面礼）：现代多以茶 / 简朴礼物。
- **师父生日**：弟子必须到场。
- **师父忌辰**：全体到祠堂 / 墓前。
- **师门排序**：按入门先后排"大师兄、二师兄、小师妹"。
- **出师**：师父亲口说"你出师了"或赐物件（戒指 / 剑 / 证书）。
- **叛师**：严重时"逐出师门"，门人见面必剪断情谊。

## 常见误用

| 误用 | 正确 |
|---|---|
| 江湖人人穿黑西装 | 真实黑帮低调为主，穿商务 / 便服 |
| 大哥随便骂手下 | 骂人会降威，真大哥用冷脸和不说话 |
| 结拜仅是"口头说一下" | 必须有仪式和见证人才成立 |
| 现代黑帮 24 小时见血 | 真实暴力率极低，大多是威慑 + 博弈 |

## 小说应用建议

- **主角初入江湖**：从被"考规矩"开始；用一次失礼换一次教训。
- **主角成长**：从"遵守规矩"到"立规矩"到"打破规矩"。
- **规矩与义气的冲突**：这是江湖故事的黄金张力。
- **代际差异**：老爷子讲礼节，年轻一代直来直去，可做"价值观对撞"场面。
