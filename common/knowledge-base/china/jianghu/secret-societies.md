# 江湖会党：洪门 / 青帮 / 哥老会 / 其他

## 定义

明清至近代的中国民间秘密结社。既是江湖武力网、互助组织，也是走私、鸦片、情报、革命的现实运作体。小说要写"江湖底色"，必须懂这几家底盘。

## 洪门

### 起源与分支

- 相传"反清复明"结社，康熙年间成立，天地会是最早的名称。
- 清末遍布海外：**旧金山、檀香山、新加坡、吉隆坡、曼谷、马尼拉**。
- 现代**致公党**是洪门的部分合法化后身（有美洲洪门渊源）。

### 组织

- **山堂香水**结构：各"山"独立，彼此平辈。
- 执事：山主（龙头）、副山主（副龙头）、大哥、二哥、新丁。
- 入会：开香堂、歃血为盟、三十六誓、七十二条。

### 文化符号

- 青红白三色、三指礼、江湖切口（茶碗摆放、称呼暗语）。
- "海底书"：成员信物。

## 青帮

### 起源

- 清雍正年间翁、钱、潘三祖创漕运工人结社，起初专运漕粮。
- 清末转型，开始经营鸦片、港口劳务、烟馆、妓院。
- 民国时期**上海三大亨**：黄金荣（法租界）、杜月笙（三鑫公司）、张啸林（投靠日本后被军统刺杀）。

### 组织

- **二十四辈**字派："清净道德，文成佛法，仁伦智慧，本来自信，元明兴礼，大通悟学"。
- 师徒制：开香堂、拜老头子（师父）、照看徒弟。
- 杜月笙是"悟"字辈，收徒排在他下一辈"学"字。

### 现代残影

- 1949 后在大陆基本清除，部分骨干流亡港澳台 / 东南亚。
- 当代"青帮"元素多数是戏剧渲染，但组织传统（辈分、师承、堂口）在小说里保留度高。

## 哥老会

### 起源

- 川湘地区会党，又称"袍哥"、"袍哥会"、"袍哥人家"。
- 清末民国在西南势力极大，川军、国民党西南将领多数袍哥出身。

### 组织

- **码头**制：以码头为基层单位。
- **仁、义、礼、智、信**五堂口排序，仁堂地位最高。
- 执事：**舵把子 / 大爷**（龙头）、二爷、三爷……十爷。
- 入会："挂牌"、"开山立堂"、"摆茶碗阵"（切口与茶碗摆法暗示身份）。

### 文化

- 讲"义气"、讲"规矩"，不轻易出手但一旦出手不留情。
- 刘湘、刘文辉、杨森等川军将领都是袍哥。

## 其他会党

- **小刀会**：清末上海、厦门起义团体。
- **白莲教**：宗教性秘密结社，清白莲教起义。
- **义和团**：清末民族主义农民结社。
- **三合会**：洪门别称，港澳地区现代"社团"底盘（14K、新义安、和胜和等）。
- **致公党**：洪门部分合法化。

## 小说应用建议

### 江湖礼节（真实存在，可用）

- **茶碗阵**：摆放不同形状的茶碗代表不同询问（身份、来意、师承）。
- **见面礼**：抱拳、三指礼、青子口（暗号）。
- **称呼**：堂主、舵把子、大哥（辈分最高）、兄弟（平辈）、新丁（新人）。
- **规矩**：师父生日 / 老祖忌辰 / 收徒开堂必须讲究仪式。

### 对现代都市文的改造

- 旧青帮 → 现代"社团"保留辈分制和师承，但明面以合法公司（物流、建材、娱乐）示人。
- 洪门海外 → 跨境华人圈的互助 / 情报网络。
- 哥老会 → 川渝地区的"袍哥文化"保留度最高，适合写市井江湖。

### 虚构代号建议

小说内禁止使用真实帮派名直接套用现代场景（如"杜月笙"、"黄金荣"、"14K"、"新义安"），一律虚构化：
- 青帮 → "青派" / "沪帮" / "滩会"
- 洪门 → "红门" / "海会" / "三色会"
- 哥老会 → "袍会" / "蜀会"
- 14K / 新义安 → "港会" / "珠会"

## 常见误用

| 误用 | 正确 |
|---|---|
| 把当代"黑社会"直接等同青帮 | 1990s 后崛起的东北 / 福建 / 浙江帮派多数与青帮无直接传承 |
| 让会党成员满街行礼 | 会党传统上要**掩人耳目**，公开场合不显 |
| 用真实帮派名称写现代犯罪情节 | 法律风险极高，必须虚构化 |
