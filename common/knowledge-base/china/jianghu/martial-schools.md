# 武术门派（现实版）

## 定义

中国传统武术的真实流派清单。小说要在"真实武学 + 虚构能力"之间平衡时，必须以本页为硬设定底盘。

## 内外家分野

- **外家**：以刚猛爆发力为主，少林、查拳、长拳、南拳。
- **内家**：以气血运行与柔化为主，太极、形意、八卦。
- 实际界限模糊，大派都兼修。

## 现实主流派

### 1. 少林（嵩山）

- 外家代表，禅武合一。
- 真实武僧存在，但现代少林主要是文化传承 / 商业化。
- 常见套路：少林拳 / 罗汉拳 / 棍法 / 易筋经（部分真实部分传说）。
- 小说挂法：主角意外得少林前辈残卷；少林出山武僧做江湖见证人。

### 2. 武当（湖北均县）

- 内家代表，道教传承。
- 相传张三丰创太极，史料上张三丰生平存疑。
- 常见：太极拳 / 太极剑 / 形意 / 玄武棍。
- 小说挂法：武当现代多数是修真观光；下山的"小道士"可做轻快角色。

### 3. 太极

- 五大派：陈（陈家沟）、杨（杨露禅）、吴（吴鉴泉）、武（武禹襄）、孙（孙禄堂）。
- 现实能力：慢练慢练，推手技实用，散手需要配合其他功夫。
- 小说挂法：陈氏爆发力强、杨氏柔化优雅、孙氏兼形意八卦；适合主角父辈 / 老爷子人物。

### 4. 形意

- 山西、河北两大流派；李洛能、郭云深、孙禄堂等近代名家。
- 五行拳（劈崩钻炮横）、十二形。
- 小说挂法：直接刚猛、后发先至、适合军旅背景（孙禄堂抗日）。

### 5. 八卦

- 董海川创于清末。
- 走圈 / 换掌，适合混战多敌。
- 小说挂法：步法诡异、擅长 1v 多；适合情报 / 杀手型角色。

### 6. 咏春

- 南派广东 / 福建系；叶问门下李小龙弟子推向世界。
- 寸拳、黐手、木人桩。
- 小说挂法：近身短打、巷战高手、港澳背景。

### 7. 洪拳 / 蔡李佛 / 鹤拳 / 螳螂等南派

- 广东福建南方传统，街斗实用、近战凶猛。
- 常见于南派武馆、海外华人圈。

### 8. 查拳 / 弹腿 / 戳脚（北派实战）

- 回族传承、华北中原。
- 高频踢技、重腿功。

### 9. 八极

- 河北、山东；清末民初军阀 / 大帅护卫常练。
- 近代代表：李书文、刘云樵。
- 短促爆发、硬打硬进。
- 小说挂法：护卫、保镖、顶级武力的真实挂钩。

### 10. 军警实战流派

- **擒拿格斗 / 军体拳 / 散打**：现代中国军警标准训练。
- **特警徒手格斗**：以压制、锁拿为主。

### 11. 外来融合

- **泰拳（Muay Thai）**：八体格斗，膝肘凶猛。
- **巴西柔术 BJJ**：地面压制、关节技。
- **MMA**：综合格斗，当代现实"最强徒手"。
- **拳击 / 跆拳道 / 空手道**：都市健身房常见。

## 真实能力边界（硬约束）

AI 创作常犯"武力值无穷"的错，参考现实边界：

| 场景 | 真实上限 | 小说可做的虚构加成 |
|---|---|---|
| 徒手单挑 | 2-3 人同级别并发（电影级要诀：对手不同时上） | 可写主角 1v5 下风逃脱 |
| 徒手对持枪 | 极限距离 3 米内有突袭机会；10 米外基本死 | 1v1 可做戏；1v 多持枪必须靠智谋 |
| 跳跃 | 立定跳远 3 米、立定摸高 3.5 米极限 | 可借力飞檐，不可轻功凌空 |
| 耐痛 | 中弹后 10-30 秒窗口期（内脏除外） | 可强撑一场完整戏，不可完全无视 |
| 恢复 | 骨折 4-6 周，内伤数月 | 不能第二天复出，必须有养伤线 |

## 常见误用

| 误用 | 正确 |
|---|---|
| 让主角徒手打赢散弹枪 | 距离控制 + 偷袭 + 智谋，不能硬刚 |
| 太极慢打 = 弱 | 太极推手实用，但对街斗需要配合散手 |
| 咏春 = 李小龙无敌 | 李小龙的能力是综合练出，咏春是基础之一 |
| 内力震飞敌人 | 内劲真实存在（寸劲）但不能把人震飞 |
| 老师父 100 岁还能打 | 真实武术老人体能下降，经验在但不耐久 |

## 小说应用建议

- **主角**：建议多派融合（如散打 + 泰拳 + 咏春），避免单一门派被"更强门派"碾压。
- **师父角色**：挂传统内家派，角色魅力强。
- **反派**：带有军警背景或特种部队背景，制造实战压力。
- **江湖门派**：虚构化到"忠信帮武馆"、"白袍会内堂"级别，不直接挂真实门派名。
