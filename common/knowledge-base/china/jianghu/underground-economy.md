# 现代地下经济

## 定位

当代都市 / 江湖题材中"黑道"的真实运作场。1990s 之后老派青帮已消散，现代地下世界以**夜场 + 快递黑灰产 + 网贷 / 套路贷 + 跨境电诈 + 博彩 + 直播打赏灰产**为主。本页规定可写与不可写的边界。

## 一、夜场产业链（最经典的地下底盘）

### 典型场所

- **KTV / 夜总会**：唱歌 + 公主服务 + 高档包间。
- **酒吧 / 酒馆**：喝酒聊天为主。
- **夜店 / Club**：Dancefloor + DJ + 卡座。
- **洗浴 / 水会**：洗浴 + 按摩 + 服务。
- **茶楼 / 棋牌室**：麻将 + 德州 + 小桌生意。
- **足疗 / 保健**：街边店到高档会所。

### 组织架构

```
老板 / 投资人（通常不出面）
    ↓
总经理 / 大堂经理
    ↓
部门经理（公关部 / 服务部 / 吧台 / DJ）
    ↓
一线员工（公主 / 服务员 / 保安 / 调酒师）
```

### 收入模式

- **包间费 + 低消 + 酒水**（显收入）。
- **服务费 / 公关费**（半灰色）。
- **会员卡 / 预存卡**（现金流锁定）。
- **抽成**（场所抽成 / 公关抽成）。

### 江湖关系

- **保护费 / 场子费**：早期常见，现代扫黑后转为"合作费"。
- **收银老员工 / 保安队长**：是老板最信任的两人。
- **"妈咪 / 领班"**：公关部负责人，手下管几十个姑娘。

### 写作细节

- 夜场高峰期 22:00-04:00，白天空无一人。
- 大哥 / 商务客用包间，不走大厅。
- 现金结算仍是主流（避开流水监管）。
- "订盘子"：客人提前订一桌酒水的套话。

## 二、快递 / 物流黑灰产

### 常见业态

- **快递偷窃 / 内盗**：快递员 / 分拣员 / 外包搬运工偷手机 / 奢侈品。
- **代收 / 代签 / 代拒收**：电商薅羊毛。
- **盗取快递信息贩卖**：个人信息黑市。
- **跨境代购 / 走私**：真货 / 假货混搭。

### 写作用途

- 身份隐藏的职业：外卖骑手 / 快递员是"隐形人"的最佳伪装。
- 消息传递：旧式江湖通过快递包裹传东西。

## 三、网贷 / 套路贷 / 民间借贷

### 典型模式

#### 1. 普通民间借贷

- **月息 1-3%** 合法。
- **月息 3-10%**：高利贷风险区。
- **月息 10%+**：高利转贷罪。

#### 2. 套路贷

- 签空白合同 → 制造虚假流水 → 平账转债务 → 暴力催收。
- 常见于校园贷 / 街边贷 / 二手车贷。

#### 3. 电话 / 网络催收

- **软暴力**：电话轰炸 / P 图 / 曝光通讯录。
- **硬暴力**：登门追债 / 泼漆 / 跟踪。
- **"债务重组"骗局**：假装帮还债，实际再骗一次。

### 法律边界

- 催收罪（刑法 293 条软暴力）、非法拘禁、故意伤害、寻衅滋事。
- **写作禁区**：具体催收话术 / 具体 P 图模板 / 具体恐吓剧本。

## 四、博彩 / 赌博

### 实体赌场

- 地下赌场 / 棋牌室 / 茶楼后堂。
- 常见项目：麻将 / 推筒子 / 牌九 / 德州扑克 / 百家乐。
- 高端：会所级德州赌场 + 跨境私人游艇赌船。

### 网络赌博

- 境外搭建 / 境内运营：杀猪盘 / 竞彩 / 虚拟币赌博。
- **写作禁区**：具体赌博操作 / 具体诈骗话术。

### 跨境

- 澳门（濠江）/ 东南亚（暹罗 / 骠国 / 柬埔寨）。
- 常见桥段：主角被诱骗出国 / 困在境外赌场。

## 五、跨境电诈 / 网络诈骗

### 常见诈骗类型

- 杀猪盘（感情诈骗）。
- 刷单诈骗。
- 冒充公检法。
- 冒充客服 / 网购。
- 投资理财（虚假 APP）。
- 虚假贷款。
- 色情诱导。

### 跨境园区

- **缅北 / 果敢 / 妙瓦底**：现实"杀猪盘"重灾区。
- 可写背景：主角被"高薪招聘"骗去。
- **写作合规**：不写具体诈骗流程 / 操作细节，重点在受害 + 救援。

### 真实法律进展

- 2023 中泰缅跨国清剿行动。
- 大量"园区"被端。
- 公安 "断卡行动"、"猎狐行动"。

## 六、直播打赏 / 流量灰产

### 真实业态

- **MCN 机构**：批量制造"主播"，用机器流量引诱打赏。
- **刷量 / 刷粉 / 刷评论**：黑产基础设施。
- **诱导打赏**：剧本化"卖惨 / PK / 挤眉弄眼"。
- **假富翁打赏**：诱导真用户跟风。

### 法律灰色

- 大额打赏可能涉嫌非法集资 / 洗钱。
- 未成年人大额打赏可申请退还。
- 平台抽成 + MCN 抽成 + 主播分成。

## 七、虚拟币 / 跨境资产灰产

### 常见业态

- **币圈 / DeFi 骗局**：虚假项目 / 老鼠仓 / 跑路。
- **搬砖套利**：真实套利（半合法）vs 虚假 "搬砖"骗局。
- **洗钱**：USDT 跨境流转。
- **"矿机" 骗局**：假云矿 / 挖矿。

### 中国法律立场

- 虚拟币交易在中国境内被明令禁止（2021 年九部委通知）。
- 挖矿被列为"淘汰类产业"。
- 持有不违法，交易违法。

## 八、公共场所灰产

### 车辆 / 停车场

- **代收车位费 / 占车位**。
- **刮擦碰瓷**：故意制造事故敲诈。
- **二手车低价回收高价卖**（事故车 / 水泡车调表）。

### 房产 / 中介

- **假房源 / 真骗定金**。
- **二房东**：高价转租。
- **中介诈骗佣金**。

## 九、江湖 / 黑帮现代化（可嫁接的"合法外壳"）

### 常见外壳

- **物流公司**：转运 / 快递 / 搬家。
- **安保公司**：场所安保 / 私人保镖。
- **文化传媒公司**：MCN / 直播 / 短视频。
- **建材 / 工程 / 装修**：工地劳务 + 资金池。
- **娱乐公司**：夜场 / 艺人经纪。
- **投资 / 咨询公司**：拉皮条 / 洗钱。

### 现代"大哥"的典型装扮

- 不穿黑西装，穿定制中山装 / 商务便服。
- 不开豪车炫耀，开低调商务车（埃尔法 / 奔驰 S / 红旗 H9）。
- 不留光头 / 纹身，形象清爽。
- 不在饭局大声讲话，微笑 + 轻声。
- 身边一两个贴身保镖（看起来像司机 / 助理）。

## 十、扫黑除恶后的格局（2018-）

- 大规模专项运动清理涉黑组织。
- 现代"大哥"多数转型做合法生意或低调隐身。
- 公检法司对涉黑容忍度极低。
- 跨境诈骗园区成为新打击重点。

## 常见误用

| 误用 | 正确 |
|---|---|
| 现代黑帮像古惑仔那样打砍 | 现代"大哥"隐身在合法外壳里 |
| 夜场老板明目张胆违法 | 现代夜场必有合规外衣 |
| 跨境诈骗 = 外国人干 | 多数园区由中国人在境外运营 |
| 让主角"开一家 KTV 就上位" | 夜场有行业规则，不是随便能做 |
| 把网贷描绘成"随便挣钱" | 网贷 / 套路贷是重罪，有后果 |

## 小说应用建议

- **主角初期底层场景**：外卖骑手 / 快递员 / 夜场服务员，隐身在人群。
- **主角创业期**：夜场 / 物流 / 安保起家，合法外壳。
- **主角对手**：套路贷 / 网诈 / 跨境团伙。
- **主角成熟期**：从灰色转向合法化，面对历史清算。
- **扫黑背景**：主角必须时刻警惕合规风险。
