# 民国（1912–1949）

## 定义

从清朝灭亡到新中国成立的三十八年，中国在军阀混战、国共合作与破裂、抗日战争、国共内战中反复撕裂与重建。小说若需要"百年隐线"、"家族旧账"、"武馆黄金时代"的底色，这段是富矿。

## 关键事实清单

### 分期

| 阶段 | 时间 | 关键词 |
|---|---|---|
| 北洋时期 | 1912–1928 | 袁世凯 / 皖直奉军阀 / 五四 / 北伐 |
| 南京国民政府 | 1927–1937 | 蒋介石 / 剿共 / 法币改革 / 江浙财阀 |
| 抗日战争 | 1937–1945 | 淞沪 / 南京 / 武汉 / 重庆陪都 |
| 国共内战 | 1945–1949 | 三大战役 / 平津 / 渡江 |

### 社会生态

- **帮会黄金时代**：青帮（上海黄金荣 / 杜月笙 / 张啸林三大亨）、洪门海外（旧金山 / 东南亚）、哥老会（川湘）、潮汕系（南洋）。
- **武术繁荣**：中央国术馆（1928，南京）；李景林、孙禄堂、杨澄甫、王子平；武馆 / 走镖 / 保镖 / 大帅护卫。
- **报纸文化**：《申报》《大公报》《文汇报》；文人圈。
- **学界**：北大 / 清华 / 燕京 / 南开 / 西南联大。
- **江浙财团**：宋子文 / 孔祥熙 / 陈立夫陈果夫 / 杜月笙。
- **外国租界**：公共租界、法租界、日租界、俄租界、英德租界（分别在上海 / 天津 / 青岛 / 汉口 / 大连）。
- **情报战**：中统（陈立夫）、军统（戴笠）、特科（周恩来 / 顾顺章）。

## 小说应用建议

### 做"家族史"底盘

- 五大家族 / 四大家族 / 江湖世家的根基落在民国；
- 常用的历史挂钩：祖上是北洋军 / 国军某将 / 青帮某堂 / 江浙财阀 / 中统军统 / 留法勤工俭学派。

### 做"旧物件"的来源

- 虎符、怀表、民国银元、青帮戒指、国军配枪、黄埔教官证书、民国地契。

### 做"百年旧账"

- 建国前的站队决定了建国后的升贬；改开后的回归，背后常是民国旧账。

## 常见误用

| 误用 | 正确 |
|---|---|
| 让民国 = 浪漫旗袍留声机 | 民国同时是极度贫困、战乱、饥荒的时代 |
| 把军阀都写成"坏人" | 军阀复杂，吴佩孚、张学良、冯玉祥各有良善面 |
| 青帮三大亨 = 纯粹黑帮 | 杜月笙既做鸦片也做慈善 / 办抗日救亡 |
| 民国特务 = 冷血杀手 | 军统 / 中统有极高的政治忠诚与知识水平 |
| 国军 = 挨打 | 国军正面战场承担了抗战主要战场 |
