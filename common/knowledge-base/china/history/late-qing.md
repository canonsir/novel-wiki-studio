# 清末（1840–1912）

## 定义

从鸦片战争到清朝灭亡的七十余年，中国从"天朝上国"坠入"半殖民地半封建"的巨变期。小说要用这段时代底色时，必须抓住"旧秩序的最后光景 + 新势力的雏形"这一张力。

## 关键事实清单

### 时间节点

| 年份 | 事件 | 影响 |
|---|---|---|
| 1840 | 鸦片战争 | 门户被撬，南方率先开埠 |
| 1842 | 《南京条约》 | 五口通商 / 割香港 / 赔款 |
| 1851 | 太平天国起义 | 江南十四年战乱 |
| 1856 | 第二次鸦片战争 | 英法联军入京 / 火烧圆明园（1860） |
| 1860s | 洋务运动开始 | 曾国藩、李鸿章、左宗棠、张之洞 |
| 1861 | 慈禧垂帘听政 | 实际掌权近 50 年 |
| 1894 | 甲午战争 | 北洋水师全军覆没 |
| 1898 | 戊戌变法 | 103 天维新，六君子就义 |
| 1900 | 庚子事变 | 八国联军 / 东南互保 |
| 1911 | 辛亥革命 | 清朝终结 |
| 1912 | 民国元年 | 中华民国临时政府 |

### 关键群体

- **朝廷**：皇帝 / 慈禧 / 军机处 / 内务府 / 总理各国事务衙门。
- **汉臣军阀**：曾国藩（湘军）、李鸿章（淮军）、左宗棠（楚军）、张之洞（鄂军）。
- **洋人**：英法美俄日德意奥八国；传教士 / 商人 / 水兵 / 顾问。
- **买办阶层**：洋行代理人，近代民族资本雏形。
- **会党**：天地会、哥老会、青帮、洪门、小刀会；江湖武力网。
- **新式学生**：留学日本 / 欧美，带回革命思想。
- **太平天国 / 捻军 / 回民起义**：各地叛乱。

### 社会场景

- **南方开埠城市**：上海、广州、宁波、福州、厦门、天津、烟台、青岛的租界。
- **传统内地**：山西票号、徽商、晋商、江南丝绸、湖广米市、川盐。
- **边疆**：新疆（左宗棠收复 1876）、西藏（英俄角逐）、东三省（俄日争夺）。
- **交通**：电报、铁路（京张、京汉、津浦）、轮船招商局、京师大学堂。
- **武器**：从传统刀枪 → 后装步枪 / 克虏伯炮 / 装甲舰的过渡期。

## 小说应用建议

### 作为"旧时代"底色

- 主角父辈 / 师长 / 老爷子的"祖上"可追溯到清末会党或湘淮军系。
- 五大家族的历史根基常设在清末（例：杨家内务府医术、苏家漕运、张家北洋奉系、林家湘军、陈家淮军）。
- 开埠城市（魔都 / 津门 / 鹭岛）的租界风格给小说后半场提供"殖民地化"地景。

### 作为"伏笔"

- 清末的旧账 → 民国延续 → 建国初被压 → 改开后浮出 → 当代冲突。
- 这条"百年隐线"是武侠都市文常用的"后台揭示"结构。

## 常见误用

| 误用 | 正确 |
|---|---|
| 让清末武林高手满街飞 | 清末武林真实存在（八极、形意、太极、咏春），但受冷兵器时代终结影响已式微 |
| 把太平天国写成"农民正义" | 太平天国造成数千万人死亡，是复杂事件，不作片面美化 |
| 让慈禧简单写成"卖国贼" | 慈禧是极复杂的政治人物，不能脸谱化 |
| 清末人都留长辫穿长袍 | 新式学生、留洋人员、新军已剪辫 / 穿西服 |
