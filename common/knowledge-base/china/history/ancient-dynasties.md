# 古代朝代速查（秦汉至明清）

## 定位

补充 `late-qing.md` / `republican-china.md` / `prc-and-reform.md` 之前的部分。用于古装 / 穿越 / 玄幻背景中的朝代底色参考。

## 二、秦（前 221-前 206）

### 关键

- **始皇帝嬴政**统一六国（前 221）。
- **郡县制**取代分封。
- **车同轨 / 书同文 / 行同伦**。
- **焚书坑儒**。
- **长城 / 阿房宫 / 兵马俑**。
- **二世而亡**：陈胜吴广起义。

### 小说用处

- 兵马俑题材。
- "大秦帝国"穿越文。
- 法家治国底色。

## 三、汉（前 206 - 公元 220）

### 西汉

- **刘邦建国 / 文景之治 / 汉武帝**（独尊儒术 / 攻匈奴 / 张骞通西域）。
- **丝绸之路**开通。
- **司马迁《史记》**。
- **王莽篡汉**（新朝）。

### 东汉

- **光武中兴**（刘秀）。
- **班固《汉书》**。
- **蔡伦改进造纸术**。
- **三国前的乱世**：党锢之祸、黄巾起义。

### 小说用处

- 丝路题材 / 西域往来。
- 汉代游侠 / 刺客文化。
- 三国前传。

## 四、三国魏晋南北朝（220-589）

### 三国

- **魏（曹操 / 曹丕）、蜀（刘备 / 诸葛亮）、吴（孙权）**。
- **赤壁 / 官渡 / 夷陵**三大战。
- **《三国演义》原型**。

### 魏晋

- **司马炎建西晋**。
- **八王之乱 → 永嘉南渡**。
- **玄学 / 清谈 / 竹林七贤**（阮籍 / 嵇康 / 向秀 / 刘伶 / 山涛 / 阮咸 / 王戎）。

### 南北朝

- **南朝**：宋 / 齐 / 梁 / 陈。
- **北朝**：北魏 / 东魏 / 西魏 / 北齐 / 北周。
- **门阀士族 / 佛教兴盛**。
- **《世说新语》**。

### 小说用处

- 三国题材不说。
- 魏晋风度 / 玄学文青。
- 南北朝民族融合。

## 五、隋唐（581-907）

### 隋

- **隋文帝 / 隋炀帝**。
- **大运河 / 科举制创立**。
- **二世而亡**。

### 唐

- **贞观之治**（唐太宗 / 李世民）。
- **武则天**：中国唯一女皇。
- **开元盛世**（唐玄宗）。
- **安史之乱**（755-763）：盛世转衰。
- **藩镇割据**。
- **唐诗**：李白 / 杜甫 / 王维 / 白居易。
- **文化开放**：胡风胡乐 / 景教 / 伊斯兰入华 / 日韩使者。

### 小说用处

- 盛唐长安是无数古装剧场景。
- 唐诗 / 玄奘 / 杨贵妃。
- 开放多元文化。

## 六、宋（960-1279）

### 北宋

- **赵匡胤陈桥兵变**。
- **文治天下 / 杯酒释兵权**。
- **王安石变法 / 司马光 / 苏东坡**。
- **理学兴起**：周敦颐 / 二程 / 朱熹。
- **《清明上河图》**（张择端）。
- **靖康之耻**（1127）。

### 南宋

- **岳飞 / 秦桧**。
- **朱熹集理学大成**。
- **商业繁荣 / 海上丝路**。
- **崖山之战**（1279 南宋灭亡）。

### 小说用处

- 宋朝文人气象。
- 理学家冲突。
- 水浒 / 杨家将。
- 南宋海商 / 船运。

## 七、元（1271-1368）

### 关键

- **忽必烈建元**（1271）。
- **蒙古四大汗国**：横跨欧亚。
- **马可波罗游记**。
- **四等人制**：蒙古 / 色目 / 汉人 / 南人。
- **元曲 / 杂剧**：关汉卿 / 王实甫《西厢记》。
- **朱元璋起义**。

### 小说用处

- 蒙古文化 / 骑兵。
- 跨欧亚贸易。
- 江湖 / 侠客行走乱世。

## 八、明（1368-1644）

### 关键

- **朱元璋建国**：农民皇帝。
- **朱棣靖难之役 / 迁都北京**。
- **郑和下西洋**（1405-1433）。
- **锦衣卫 / 东厂 / 西厂**：特务政治。
- **张居正改革**。
- **抗倭援朝**（1592-1598）。
- **万历怠政 / 党争**。
- **李自成起义 / 吴三桂引清兵**（1644）。

### 文化

- **心学**：王阳明。
- **四大名著雏形**：《三国》《水浒》《西游》《金瓶梅》。
- **《永乐大典》**。
- **科学**：李时珍《本草纲目》、徐光启《农政全书》。

### 小说用处

- 锦衣卫 / 东厂特务。
- 郑和下西洋 / 海商。
- 东林党争。
- 王阳明心学。

## 九、清（1644-1912）

### 关键阶段

- **康雍乾盛世**（1662-1795）。
- **文字狱 / 闭关锁国**。
- **乾嘉学派 / 考据学**。
- **1840 后进入半殖民地**（见 `late-qing.md`）。

### 制度

- **八旗制**：满洲 / 蒙古 / 汉八旗。
- **军机处**：皇权集中。
- **科举 / 书院**。

### 文化

- **《红楼梦》《聊斋》《儒林外史》**。
- **乾嘉学派**：训诂考据达到顶峰。
- **洋务运动**（1860s）。

### 小说用处

- 清宫剧经典。
- 江湖反清复明（天地会）。
- 洋务 / 买办初期。

## 十、关键制度演变

### 皇权

- 秦：中央集权雏形。
- 汉：丞相为首的三公九卿。
- 唐：三省六部制（中书 / 门下 / 尚书）。
- 宋：弱宰相强皇权。
- 明：废宰相，内阁。
- 清：军机处。

### 选官

- 察举（汉）→ 九品中正（魏晋）→ 科举（隋唐至清）。
- 科举：秀才 → 举人 → 进士。

### 地方

- 秦：郡县。
- 唐：道州县。
- 元：行省制（现代省制起源）。
- 明：布政司。
- 清：省府县。

### 军事

- 府兵制（唐）→ 禁军厢军（宋）→ 卫所制（明）→ 八旗绿营（清）。

## 十一、朝代更替常见话语

- **"分久必合，合久必分"**（《三国演义》开篇）。
- **"兴，百姓苦；亡，百姓苦"**（张养浩）。
- **"王侯将相，宁有种乎"**（陈胜）。
- **"天下大势，浩浩荡荡"**。

## 十二、常见误用

| 误用 | 正确 |
|---|---|
| 把唐朝写成"开放到现代" | 唐开放但仍有等级 / 身份 |
| 让宋朝"军事无能" | 宋军事有限但不是"无能"，技术发达 |
| 元朝 = 蒙古人全暴虐 | 元蒙古化 + 色目 + 汉文化杂糅 |
| 明朝太监 = 全部奸臣 | 郑和 / 冯保 / 王承恩是忠臣 |
| 清朝 = 落后挨打的代名词 | 清前中期疆域辽阔 / 文化多元 |

## 十三、小说应用建议

### 穿越文

- 挑一个朝代做底色，核心要素抓住：政治 / 军事 / 文化 / 日常。
- 不要穿到一个朝代写另一个朝代的东西（如穿到唐却写明的锦衣卫）。

### 古装都市

- 现代人物的祖上可追溯到某个朝代。
- 五大家族 / 江湖门派的渊源常在明末清初（反清复明 / 太平天国遗脉）。

### 文化挂钩

- 玄学挂魏晋。
- 诗词挂唐。
- 理学挂宋明。
- 心学挂明。
- 考据挂清。
