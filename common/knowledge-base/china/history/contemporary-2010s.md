# 当代中国（2012-2026）

## 定位

补充 `prc-and-reform.md`（1949-2012）之后的时间线。当代都市题材发生于本阶段，必须对这段年代有清晰认知。

## 一、分期

| 阶段 | 时间 | 关键词 |
|---|---|---|
| 新时代开启 | 2012-2017 | 十八大 / 反腐 / 一带一路 |
| 新常态与改革 | 2017-2020 | 十九大 / 中美博弈 / 结构性改革 |
| 后疫情时代 | 2020-2023 | 新冠 / 共同富裕 / 产业调整 |
| 当下 | 2023-2026 | AI / 新质生产力 / 国际秩序重构 |

## 二、政治

### 核心词

- **新时代中国特色社会主义**：核心叙事。
- **全面从严治党**：反腐常态化。
- **一带一路**（2013-）：跨境经济战略。
- **精准扶贫 / 脱贫攻坚**（2015-2020）：历史性成就。
- **共同富裕**（2021-）：收入分配导向。
- **双循环**（2020-）：内外循环战略。
- **三去一降一补**（2015-）：供给侧改革。

### 关键事件

| 年份 | 事件 |
|---|---|
| 2012 | 十八大 / 习近平任总书记 |
| 2013 | 一带一路提出 |
| 2015 | 军改启动 / "八项规定" |
| 2016 | 供给侧改革 / 房地产长效机制 |
| 2017 | 十九大 / 新时代 / 雄安设立 |

| 2022 | 二十大 / 疫情"动态清零" / 俄乌冲突 |
| 2023 | 疫情防控优化 / 经济重启 |
| 2024 | 新质生产力 / AI 国际竞争 |
| 2025-2026 | ... |

## 三、经济

### 关键议题

- **房地产调整**（2015-）：从"住房属性"到"居住属性"。
- **互联网反垄断**（2020-）：阿里 / 美团 / 腾讯 / 滴滴等被重点审视。
- **"双碳"目标**（2020）：2030 碳达峰 / 2060 碳中和。
- **芯片产业自主**：中美科技博弈。
- **新能源车**：全球领先（比亚迪 / 蔚来 / 理想 / 小鹏）。
- **数字经济**：平台监管常态化。
- **结构性改革**：从高速增长转向高质量发展。

### 行业兴衰

| 行业 | 2012 → 2026 |
|---|---|
| 房地产 | 高歌 → 调整 |
| 互联网 | 高速 → 严监管 |
| 新能源车 | 起步 → 全球领先 |
| 教育培训 | 繁荣 → "双减"重创 |
| 社区团购 | 兴起 → 洗牌 |
| 短视频 | 爆发（抖音 / 快手）|
| AI | 规模化应用（ChatGPT / 大模型）|
| 芯片半导体 | 外部压力 → 自主突破 |
| 医药 | 集采压价 / 创新药 |

## 四、科技

### 大事件

- **移动互联网下半场**（2012-2017）：BAT 格局 → 字节 / 美团 / 滴滴 / 拼多多崛起。
- **5G 商用**（2019-）：全球领先。
- **北斗全球组网**（2020）。
- **载人航天**：天宫空间站 / 嫦娥探月 / 天问探火。
- **大模型 / AI**（2023-）：ChatGPT 引发全球热潮，中国跟进。
- **量子通信 / 量子计算**（2016-）：墨子号 / 九章。
- **芯片**：持续追赶，国产替代加速。

### 代表公司

- **BAT**（百度 / 阿里 / 腾讯）：传统互联网三巨头。
- **TMD**（头条 / 美团 / 滴滴）：新生代。
- **拼多多**：下沉市场爆发。
- **抖音 / TikTok**：全球影响力。
- **华为 / 比亚迪 / 大疆**：硬科技代表。
- **宁德时代**：动力电池龙头。

## 五、社会

### 关键变化

- **城镇化加速**（2012 51% → 2024 66%）。
- **人口变化**：2022 开始人口负增长。
- **老龄化**：60 岁以上人口占比超 20%。
- **教育**："双减"（2021）/ 职业教育改革。
- **医疗**：集采 / 分级诊疗。
- **社保**：养老金并轨 / 医保全国统筹。
- **扫黑除恶**（2018-2020）：三年专项斗争。
- **扫黄打非**：持续专项行动。

### 文化消费

- **影视**：《战狼 2》《流浪地球》《封神》等国产大片崛起。
- **短视频**：抖音 / 快手主导。
- **游戏**：《原神》《王者荣耀》全球化。
- **文旅**：疫情后"报复性旅游" / 国潮兴起。
- **IP 变现**：网文 / 影视 / 游戏联动。

### 社会心态

- **"内卷"**：竞争过剩。
- **"躺平"**：年轻一代反抗竞争。
- **"佛系"**：中间状态。
- **"丁克 / 不婚"**：婚育率下降。
- **"打工人"**：年轻职场自嘲。
- **"小镇做题家 / 985 废物"**：教育阶层焦虑。

## 六、都市题材时间线锚点

### 2012-2015

- 移动互联网红利期。
- 智能手机普及。
- 滴滴 / 快的大战。
- 老 BB 机 / 大哥大退场。
- 微信覆盖社交。

### 2016-2019

- 共享经济爆发（共享单车 / 共享充电宝）。
- 网络直播兴起。
- 比特币热潮。
- 房价高位调控。
- 中美贸易战开启。

### 2020-2022

- **新冠**：全民戴口罩 / 居家办公 / 核酸 / 健康码。
- 直播电商爆发。
- "双减"冲击教培。
- 房地产暴雷（恒大）。
- 俄乌战争。

### 2023-2026

- AI 大模型普及。
- 新能源车全面取代燃油车（部分省市）。
- 国际秩序重构。
- 数字人民币试点。
- 短剧 / 短视频成为主流。

## 九、政商关系（可写细节）

### 层级

- **中央 / 省 / 市 / 县区 / 街道 / 社区**。
- 政商关系：企业家 ↔ 书记 / 市长 / 副市长 / 局长。

### 关键事件

- **十八大后反腐**：数十位省部级落马。
- **"打虎拍蝇"**：高压态势持续。
- **政商"亲清"关系**：既要亲近又要清白。

### 写作建议

- 现代主角做大后面临的政商关系必须有合规意识。
- 不写具体行贿细节，可写"吃饭应酬 / 送礼品 / 办事"。
- 公权力立场必须正。

## 十、流行语 / 梗 / 符号

### 2015-2020

- "心灵鸡汤" / "小目标" / "一个亿" / "蓝瘦香菇" / "吃鸡" / "C 位"。

### 2020-2023

- "内卷" / "躺平" / "打工人" / "工具人" / "绝绝子" / "yyds" / "破防" / "emo"。

### 2024-2026

- 使用时注意：这些流行语有时效性，用在小说里要考虑时代感。

## 十一、常见误用

| 误用 | 正确 |
|---|---|
| 把 2020 疫情前写成"后疫情" | 时间线必须准确 |
| 让主角 2015 年用 "yyds" | 流行语有时间锚点 |
| 把 2010 年房价与 2024 年等同 | 房价经历多轮调整 |
| 不涉疫情就"没发生" | 2020-2022 疫情是集体记忆 |
| 让"主角一年赚 10 亿"显得正常 | 2020 后监管严，暴富戏需要更谨慎的来源线 |

## 十二、小说应用建议

### 时间锚点选择

- 都市文一般设定在**当下或近 5 年内**，便于读者代入。
- 可明确年份（2024 春 / 2025 秋）或模糊（最近 / 这几年）。
- 回忆 / 过去用具体年份带出。

### 关键事件做戏剧

- 疫情封控 / 解封：代际差异。
- 房地产暴雷：家庭变故。
- "双减"：教育从业者的转型。
- 短视频爆发：主角创业契机。
- AI 普及：职业危机 / 新机遇。

### 代际差异

- 70 后：改开红利受益者。
- 80 后：下海 / 房地产黄金期。
- 90 后：互联网第一代原住民。
- 00 后：移动互联网原住民 / AI 原住民。
