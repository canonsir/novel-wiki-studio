# 建国初（1949–1978）与改革开放（1978–2012）

## 定义

从新中国成立到十八大之前的六十余年。小说常用的两个底色阶段：
- **建国初**：旧秩序被重塑；江湖势力被清理；物质极度稀缺。
- **改开**：旧账浮出；民间财富积累；江湖重建；灰色地带诞生。

## 建国初（1949–1978）

### 关键阶段

| 阶段 | 时间 | 关键词 |
|---|---|---|
| 建国与巩固 | 1949–1952 | 土改 / 镇反 / 抗美援朝 |
| 过渡期 | 1953–1957 | 一五计划 / 社会主义改造 / 反右 |
| 大跃进与困难 | 1958–1962 | 大炼钢铁 / 人民公社 / 三年自然灾害 |
| 调整与四清 | 1962–1965 | 调整巩固 / 社教运动 |
| 文革 | 1966–1976 | 红卫兵 / 停课 / 下乡 / 批斗 |
| 过渡 | 1976–1978 | 粉碎四人帮 / 真理标准讨论 |

### 对小说的用处

- **江湖清理**：建国初镇反把旧青帮、洪门、哥老会、国军遗系基本清光，少数核心人物遁入民间或海外。
- **家族沉底**：主角的爷爷辈 / 太爷辈多在这段"沉下去"——改开后才有机会回来。
- **文革伤痕**：家人被下放、财产没收、师承被批斗；可做"父辈心结"的来源。
- **知青下乡**：1968–1978 千万知青到农村，常作主角父母的爱情 / 创伤来源。

## 改革开放（1978–2012）

### 分期

| 阶段 | 时间 | 关键词 |
|---|---|---|
| 启动 | 1978–1984 | 十一届三中 / 包产到户 / 深圳特区 |
| 探索 | 1984–1992 | 价格双轨 / 下海潮 / 六四 |
| 加速 | 1992–2002 | 南巡 / 社会主义市场经济 / 入世 |
| 高速 | 2002–2012 | 加入 WTO / 四万亿 / 房地产浪潮 |

### 对小说的用处

- **江湖重建**：1990s 东北 / 东南沿海 / 西南的黑社会从烂尾工程、歌舞厅、建材、运输起家。
- **财富原始积累**：九十年代的"下海"、股改、国企改制、国有土地出让、房地产开发。
- **身份跃迁窗口**：
  - 1980s 文艺青年 / 诗人 / 第一批个体户
  - 1990s 下海经商 / 走私 / 歌厅
  - 2000s 房地产 / 互联网 / 跨境贸易
- **父辈命运**：
  - 读书改命（恢复高考 1977 第一批）
  - 下海经商（1992 南巡后）
  - 国企下岗（1998 前后）
- **当代"百年隐线"的落点**：清末 → 民国 → 建国初沉底 → 改开后重现。

### 关键背景

- **证券市场**：1990 上交所 / 1991 深交所。
- **房地产**：1998 房改（取消福利分房）；2003–2012 房价上行。
- **互联网**：1995 瀛海威、1999 BAT 雏形、2010 移动互联网。
- **教育**：1977 恢复高考；1999 大扩招；2000s 985/211 格局。
- **媒体**：《中国青年报》《南方周末》黄金期（1990s–2000s）；央视春晚文化。

## 对主角父辈设定的建议

| 父辈类型 | 时代背景 | 性格底色 |
|---|---|---|
| 下乡知青 | 1968–1978 | 吃苦耐劳、沉默、理想主义幻灭 |
| 恢复高考首批 | 1977–1980 | 读书改命、精英意识、与江湖脱节 |
| 下海第一代 | 1984–1992 | 冒险、灰色、江湖人情深 |
| 92 派 | 1992–1998 | 规则意识、懂政策 / 懂法 |
| 国企下岗 | 1998 前后 | 怨气、钻营、晚景堪忧 |
| 2000 后 | 2000– | 房地产 / 互联网新贵 |

## 常见误用

| 误用 | 正确 |
|---|---|
| 把文革写成"大背景"却不涉具体代价 | 文革必须以具体人物损失呈现，不空谈 |
| 让改开后的致富都"黑" | 大量合法致富（科技 / 外贸 / 建筑）同时存在 |
| 一提黑社会就落到 2010 后 | 2010s 大规模扫黑后格局重塑；设定在当代要考虑扫黑背景 |
| 时代感只靠"大哥大 / BB 机" | 时代感来自制度、物价、常用词、流行文化多维度 |
