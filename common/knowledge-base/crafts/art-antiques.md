# 艺术 / 古玩 / 鉴藏

## 定位

鉴宝文、老钱世家、文玩江湖、艺术品投资等题材的硬设定底盘。中国题材绕不开古玩字画 / 瓷器玉器 / 文玩手串，国际题材涉及拍卖行 / 艺术品洗钱。

## 一、中国古玩门类

### 1. 瓷器

- **五大名窑**：汝（天青釉）、官（釉开大片纹）、哥（金丝铁线）、钧（钧瓷窑变）、定（白瓷刻花）。
- **宋瓷**：被公认艺术顶峰；一件完整宋汝市场数千万。
- **元青花**：鬼谷子下山元青花，2005 年苏富比 2.3 亿港币。
- **明代**：永乐甜白、宣德青花、成化斗彩。
- **清代**：康雍乾三代巅峰；珐琅彩、粉彩、斗彩、青花。
- **民国 - 现代**：仿品市场庞大，是打眼高发区。

### 2. 玉器

- **和田玉**：羊脂玉（顶级）、青玉、青白玉、碧玉、糖玉。
- **翡翠**：缅甸产，分种水色（玻璃种 / 冰种 / 糯种 / 豆种）。帝王绿、冰阳绿为顶级。
- **古玉**：红山文化 / 良渚文化 / 商周 / 汉代玉器。
- **近代玉**：明清工 / 民国工 / 现代工艺。

### 3. 书画

#### 古代书法

- 王羲之《兰亭序》（真迹失传，神龙本是最权威摹本）、怀素《自叙帖》、张旭狂草、颜真卿。
- 宋四家：苏（东坡）、黄（庭坚）、米（芾）、蔡（襄）。
- 元代：赵孟頫、鲜于枢。
- 明代：祝允明、文征明、董其昌。
- 清代：王铎、傅山、何绍基。

#### 古代绘画

- **唐**：吴道子、阎立本、周昉。
- **宋**：范宽、郭熙、李唐、马远、夏圭、《清明上河图》张择端、《富春山居图》黄公望（元）。
- **元**：赵孟頫、黄公望、倪瓒、王蒙。
- **明四家**：沈周、文征明、唐寅、仇英。
- **清**：石涛、八大山人、郑板桥。
- **近现代**：吴昌硕、齐白石、张大千、徐悲鸿、黄宾虹、傅抱石、李可染。

### 4. 青铜

- **商周青铜**：鼎、尊、簋、鬲、豆。
- **礼器 / 兵器**：九鼎八簋是周礼最高规格。
- **铭文**：司母戊鼎、毛公鼎（铸铭 500 字）、散氏盘。
- **流通**：绝大多数是博物馆藏品，市场流通极少。

### 5. 杂项

- **文玩手串**：沉香、檀香、黄花梨、小叶紫檀、海南黄花梨、崖柏、绿松石、南红、蜜蜡。
- **印章**：寿山石（田黄顶级）、青田石、昌化石（鸡血石顶级）。
- **古籍善本**：宋版 / 元版 / 明清刻本。
- **铜钱**：先秦刀币、汉五铢、唐开元、宋徽宗瘦金书大观通宝。
- **徽章 / 老照片 / 老票据**：现代收藏品。

## 二、常见作伪手段（鉴宝文高频）

### 瓷器作伪

- **做旧**：茶叶水煮 / 高锰酸钾浸泡 / 微波炉做氧化层。
- **接底**：真底假上。
- **移花接木**：老底 + 新画。
- **化学腐蚀**：模仿出土锈蚀。

### 玉器作伪

- **染色**：高锰酸钾、硝酸铁染古玉皮色。
- **火烧**：模仿古玉受沁。
- **酸蚀**：模仿古玉开窗。
- **粘接**：碎玉粘合伪装整件。

### 书画作伪

- **摹本**：按原作临摹（最高级作伪，专家才能辨）。
- **仿本**：仿风格但自画。
- **代笔**：弟子代笔。
- **著录造假**：虚构流传记录。

### 青铜作伪

- **化学做锈**：盐卤土里埋 / 盐水浸泡。
- **真器后刻铭文**：原件无铭，后刻字值翻倍。

## 三、鉴定方法（可写细节）

### 瓷器

- **胎质**：现代工艺是机器压胎，古代是手工拉胎；真古瓷胎底常不平整。
- **釉色**：古瓷釉色沉稳不浮，仿品常"贼光"。
- **开片**：真宋哥窑金丝铁线自然，仿品过于规整。
- **款识**：年号款字体 / 风格 / 排版都有时代特征。
- **荧光反应**：现代瓷在紫光下有特殊反应。

### 玉

- **手感**：真玉温润沉手；B 货 / C 货轻飘。
- **声音**：真玉敲击清脆；塑料闷。
- **光学**：真玉透光均匀；人工处理显现结构。

### 书画

- **纸质 / 绢**：年代感；熟宣 / 生宣 / 粉笺 / 蜡笺。
- **印章**：印泥年代 / 印文刀法 / 布局。
- **笔墨**：真迹气韵贯通；仿作笔断意不连。
- **题跋 / 收藏印**：流传链条。

## 五、艺术品市场的灰色面（可做情节）

### 洗钱（可提，不写细节）

- 艺术品是常用洗钱载体之一（高价值、估值主观、跨境流通）。
- 常见手法：虚高估值自买自卖 / 境外拍行拉抬 / 以物抵债 / 捐赠逃税。

### 盗墓（**绝对禁区**）

- 可写：盗墓背景 / 被追查 / 后果 / 江湖传说。
- **严禁**：具体盗墓流程、工具、墓葬位置、法律避坑。

### 走私（禁区细节）

- 中国文物出口严格管控，1949 年之前文物原则上不得出境。
- 可写走私背景，不写具体通道。

### 假拍 / 洗画

- 画家 / 画廊 / 拍行三方串通：假拍记录拉价。
- 媒体宣传造势：造典当作品。

## 六、瓷玉书画其他可能场景（鉴宝文常用）

### 捡漏

- 古玩市场 / 旧货摊 / 外地出差。
- 真实度：顶级捡漏在今天极其罕见，但小捡漏仍有。

### 走眼 / 打眼

- 真有钱人也会被骗；吃过亏的才算行家。

### 鉴宝节目

- 《鉴宝》、《华豫之门》、《收藏马未都》、《天下收藏》都是常见背景。

### 师承

- 老一辈收藏家 / 文物局 / 拍行专家 / 博物馆研究员 / 民间高手。

## 七、常见误用

| 误用 | 正确 |
|---|---|
| 让主角一眼看破所有赝品 | 真实鉴宝需要上手 / 看胎 / 看款 / 多维度 |
| 瓷器只看釉色 | 胎 + 釉 + 工 + 款 + 伤残都要看 |
| 把古玩市场写成"宝物遍地" | 现实 95% 是赝品 / 普品 |
| 让富豪随便 "一掷千金" | 真顶级藏家不盲买，需要慢慢养眼 |
| 把盗墓写成"热血冒险" | 盗墓是重罪，必须有严厉后果 |

## 八、小说应用建议

- **古玩开场**：主角捡漏引发连锁冲突。
- **传承信物**：祖传物件揭示身世。
- **真伪博弈**：拍卖场的信息战 / 心理战。
- **洗钱 / 走私**：高层反派的另类敛财。
- **文化情怀**：主角成熟后"回捐"文物。
