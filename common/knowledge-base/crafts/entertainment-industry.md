# 影视圈 / 娱乐圈 / 直播圈

## 定位

都市文主角做大后常进入文化传媒产业，女频言情则大量使用明星、影帝、导演、经纪人设定。本页提供**影视工业流程、娱乐圈权力结构、直播生态的常识级事实**。税务与资本运作见 `finance-business.md`。

## 合规红线（最高）

- 不影射、不丑化**真实在世艺人 / 导演 / 公司**；涉及丑闻一律虚构人物与虚构公司名。
- 真实平台、品牌、奖项名称做**模糊化 / 虚构化**（"某短视频平台""金鹤奖""华耀影视"）。
- 阴阳合同、偷漏税、潜规则可作为**剧情背景概括呈现**，不写可操作的避税步骤，不渲染权色交易细节。
- 艺人涉毒 / 嫖娼 / 逃税是真实违法行为，写虚构角色时必须呈现**法律后果**（参见 `../china/law-enforcement/anti-mafia.md` 与国家红线 checklist）。
- 不写饭圈集资、刷数据、网络暴力的组织教程。

## 影视工业流程（一部戏怎么诞生）

### 开发阶段

- **IP / 原创剧本**：买网文改编权（期限常为 3-5 年），或编剧原创。
- **制片方**：影视公司立项，制片人是项目实际操盘者——找钱、组班子、控周期，权力常大于导演。
- **备案**：剧本梗概需向主管部门备案公示，现代戏、涉案、重大题材审查更严，没过审不能播。
- **拉投资**：主投 + 联合出品，常带预售 / 平台定制（视频网站直接订剧）。

### 拍摄阶段

- **组盘（选角）**：制片人、导演、平台方共同定角；**流量明星能带来预售和招商，所以"带资进组""资本塞人"真实存在**。
- 角色层级：领衔主演（男一女一）→ 主演 → 配角 → 特约 → 群演；番位（署名顺序）是粉丝与团队必争之物。
- **剧组核心职务**：导演、制片人、编剧、摄影指导、美术、灯光、录音、造型；执行层面有统筹、场记、副导演。
- 拍摄周期：电影 1-3 个月，电视剧 3-6 个月；连轴转、大夜戏、两班倒是常态，"剧组是体力活"。
- **杀青**：拍摄结束 ≠ 作品完成，后面还有剪辑、特效、配音、配乐、调色、送审。

### 播出阶段

- 渠道：院线电影（排片说了算）、电视台、爱优腾等视频平台、短视频短剧。
- **定档与撤档**：过审、档期、舆情任一环节都能让戏压箱底，"压播剧"是行业常态风险。
- 分账：票房要先扣专项基金和税，再由院线 / 影院 / 发行 / 出品分；网剧多为平台买断或会员分账。

## 娱乐圈权力与生存结构

### 经纪生态

- 艺人与公司：分成模式（新人公司拿大头，头部艺人反过来抽公司）；合约常 5-10 年，**解约是高频官司**。
- 经纪人 / 执行经纪 / 助理分层；头部艺人有工作室，挂靠大公司。
- 明星收入构成：片酬 / 通告费 + 代言（最赚）+ 商业活动 + 综艺 + 投资。
- **"塌房"机制**：税务、私生活、言论、学历造假任一爆雷 → 品牌方 24 小时内解约索赔、作品下架、账号封禁，沉没成本巨大。品牌合同里都有道德条款。
- 公关行业：声明、撤热搜、买稿、告黑、粉丝控评是一套组合拳；越压越大的反噬也常见。

### 真实的阶层差异

- 顶层：一线明星、名导、头部公司老板，资本与话语权兼具。
- 腰部：有代表作的配角、过气艺人、资深幕后，收入波动大。
- 底层：横漂 / 北漂群演、跟组演员、小编剧、片场民工，日薪百元计、吃了上顿没下顿。
- "**中戏北电上戏**"三大表演院校是重要出身标签；科班、选秀、童星、网红跨界是四条主要入行路径。

### 奖项与节展（小说可虚构）

- 电影类：国内有政府奖、行业奖；国际有欧洲三大电影节等。写小说虚构"金鹤奖""亚洲影展"即可，不套用真实奖项结果编排真人。

## 直播 / 网红生态

### 行业结构

- 平台类型：秀场直播、游戏直播、电商直播、短视频带货、知识 / 户外；机构端是 **MCN**（网红孵化公司）。
- MCN 模式：签约素人 → 培训 → 投流涨粉 → 接广告 / 带货 → 分成；合约坑多，头部网红与 MCN 对簿公堂是常见戏码。
- 变现方式：打赏分成、品牌广告（植入 / 口播）、直播带货佣金 + 坑位费、知识付费、私域引流。

### 带货真实逻辑

- 核心是**供应链**：低价货源、仓配、售后才是壁垒，不是光会喊"321 上链接"。
- 角色分工：主播、副播 / 助播、场控、投手（买流量）、选品、商务。
- 风险点：虚假宣传 / 假货（退一赔三、行政处罚）、刷单造假、数据注水、税务问题（主播补税案真实发生过）。
- 头部主播本质是**渠道商**，一场 GMV 过亿不等于个人赚一个亿，退货率、佣金率、投流成本都要扣。

### 秀场直播生态

- 打赏经济：大哥 / 榜一文化，公会运营主播、刺激消费；现实中有巨额打赏纠纷、未成年人退款。
- 榜一大哥与主播私下关系是都市文常用桥段，但写时注意：诈骗（"乔碧萝"式）真实入刑，要呈现法律边界。

## 饭圈常识（写年轻角色用）

- 基本盘：超话 / 数据站、控评、反黑、轮博、应援、做数据是粉丝日常劳动。
- 粉头、站姐、后援会有实际利益（周边、集资），卷款跑路、互撕、网暴是行业痼疾。
- 平台与品牌把"数据"当热度指标，因此刷榜买粉灰产长期存在，但近年监管持续收紧（"清朗"行动）。
- 写作分寸：把粉丝写成正常人而非极端符号；主角是明星时，与粉丝的关系应是感恩与边界并存。

## 常见误用

| 误用 | 正确 |
|---|---|
| 投资人 / 导演在片场说一不二、随便改剧本 | 平台、制片人、审查多方博弈，导演权限因人而异 |
| 新人撞运气一部戏爆红成顶流 | 有但极少；真实路径是资源、团队、时机、作品叠加 |
| 明星片酬 = 纯收入 | 要扣团队分成、公司抽成、税；阴阳合同是违法行为不是避税技巧 |
| 直播一场赚一个亿 | GMV ≠ 利润，退货、佣金、投流、税层层扣除 |
| 影帝影后天天泡在感情里没工作 | 头部艺人全年无缝进组 / 赶通告，时间极不自由 |
| 剧组拍古代戏演员直接穿古装上街 | 现代剧组拍摄有围挡、通告单、群众演员管理 |
| 被黑后开个发布会就洗白 | 舆情反转周期长、代价大，取决于证据和违法行为是否坐实 |

## 小说应用建议

- **适合的人物**：资本系男主收购影视公司、过气女星翻红线、练习生 / 群演成长线、明星与素人的身份差恋爱、金牌经纪人女主。
- **戏剧冲突**：带资进组抢角、对家黑公关、狗仔偷拍与隐私边界、解约官司、剧组事故责任、直播翻车、MCN 霸王合同。
- **爽点资产**：红毯高光、作品逆袭票房 / 收视率打脸、颁奖礼封后、塌房反杀（靠证据与法律，不靠特权）。
- **虚实处理**：城市虚构化（帝都 / 魔都），公司 / 奖项 / 平台全部虚构；可借"横店"概念写影视城但建议虚构命名。
- **合规收束**：潜规则情节用"拒绝 + 对等强度的事业危机与反击"替代露骨呈现；毒、税、私生活问题必须让虚构角色承担后果。
