# 玄幻 / 仙侠 / 武侠 修炼体系

## 定位

本页汇总中文玄幻 / 仙侠 / 武侠类型中**修炼境界、功法分类、法宝体系、门派结构、丹药谱系、符箓 / 阵法、剑意 / 刀意**等常用骨架，为小说中的功法命名、境界设计、战力分级、门派架构提供可直接套用的清单与误用边界。

真实武学硬上限见 `martial-arts.md`；本页专供**超常设定**（都市玄幻、仙侠、武侠），不与现实武学混淆。

## 合规红线（最高）

- **真实武学硬上限不动**：现实武学 1v3 为上限、徒手对持枪 10 米外必死——这是 `martial-arts.md` 的红线。本页境界只用于"超常题材"，不混用到都市硬核武打。
- **符箓 / 丹药 / 蛊 / 鬼道**：只写文化象征与叙事效果，不写**可操作教程**（炼丹配方、符咒咒文、尸养细节）。
- **宗教敏感**：使用道教真实术语（内丹、金丹、三花聚顶）时不虚构真实在世道士言行；佛教术语（元神、六道）同样处理。
- **玄学迷信免责**：涉及"真实现实中能习得超能力"的桥段，必须让叙事定位在虚构世界。
- **未成年习武 / 修仙**：避免未成年人独自入门邪派、牺牲身体为代价等桥段；需与成年引路人同行。

## 一、仙侠境界骨架（标准七大阶）

当代仙侠文最通用的七大阶骨架：

| 阶 | 俗名 | 内核 | 对应生命周期 |
|---|---|---|---|
| 1 | 练气 / 炼气 | 吐纳聚气入经脉 | 1-30 年 |
| 2 | 筑基 | 周天贯通，奠真元之基 | 30-100 年 |
| 3 | 金丹 / 结丹 | 元气凝核 | 百余年 |
| 4 | 元婴 | 丹破婴生，可脱体 | 数百年 |
| 5 | 化神 / 分神 | 神识出窍，可寄物 | 千年 |
| 6 | 合体 / 炼虚 | 虚实合一，掌小规则 | 千年以上 |
| 7 | 大乘 / 渡劫 | 迎天劫；成仙 | 临劫 |
| ∞ | 飞升 / 真仙 | 脱凡入上界 | 永恒 |

**变体**：每阶可再分初 / 中 / 后期；大阶间常设"瓶颈"或"心魔"。本作如需启用，建议**只用其中一段**（见下文"借鉴策略"）。

## 二、玄幻境界骨架（九转 / 三境 / 十二阶）

### 九转骨架

- **九转玄功**：炼体 / 炼气 / 炼神 / 炼魂 / 炼魄 / 炼意 / 炼道 / 炼虚 / 炼空
- 适合"身体碾压流"，与仙侠纯元气流做区分。

### 三境骨架（当代都市玄幻常用）

| 境 | 内容 |
|---|---|
| 后天 | 俗世武者；徒手对持兵械者有胜算，但对现代枪械无能 |
| 先天 | 内劲外放，可御兵刃；接受冷兵器为主的现代江湖 |
| 宗师 / 大宗师 | 内劲凝实；对现代冷兵器完全碾压；对热兵器仍有限 |
| 武神 / 大圆满 | 本作明确限定不往"刀枪不入"方向走，保留"反应速度 + 短距挪移"作上限 |

### 十重天宫（本作 my-glory 用）

见 `../../novels/my-glory/wiki/terms/十重天宫.md`。本作选用十二段锦 + 十重天宫作为**修行层级标记**而非超常战力，映射训练深度与团队管理层级，严格受 `martial-arts.md` 硬上限约束。

## 三、功法分类

### 按属性

- **炼体类**：身体为宝；代表《九转玄功》《不灭金身》等；对标肉身战斗流。
- **元气类**：吐纳聚气；代表道家内丹传统；适合丹鼎线。
- **神念 / 神识类**：意识为武器；代表《神诀》《元神诀》《无相神功》等；适合情报 / 博弈 / 心战戏。
- **符箓 / 咒语类**：真言为武器；适合"道士线"配角。
- **阵法 / 禁制类**：以阵代战；适合军师 / 智囊线。
- **丹药 / 蛊毒类**：外物为战；适合反派 / 医者双线。
- **剑意 / 刀意 / 拳意类**：意为战；适合单一兵器流主角。
- **身法 / 步法类**：以速取胜；辅助。

### 按阵营气质

- **正道**：清、刚、守；代表功法用"明""清""归""守"等字。
- **邪道**：污、吞、噬；用"吞""噬""邪""魔"字；谨慎——邪派常踩合规红线。
- **中立**：观、游、辩；用"玄""观""游"字。

## 四、门派架构模板（当代玄幻 / 仙侠通用）

### 典型门派层级

| 层级 | 职能 | 规模 |
|---|---|---|
| 掌门 / 宗主 / 教主 | 决策与对外 | 1 |
| 太上长老 | 退居二线的最高辈 | 3-7 |
| 长老 | 分管一堂 / 一峰 | 10-20 |
| 执事 / 真传弟子 | 教学 + 战力 | 30-80 |
| 内门弟子 | 核心培养 | 100-500 |
| 外门弟子 | 杂役 + 预备 | 500-5000 |
| 俗家弟子 / 挂名 | 社会关系网 | 大量 |

### 分堂 / 分峰模式（本作天下会可参考）

- **武堂 / 文堂 / 法堂**：武治 + 文书 + 刑赏
- **情报堂 / 外联堂 / 财堂**：现代化模块
- **七峰 / 九堂 / 十二殿**：中古体裁常用；每个支线有独立功法与色号

## 五、法宝 / 灵器谱系

| 等级 | 俗名 | 定位 |
|---|---|---|
| 凡器 | 普通冷兵 | 江湖日用 |
| 灵器 | 带器灵 | 感应主人 |
| 法器 | 法家之器 | 需灵力驱动 |
| 玄宝 / 宝器 | 名宝 | 一宝压一派 |
| 仙器 / 仙宝 | 神宝 | 稀世 |
| 后天至宝 / 先天灵宝 / 先天至宝 | 开天级 | 大乘以上 |

**命名口诀**：
- 单字 + 器名：**"玄"剑 / "青"刀 / "赤"炎鞭**
- 典故 + 器名：**诛仙剑 / 落日弓 / 太虚镜 / 山海卷**
- 异兽 + 器名：**饕餮刀 / 青鸾剑 / 麒麟角弓**（接 `../china/philosophy/shanhaijing.md`）

## 六、丹药 / 符箓 / 阵法（合规层）

### 丹药谱系

- **一品 → 九品**（低→高）或 **凡品 / 下品 / 中品 / 上品 / 极品 / 仙品**
- 命名：**续命丹 / 培元丹 / 洗髓丹 / 破障丹 / 金丹**
- 本作应用：接 `../../novels/my-glory/wiki/terms/一级药剂.md` 的现代合规版——写效果与副作用不写配方。

### 符箓 / 咒语

- 符的类型：**治愈 / 攻击 / 禁锢 / 隐身 / 通讯 / 招魂**
- 写作分寸：**只写外形 + 使用场景 + 心法关键字**，禁写咒文全文、画符顺序。

### 阵法

- 常见名：**诛仙 / 周天 / 八门 / 九宫 / 太极 / 两仪**
- 组合要素：阵眼 / 阵旗 / 阵核 / 阵种
- 适合军师线使用；本作贺九思的"情报堂"可用阵法做场景化道具。

## 七、剑意 / 刀意 / 拳意（武侠内劲系）

- **意**不是具体招式，是人格 + 情境的凝结：**孤剑意 / 怒刀意 / 守拳意 / 游龙意**
- 真正高手"**剑无需出鞘**"是武侠传统写法；本作如引入，限 S4 后期以隐喻方式使用。

## 八、与真实武学的边界

| 场景 | 允许做法 | 禁止做法 |
|---|---|---|
| 都市硬核武打（本作 S1-S3） | 使用 `martial-arts.md` 硬上限；1v3 现实边界；伤势按 `medicine-pharmacology.md` 周期 | 一人打一百、刀枪不入、徒手挡枪 |
| 都市玄幻（本作 S4 神龙线） | 可用十二段锦、一级药剂、十重天宫作为**层级隐喻**，强调训练深度与极限反应 | 不写超常"御空"、"隔山打牛"、"隔空取物" |
| 门阀仪式（本作 S5-S6 五家议会） | 可用家族家训级的"心法"隐喻（如"北辰心法"），作为人格象征 | 不以"修仙战力"决定议会胜负；议会靠规则 / 票 / 事实 |

## 九、小说应用建议（对本仓 my-glory 的直接参考）

### 本作功法 / 境界命名候选

- **十二段锦**（已启用）：取道家十二段动功真实依据；作为呼吸 / 恢复 / 身体控制。
- **北辰心法**（候选）：取《论语·为政》"北辰居其所而众星共之"；主角专属心法，象征"居中"而非"攻伐"。
- **五藏引**（候选）：取山海经"五藏山经"命名；对应五大家族五种家训身法（顾 / 霍 / 裴 / 秦 / 韩 各一种）。
- **破军势 / 贪狼步 / 七杀式**（候选）：取紫微斗数杀破狼三星；对应主角三位核心兄弟（破军=军师 / 贪狼=锋锐 / 七杀=断情）。
- **烛阴九转**（候选）：山海经"烛阴"；主角长线功法进阶的九个阶段。
- **白泽图经**（候选）：山海经"白泽"；情报堂贺九思的识物 / 博物心法。

### 本作门派架构参考

- 天下会的"武堂 / 情报堂 / 财堂 / 外联堂"模板已成形；可加"法堂（刑赏）"与"外务堂（跨城）"。
- 五家议会 vs 天下会的关系是**门阀议会 vs 江湖组织**，仿东汉"士族 vs 游侠"的张力。

### 本作战力对标（硬上限不破）

| 阶段 | 对应真实武学定位 | 严格禁区 |
|---|---|---|
| S1-S3 | 街头 / 江湖打手级，徒手 1v3 为上限 | 不描写内功外放 / 刀枪不入 |
| S4 神龙 | 特种兵 + 道家导引，极限反应速度 + 短距爆发 | 不描写御空 / 隔山打牛 |
| S5-S6 门阀 | 议会靠规则而非武力决胜 | 不以"修为高低"定输赢 |

## 十、常见误用

| 误用 | 正确 |
|---|---|
| 都市文主角"筑基"后一人打一百 | 都市硬核受真实武学硬上限约束；不借用仙侠境界 |
| 把道教真实内丹术语当"可操作教程" | 只用象征意味，不写呼吸 / 坐姿 / 咒文全文 |
| 现代主角"炼气化神"后变飞 | 现代都市玄幻的"飞"要有机械 / 载具解释，不能纯粹御空 |
| 让所有角色都有境界 | 境界只给**超常题材**；都市硬核保留"训练深度 + 极限反应"即可 |
| 门派层级无差异 | 不同门派必须有独特"色号"（主色、信物、口头禅、禁忌） |
| 乱用邪派 / 蛊毒 | 邪派必写代价与后果；蛊毒不写配方 |
| 把真实在世武术家写进境界体系 | 真实在世人物不虚构其武学境界 |
