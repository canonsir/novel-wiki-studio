# 医疗行业 / 医院体系 / 医保医患

## 定位

医疗题材与"医生女主 / 主任男主 / 主角住院结识贵人"是都市、言情文高频设定。本页讲**医院等级、职称晋升、科室生态、医保制度、医患关系**等行业运行常识；伤病、急救、药理的技术细节见 `medicine-pharmacology.md`。

## 合规红线（最高）

- 不写可操作的**处方药用法、剂量、毒麻药获取**细节；不写骗保、挂证、医疗废物倒卖的操作流程。
- 真实医院、药企、医学院名称一律虚构化（"帝都协和"式半实名也不建议，用虚构名如"华济医院"）。
- 医患矛盾不渲染、不煽动对立；**医闹、伤医是违法行为**，虚构情节须呈现法律后果。
- 医生角色的救治行为要符合诊疗规范，不渲染"神医一针起死回生"；绝症不靠玄学 / 偏方治愈。
- 涉及传染病、公共卫生事件时，与公开的国家防控口径一致，不造谣不恐慌营销。

## 医院等级体系

### 分级

- **三级**：三级特等（极少）、三级甲等（三甲，最高最常写）、三级乙等、三级丙等。
- **二级**：二甲、二乙等，多为区县 / 市级医院。
- **一级**：社区卫生服务中心、乡镇卫生院。
- 评级看床位、科室、设备、科研、教学能力；**三甲集中了最好的资源，也最忙**。

### 医院类型

- 公立医院（部属 / 省属 / 市属 / 大学附属医院）、军队医院、民营医院（莆田系是真实的负面典型，写作虚构化）、专科医院（儿童、妇产、肿瘤、眼科、口腔、精神）。
- 大学附属医院的医生同时有**教师职称**（副教授 / 教授），医教研三条线并行。
- **医联体 / 分级诊疗**：小病社区、大病转三甲、康复回基层；双向转诊是政策方向。

## 医生职称与晋升（职业线骨架）

| 职称 | 大致年限 | 状态 |
|---|---|---|
| 住院医师 | 毕业后 0-5 年 | 规培 + 管床，最苦最底层 |
| 主治医师 | 聘任后 | 能独立带组处理常规病例 |
| 副主任医师 | 晋升后 | 副高，专家门诊门槛 |
| 主任医师 | 晋升后 | 正高，科室顶层 |

- **学历门槛**：三甲热门科室普遍要求博士；地市级本科 / 硕士仍有空间；学历天花板真实存在。
- **规培（住院医师规范化培训）**：本科 / 硕士毕业要"5+3"等规培 3 年，**规培医生是医院最廉价劳动力**：值夜班、写病历、拉钩、跑腿，收入低、强度大、猝死新闻时有发生。
- 晋升硬指标：**论文 / 科研课题 + 临床年限 + 手术量 + 职称考试 + 名额**；"唯论文"问题在改革但仍关键，外科还看谁能上大手术。
- 外科晋升更看**主刀机会**，机会掌握在主任手里，因此科室内部争手术、争课题、站队是真实生态。

## 科室生态

### 主要科室速览

| 科室 | 特点 | 小说气质 |
|---|---|---|
| 急诊 | 三班倒、节奏最快、什么都接、冲突高发 | 高压、见生死、成长快 |
| ICU | 危重监护、仪器密集、与家属谈生死 | 压抑、技术流、伦理困境 |
| 外科（普外 / 骨科 / 神外 / 心外） | 手术为王，手术时长 4-10 小时 | 师徒制、体力活、成就感强 |
| 内科（心内 / 呼吸 / 消化 / 肾内） | 诊断逻辑 + 用药 + 慢病管理 | 推理感、慢功夫 |
| 妇产科 | 夜班忙、急症多、纠纷多 | 生死并置、情绪浓度高 |
| 儿科 | 哑科（孩子不会描述病情）、家属焦虑、收入低 | 高压高冲突 |
| 麻醉科 | "手术室内的内科医生"，管生命体征，常被忽视 | 隐形主角、关键反转位 |
| 肿瘤科 | 预后差、临终决策多 | 伦理与人性深度 |
| 精神心理科 | 病耻感、诊断主观 | 悬疑 / 治愈题材富矿 |

### 院内权力结构

- **科室主任（一把刀）**：科室绝对核心，定手术分配、课题、人事。
- 院长 / 业务副院长 / 医务处 / 护理部；护士线：护士 → 护师 → 主管护师 → 护士长。
- 辅助科室：检验、影像（放射 / CT / MRI）、超声、病理——**病理是"医生的医生"，诊断金标准**，常被外行忽略，适合埋反转。

## 医院日常细节（可直接入文）

- 白大褂口袋标配：笔（常被顺走）、便签、小手电、听诊器；外科医生站姿挺拔、多数有腰肌 / 颈椎问题。
- 交班：晨交班念夜班危重病人 → 查房（主任带头，一屋子人，住院医背病情）→ 开医嘱 → 手术 / 门诊。
- 门诊：一上午看 40-80 个号，分给每个病人几分钟，**不是医生冷漠，是资源密度决定的**。
- 值夜班：连轴 30+ 小时是常态（"住院医"名字由来），凌晨最容易来急症；术后病人半夜病情变化是高频剧情点。
- 饮食靠外卖和值班室泡面，手术日吃不上饭；洗手要刷到肘上，进手术室层层更衣。
- 谈话签字：术前 / 病危 / 输血 / 特殊检查都要**知情同意书**，医生逐条讲风险，家属的笔往往比刀还重。

## 医保制度（行业线必备常识）

- 基本医保：**职工医保**（上班族，单位 + 个人缴）和**居民医保**（城乡居民、学生、老人）。
- 报销有**起付线、报销比例、封顶线**；目录分甲类（全纳入）、乙类（自付一部分）、丙类（自费，多数进口靶向药 / 新疗法在此）。
- 异地就医需备案；门诊、住院、大病保险、医疗救助分层报销。
- **DRG / DIP 付费改革**：医保按"病种"打包付给医院，超支医院承担——因此会出现"控制均次费用""赶出院"现象，是真实的政策驱动矛盾。
- 常见违法（禁写操作，可写查处）：**骗保**（虚构住院、挂床、串换药品）入刑；医生收**红包 / 回扣**是非国家工作人员受贿 / 受贿，医药反腐持续高压。

## 医患关系（分寸极重要）

### 真实的矛盾来源

- 信息不对称：医学术语 vs 家属的朴素预期；坏消息传达是专门技术。
- 资源紧张：排队、床位、等待造成的情绪积累。
- 费用压力：一场大病拖垮一个家庭是真实存在的社会痛点。
- 预期落差："进了医院就该治好" vs 医学有边界——**多数疾病医生是安慰、帮助，少数才能治愈**。

### 写作分寸

- 医闹 / 职业医闹入刑（聚众扰乱社会秩序、敲诈勒索），不能被写成"维权英雄"。
- 伤医必受法律严惩，不作为戏剧爽点；可以写冲突的发生与**制度性化解**（医务处、调解、诉讼、鉴定）。
- 医疗事故处理路径：**病历封存 → 医疗损害鉴定 → 调解 / 诉讼 → 责任划分**，不是拉横幅解决。
- 好的医疗戏写"共同的敌人是疾病"：医生与家属从误解到并肩，比对立更动人。

## 常见误用

| 误用 | 正确 |
|---|---|
| 白大褂敞开穿、上班浓妆高跟鞋、手术室说说笑笑 | 院内有严格着装与无菌规范，手术室帽子口罩遮全 |
| 实习生 / 规培生主刀大手术 | 手术权限按职称和授权分级，新手只能拉钩、扶镜、做助手 |
| 主任天天坐办公室看 X 光片谈恋爱 | 临床主任要查房、门诊、手术、教学、科研，时间极满 |
| 看一眼就确诊罕见病 | 真实诊断靠病史 + 查体 + 检验影像病理，层层排除 |
| 家属说"用最好的药不怕花钱"就能救命 | 药有适应症和禁忌，最好 ≠ 最合适；还受医保目录限制 |
| 病人术后三天活蹦乱跳出院 | 恢复周期见 `medicine-pharmacology.md`，大手术以周 / 月计 |
| 医保全额报销天价治疗费 | 起付线 / 比例 / 封顶 / 目录外自费，大病仍可致贫 |
| 医生随手开止痛药 / 抗生素 | 毒麻精放药品红处方专管，抗生素分级管理，严禁滥用 |
| 护士就是打针的配角 | 护理有独立专业体系，术后观察、抢救中护士常是第一发现人 |

## 小说应用建议

- **适合的人物**：急诊 / 外科女医生（专业强、情感钝）、规培期成长线、海归专家 vs 本土体系、医药代表（灰色视角）、院长公子下基层。
- **戏剧冲突**：疑难病例确诊（医学推理）、抢救与生死、手术台上的意外、论文 / 课题之争、医闹与舆情、医保控费下的两难、医药反腐站队。
- **情感线抓手**：并肩抢救的信任、值班室的深夜、对职业耗竭（burnout）的互相托住；避免"病人当僚机"式消费苦难。
- **爽点资产**：高难度手术成功、误诊翻案、学术会议打脸、规范行医熬出头；让高光**建立在专业与协作**上。
- **伦理富矿**：知情同意、抢救无力支付者、临终抢救到什么程度、罕见病无药可医——呈现两难，不给廉价答案。
- **合规收束**：红包回扣情节写成被拒绝或被查处；偏方 / 神医不能成为解决方案；医院与药企全部虚构命名。
