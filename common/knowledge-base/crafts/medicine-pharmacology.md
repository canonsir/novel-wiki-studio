# 医学 / 药理（常识级准确）

## 定位

小说中的"受伤 / 中毒 / 急救 / 慢性病"必须符合医学常识。本页提供**可写的常识级细节**与**禁区**。

## 创伤医学（最常用）

### 失血与休克

| 失血量 | 症状 |
|---|---|
| < 500 ml | 可自愈 |
| 500-1000 ml | 面色苍白、心率加快、口渴 |
| 1000-2000 ml | 休克前期：意识模糊、冷汗、血压下降 |
| 2000+ ml | 休克：昏迷、死亡风险极高 |

**写作要点**：角色重伤后不要立刻说话流利，要有口渴 / 寒冷 / 眼前发黑的生理反应。

### 骨折

- **闭合性**：皮肤完整，骨头断裂。愈合 4-8 周。
- **开放性**：骨头穿破皮肤，感染风险高，必须立刻处理。
- **粉碎性**：骨头多段断裂，3-6 月恢复。
- 石膏固定 → 功能锻炼 → 恢复。

### 枪伤（见 `weapons.md` 弹道章）

### 刀伤

- **浅表伤**：缝合 + 包扎，7-10 天愈合。
- **深层伤 / 肌肉**：缝合 + 抗感染，2-4 周。
- **血管伤**：止血 → 血管吻合 → 功能恢复。
- **内脏穿透**：开腹探查，必须急诊手术。

### 脑外伤

- **轻度脑震荡**：短暂失忆 + 头痛，24 小时观察。
- **中度**：意识丧失数分钟到数小时。
- **重度（颅内出血）**：昏迷 + 瞳孔异常 + 需要开颅。

## 急救（可写细节）

### 心肺复苏（CPR）

- 胸外按压：30 次 + 人工呼吸 2 次为一组。
- 按压深度 5-6 cm，频率 100-120 次/分。
- 持续至专业救援到达或自主心跳恢复。

### 止血

- **直接压迫**：最有效，持续 10-20 分钟。
- **止血带**：必须记录绑扎时间，每 30 分钟放松一次。
- **冷敷**：减少皮下出血。

### 气道梗阻（海姆立克）

- 从背后环抱腹部，向上冲击式按压。

## 中毒（合规高度敏感）

### 写作红线

- **严禁**具体毒物名称 + 剂量 + 来源 + 施用方法的完整链条。
- 可以写**结果**（中毒后的症状），不写**配方**。

### 常见小说用情节（合规版）

- **安眠药**：泛指"镇静剂"，不写具体药名。
- **一氧化碳**：可以写（常识），但不写具体气量。
- **食物中毒**：泛指"吃了不干净的东西"。
- **传统药物**：可提"民间草药"但不写配方。

### 症状（可写）

- **急性中毒**：恶心 / 呕吐 / 腹泻 / 瞳孔变化 / 昏迷。
- **慢性中毒**：面色异常 / 乏力 / 慢性头痛 / 不明脏器衰竭。

## 慢性病（给人物背景加厚度）

### 常见设定

| 疾病 | 戏剧用途 |
|---|---|
| 心脏病 | 老年人物随时倒下的悬念 |
| 糖尿病 | 需要定时服药 / 注射胰岛素 |
| 胃癌 / 肝癌 | 中年人物不告诉家人的秘密 |
| 肺结核（旧时代）| 民国题材的经典病 |
| 肺病（现代） | 环境污染 / 老员工伤病 |
| 抑郁症 | 现代都市人物心理线 |
| 创伤后应激（PTSD）| 退伍军人 / 江湖老人 |

**写作要点**：慢性病应影响角色**日常行为**（饮食限制、避光、情绪波动），不只是"随时死"的工具。

## 药物（泛化即可，不写具体品牌）

### 可写的"模糊类"

- **抗生素** / **消炎药** / **止痛药** / **退烧药** / **抗焦虑药**。
- 急救常用：**肾上腺素**（心脏停跳）、**阿托品**（心率过慢）、**纳洛酮**（阿片中毒）。

### 禁写

- 具体毒物配方 / 麻醉药品剂量 / 精神科药物滥用方法 / 毒品制作。

## 医院场景（供真实化）

### 分级

- **三甲医院**：顶级，综合科齐全。
- **二甲**：市级，常见病。
- **乡镇卫生院**：基层，急救能力有限。

### 急诊流程

```
分诊 → 挂号 → 诊室 → 检查（抽血 / CT / X 光） → 处置（手术 / 输液 / 观察） → 出院 / 住院
```

### 相关人员

- **急诊医生**：全科，快速判断。
- **外科医生**：手术主刀。
- **麻醉师**：手术必需。
- **护士长 / 护士**：日常护理。
- **药房 / 影像 / 化验室**：辅助部门。

## 常见误用

| 误用 | 正确 |
|---|---|
| 中弹后"没事"几天后出血死 | 内出血 / 感染可延迟致命，但有过程 |
| 任意从医院"偷药" | 处方药有管控，必须有情节合理性 |
| 普通人学会 CPR 立刻救活 | CPR 存活率 10% 左右，需要配合除颤 |
| 麻醉药一按就睡 | 真实麻醉需要几分钟且无痛苦挣扎 |
| 中毒后立刻解毒 | 多数毒物无专门解毒剂，支持治疗为主 |

## 对主角受伤曲线的建议

- **S1-S2**：轻伤为主，恢复 1-3 周。
- **S3**：第一次重伤（刀伤 / 枪擦伤），恢复 1-2 月。
- **S4-S5**：严重伤（粉碎性骨折 / 枪贯穿），恢复 3-6 月。
- **S6**：接近死亡的大伤，恢复期可留永久性后遗症（跛 / 疤 / 慢性痛）。
