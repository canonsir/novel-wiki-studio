# 武学 / 徒手格斗（硬设定）

## 定位

本页规定**小说武力值的硬上限**。Author 和 Continuity Agent 发现角色能力超出本页约束时，必须给出明确虚构世界观依据（如修真 / 异能），否则必须回退到本页标准。

## 现实能力上限

### 徒手单挑

| 能力 | 现实数据 | 小说可做 |
|---|---|---|
| 一拳爆发力 | 职业重拳约 500-800 kgf | 可写一拳打断对方骨头，不可写打飞 2 米 |
| 连续作战 | 高强度 3-5 分钟后体能大幅下降 | 一场戏最多 3-5 分钟高强度，之后气喘 |
| 耐痛 | 中拳数十次仍可战，但头部重击可能瞬间 KO | 可写耐打角色，但头部中招有晕眩风险 |
| 1v 多 | 职业拳手不超过 1v3 散兵 | 可写 1v5 但必须依靠地形 / 偷袭 / 器械 |

### 徒手对冷兵器

| 场景 | 现实 | 小说可做 |
|---|---|---|
| 徒手对单刀 | 必败 90% | 可写用环境物件 / 临场抓取反制 |
| 徒手对双持 | 必败 99% | 必须有外部变量（人 / 环境） |
| 徒手对棍 | 距离控制可胜 | 近身抢位可写胜 |

### 徒手对火器

| 距离 | 现实 | 小说可做 |
|---|---|---|
| 0-3 米 | 突袭有机会（技术上可行） | 可写一次性成功 |
| 3-10 米 | 几乎必死 | 不可直接硬刚 |
| 10+ 米 | 必死 | 必须用掩体 / 距离 |

### 跳跃 / 奔跑

| 动作 | 现实上限 | 小说极限 |
|---|---|---|
| 立定跳远 | 3 米 | 可写 3.5 米 |
| 立定跳高 | 1.3-1.5 米 | 可写 1.8 米 |
| 短跑 100 米 | 10 秒级（职业） / 13 秒级（普通健儿） | 可写 11-13 秒 |
| 翻墙 | 2 米墙可徒手翻越 | 可写 2.5 米 |
| 高空落地 | 2 米可缓冲落地，4 米重伤风险 | 可写 3 米落地无伤但有后续代价 |

## 恢复周期（关键）

| 伤势 | 恢复时间 | 戏剧用途 |
|---|---|---|
| 擦伤 / 淤青 | 3-7 天 | 当天可继续战斗 |
| 挫伤 / 轻微裂伤 | 1-2 周 | 影响下一场戏 |
| 骨折（非粉碎） | 4-8 周 | 必须有养伤线 |
| 骨折（粉碎） | 3-6 月 | 大线暂停 |
| 内脏挫伤 | 2-6 月 | 必须有医疗线 |
| 枪伤（擦过） | 2-4 周 | 当章可能昏倒 |
| 枪伤（贯穿非要害） | 1-3 月 | 完全线暂停 |
| 枪伤（要害） | 死亡 60-80% / 救活后 3-6 月 | 戏剧性最大 |

**严禁违反：** 骨折当天继续追逐、枪伤第二天就"没事了"、重伤三天恢复。

## 门派特色（可挂的真实流派）

见 `../china/jianghu/martial-schools.md`，但在**可写能力**上必须以本页上限为准。

### 分配建议（避免"同质化武力"）

| 角色类型 | 建议背景 | 不建议 |
|---|---|---|
| 主角初期 | 街头 + 散打 + 临场 | 开局就"内家传人" |
| 主角成熟期 | 融合多派（散打 + 泰拳 + 咏春短打） | 单一门派被更强门派碾压 |
| 师父角色 | 内家派（太极 / 形意 / 八极） | 普通技术员 |
| 杀手型反派 | 军警出身 + 现代格斗 | 江湖门派 |
| 保镖型 | 八极 / 散打 + 实战经验 | 空谈套路 |

## 器械

### 短兵（刀匕首）

- **匕首**：15-25 cm，近身刺砍，常用。
- **军刺 / 三棱刺**：穿透力强，军警常用。
- **折刀 / 蝴蝶刀**：便携，街头常见。
- **大刀 / 砍刀**：帮派械斗标配，威慑强。

### 长兵（棍 / 枪）

- **棍**：三节棍、单棍、双节棍。
- **枪 / 长矛**：现代少见，古风场景用。

### 软兵

- **链子 / 鞭 / 流星锤**：训练难度高，现实使用少。

### 暗器

- **飞镖 / 飞针**：古装可用，现代罕见。
- **弹弓**：乡村少年合理，成人暗器戏少。

## 常见误用

| 误用 | 正确 |
|---|---|
| 武力值无穷递增 | 必须设天花板和代价 |
| 老师父能超越年轻顶级运动员 | 经验在，体能不在；真实 60+ 岁顶级武术家对抗 25 岁职业选手劣势 |
| "内力"隔山打牛 | 现代武学无此现象，若写必须明确为虚构世界观 |
| 一招制胜（电影化） | 真实格斗是连续数十次攻防 |
| 轻松击败特种兵 | 特种兵有系统训练 + 实战经验，必须用智谋 / 偷袭 |

## 对主角武力曲线的硬建议

- **S1-S2 街头期**：职业业余格斗水平，可赢 1v2，被 1v3 虐。
- **S3 组织期**：开始接触高手，赢在布局而非徒手。
- **S4-S5 跨城期**：被更强对手压制，靠团队 / 智谋。
- **S6 终局期**：个人武力接近现实顶级，但胜负靠全局谋划。
