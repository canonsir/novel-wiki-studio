# 金融 / 商业（含灰色地带）

## 定位

小说中主角做大后，必然进入"商业 + 灰色金融"的层面。本页提供**可写的常识级商业事实**与**灰色金融的真实边界**。

## 合法商业结构

### 公司形式

- **个体工商户**：街边小店。
- **有限责任公司**：最常见。
- **股份有限公司**：可上市。
- **合伙企业**：合伙人连带责任。
- **外商独资**：WFOE。
- **中外合资**：JV。

### 实控结构（主角做大常用）

- **代持**：别人工商登记，实际控制人是主角。常用，但有法律风险（股权争议）。
- **多层股权**：境内公司→香港公司→开曼公司→BVI，常用于"隐藏实控人"。
- **VIE 架构**：互联网公司常用的"协议控制"结构。
- **信托 / 家族办公室**：顶级富豪的资产隔离。

### 工商登记（可用于情节）

- **国家企业信用信息公示系统**：公开可查。
- 法人代表、股东、注册资本、经营范围、变更记录。
- 现实中查公司底细就靠这个。

## 灰色金融（真实存在，写作边界清晰）

### 民间借贷

- **月息 1-3%** 是合法范围。
- **月息 3% 以上**：可能被认定高利贷。
- **月息 10% 以上**：高利转贷罪 / 非法经营罪。
- **暴力催收**：催收罪（刑法 293 条）。

### 洗钱常见手法（禁写具体步骤）

- 可**提及**："把钱洗白"、"过账"、"做流水"。
- 不可**写**：具体步骤 / 账户设计 / 跨境路径。

### 走私（禁写细节）

- 可**提及**：电子烟 / 化妆品 / 香烟 / 奢侈品走私。
- 不可**写**：具体通道 / 船只 / 关口 / 行贿对象。

### 赌博（高度敏感）

- 赌博罪 / 开设赌场罪（刑法 303 条）。
- 可**提及**：地下赌场 / 棋牌室 / 境外赌场。
- 不可**写**：具体规则 / 诈骗手法 / 组织层级。

### 高利贷 / 套路贷

- 套路贷：形式合法、实质放高利贷的 "pay day loan" 变种。
- 典型手法（可**概括提及**，不细写）：
  - 签空白合同
  - 制造虚假流水
  - 平账转债务
  - 暴力催收

## 真实公司常见业务（主角可做）

### 合法扩张路径

| 阶段 | 行业 | 现实对应 |
|---|---|---|
| S1-S2 | 餐饮 / 酒吧 / 歌厅 / 洗浴 | 现金流大、监管相对松 |
| S3 | KTV / 夜店 / 建材 / 物流 / 运输 | 大本营 + 遮羞 |
| S4 | 房地产 / 工程 / 文旅 / 保安 | 规模化但政商关联 |
| S5-S6 | 金融 / 跨境 / 文化传媒 / 互联网 | 资本层级 |

### 真实关联场景

- **政商关系**：局长 / 书记 / 副市长的审批。
- **银行**：授信 / 贷款 / 承兑汇票。
- **投行 / PE**：中后期融资。
- **律所 / 会计师事务所**：顾问。
- **公关公司**：媒体与形象。

## 税务 / 合规（可写细节）

### 偷税漏税

- 偷逃税罪：刑法 201 条，5 年以下。
- 虚开增值税发票罪：刑法 205 条，最高死刑（已改无期）。
- 阴阳合同：常见偷税手法，涉及明星 / 大 V。

### 合规风险（主角成熟后要面对）

- 税务稽查：企业做大后高频事件。
- 反洗钱申报：银行对大额可疑交易要报人民银行。
- 反垄断：行业龙头的新门槛。

## 商业礼节（都市文可用）

### 商务宴请

- **接待层级对等**：对方来副总，我方也派副总。
- **座次**：主位 / 副主位 / 陪客，与江湖礼节类似。
- **酒文化**：敬酒 / 回敬 / 挡酒 / 替酒，重要场合必有。
- **茶文化**：高端场合用茶替酒。

### 送礼

- **可写**：茶叶 / 字画 / 名表 / 高端白酒。
- **禁区**：具体贿赂金额、给具体真实人物。
- **规矩**：现金装购物袋 / 工艺品底座暗槽 / 境外卡。

## 常见误用

| 误用 | 正确 |
|---|---|
| 主角上来就"投资 10 亿" | 商业有逐级积累，一夜十亿不真实 |
| 洗钱像"按一下按钮" | 洗钱需要跨机构 / 跨境 / 多层节点 |
| 代持无风险 | 代持常引发争议，须有法律文件 |
| 商业战全靠运气 | 商业战是信息 + 资源 + 规则 + 法律的综合 |

## 对主角商业线的建议

- **真实的积累速度**：第一桶金 → 第一家公司 → 第一个行业 → 跨行业 → 资本运作，每一级至少一卷。
- **政商博弈**：政策是最大变量，不能忽略。
- **司法风险**：越做大越容易被盯上，是合理的外部压力。
- **合法化焦虑**：灰色起家的人物面对"洗白"是终局大问题。
