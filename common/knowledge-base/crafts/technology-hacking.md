# 现代科技 / 黑客 / 网络安全

## 定位

都市文 / 悬疑文 / 科幻文中的"技术戏"。本页规定**可写的现代科技常识**与**不可写的具体攻击链**。黑客能力过度魔化会让懂行读者立刻弃书。

## 合规红线（最高）

### 严禁写入

- 具体漏洞利用代码 / 攻击 payload / 恶意软件配方。
- 具体密码破解流程（如：具体彩虹表构造 / 字典攻击参数）。
- 具体入侵真实系统的步骤（银行 / 政务 / 医院 / 公安）。
- 制造实体武器 / 爆炸物 / 毒物的 3D 打印参数。
- 真实目标（具体公司 / 真实服务器 / 真实 IP）。

### 可以写

- 技术**概念、术语、常识**（如 SQL 注入是什么、XSS 是什么）。
- 黑客**行为的后果**（信息被盗 / 系统瘫痪 / 遭溯源）。
- 攻防戏的**心理张力**（时间紧迫 / 门槛心理 / 侦查压力）。
- 虚构场景中的"虚构漏洞"。

## 一、现代科技常识（可引用）

### 智能手机

- **操作系统**：iOS / 鸿蒙 / Android 三大体系。
- **常见品牌**：iPhone / 华为 / 小米 / OPPO / vivo / 荣耀。
- **信号追踪**：手机信号基站定位（精度 50-500 米）、GPS 定位（精度 5-10 米）、WiFi 探针。
- **真实能力**：
  - 公安通过运营商可直接拿到基站位置数据（需审批）。
  - 普通人无法"远程追踪"任意手机。
  - 手机关机≠无法定位（电池未取掉仍可被动追踪）。
- **写作细节**：真实警察办案需要走流程，不能"手机号一输定位到人"。

### 社交媒体

- **主流**：微信 / 微博 / 抖音 / 小红书 / B 站 / 快手 / 知乎。
- **跨境**：Facebook / Instagram / X（Twitter）/ TikTok / YouTube。
- **即时通信**：微信 / QQ / 钉钉 / 飞书 / Telegram / Signal / WhatsApp。
- **写作提示**：
  - 用户隐私信息（手机号 / 身份证 / 位置）需要通过平台和公安配合才能查到。
  - 社交数据的"大数据画像"是真实存在但需要专业工具。

### 支付与金融科技

- **支付宝 / 微信支付 / 云闪付**：电子支付三巨头。
- **银行转账**：实时到账或 T+1。
- **流水追踪**：公安 / 税务 / 反洗钱可查，但需程序。
- **加密货币**：比特币 / 以太坊 / USDT 等；交易所：币安 / OKX / 火币。
- **洗钱**：加密货币 / 虚拟资产 / 跨境电汇是常见渠道（可提不细写）。

### 云 / 大数据

- 云厂商：阿里云 / 腾讯云 / 华为云 / AWS / Azure / Google Cloud。
- 大数据应用：精准广告 / 风控 / 用户画像 / 智慧城市。

### AI

- **大语言模型**：ChatGPT / 文心 / 通义 / 豆包 / Claude / Gemini / DeepSeek。
- **AI 绘画**：Midjourney / Stable Diffusion / 文生图。
- **AI 语音 / 换脸 / Deepfake**（**合规警示**）：
  - 真实存在，但用于诈骗属违法行为。
  - 可写"诈骗分子用 AI 换脸冒充亲友"情节，但不写具体工具链。

## 二、常见黑客类型（人物设定）

### White Hat（白帽）

- 为企业做渗透测试、漏洞挖掘。
- 合法职业，年薪 50-200 万。
- 常见背景：计算机科班 / CTF 比赛冠军 / 大厂安全团队。

### Black Hat（黑帽）

- 非法攻击、勒索、盗取数据。
- 真实后果：3-10 年刑期（刑法 285-287 条）。
- 常见活动：勒索软件 / 数据盗取 / APT 攻击。

### Grey Hat（灰帽）

- 游走灰色地带，发现漏洞后勒索企业"修复费"。

### 国家级 APT 组织

- Advanced Persistent Threat，有国家背景的长期渗透组织。
- 现实知名：Lazarus（朝鲜）、APT28（俄罗斯）、APT41（有报道称中国背景）等。
- **写作禁区**：不虚构具体国家 APT 的具体行动。

### Script Kiddie（脚本小子）

- 下载工具就能攻击的小白，99% 攻击者属于此。

## 三、常见攻击类型（概念级，不写细节）

| 攻击类型 | 概念 | 可写的情节 |
|---|---|---|
| SQL 注入 | 利用网站数据库漏洞 | 主角网站被攻破 |
| XSS | 跨站脚本 | 浏览器中招 |
| 钓鱼（Phishing）| 假冒邮件 / 短信 / 网站 | 受害者被骗 |
| 勒索软件 | 加密受害者数据勒索 | 公司瘫痪 |
| DDoS | 大流量瘫痪服务 | 竞争对手被攻击 |
| 社会工程 | 利用人性弱点骗取信息 | 伪装快递员套话 |
| 木马 / 后门 | 控制目标主机 | 被监视 |
| 中间人 | 拦截通信 | 偷听 |
| 零日漏洞 | 未公开漏洞 | 顶级黑客的武器 |

**原则**：所有攻击可以"**提及类型 + 结果**"，不写**具体步骤**。

## 四、防御与反制（可写细节）

### 企业防御

- 防火墙 / IDS / IPS / SIEM / EDR / WAF。
- 零信任架构、多因素认证（MFA）。
- 应急响应（Incident Response）流程。

### 个人防御

- 强密码 + 密码管理器（1Password / Bitwarden）。
- 不点可疑链接、不下不明附件。
- 开启两步验证。
- 定期备份。
- VPN（**慎用，中国境内未经批准使用国外 VPN 违法**）。

### 溯源

- IP 定位（但可用 VPN / 代理混淆）。
- 流量指纹分析。
- 恶意代码特征。
- OSINT（公开信息搜集）。

## 五、涉及现实法律的部分

### 《中华人民共和国网络安全法》

- 保护关键信息基础设施。
- 个人信息保护。
- 禁止提供黑客工具。
- 禁止从事网络攻击。

### 《中华人民共和国数据安全法》

- 数据分级分类保护。
- 跨境数据流动管制。

### 《中华人民共和国个人信息保护法》

- 2021 施行，中国的 GDPR。
- 严格限制个人信息收集 / 处理 / 跨境传输。

### 刑法涉及条款

- 285 条：非法侵入计算机信息系统罪 / 非法获取计算机信息系统数据罪。
- 286 条：破坏计算机信息系统罪。
- 287 条：利用计算机实施犯罪的其他罪。

## 六、常见黑客情节（可用模板）

### 1. 被追踪

- 主角被神秘黑客盯上，手机 / 邮箱 / 聊天记录被监控。
- 真实感：不要让"一个高手就能全知全能"，必须有具体手段来源。

### 2. 身份爆破

- 主角身份被深度扒出：家庭 / 工作 / 行踪 / 社交 / 消费习惯。
- 真实感：大部分来自公开信息（人肉搜索）+ 泄露数据。

### 3. 关键证据获取

- 主角需要从企业 / 政府系统拿关键证据。
- 真实感：法律风险极高，必须付出代价 / 配合内应。

### 4. 诈骗 / 勒索

- AI 换脸冒充亲友 / 老板 / 领导。
- 真实感：常见案例，受害者多为中老年或急躁职场人。

### 5. 军火 / 跨境信号战

- 跨境黑客 / 情报战 / 军方电子战。
- 真实感：这类情节需要专业背景支撑。

## 七、黑客人物典型设定

### 外形

- 不是"穿黑帽戴黑眼镜的变态"。
- 现实黑客多数外形普通，衣着邋遢 / 极客休闲。
- 深夜工作、咖啡 / 功能饮料不离手。

### 性格

- 高度专注、技术至上、看不上非技术人。
- 社交能力弱 / 极强（两极分化）。
- 偏执狂倾向（为一个 bug 睡不着）。

### 工作

- 大厂安全 / 独立咨询 / 自由职业。
- 实验室 / 云环境 / 多显示器。

### 工具（可提名字，不细写用法）

- Linux（Kali / Ubuntu / Debian）。
- Burp Suite / Wireshark / Metasploit（提名字，不细写）。
- 编程语言：Python / Go / Rust。
- 终端 / 命令行工作主流。

## 八、常见误用

| 误用 | 正确 |
|---|---|
| 让黑客"一按回车攻破银行" | 真实攻击需要漫长时间 + 多环节配合 |
| 黑客 100% 看懂一切代码 | 术业有专攻，Web 黑客未必懂二进制 |
| 把手机关机就"失联" | 关机仍可被动追踪（基站 / GPS） |
| 让主角用 AI 换脸就能冒充所有人 | 真实 AI 换脸视频有破绽 + 需要大量素材 |
| 加密货币 = 匿名完全追不到 | 区块链公开可查，专业机构可溯源 |

## 九、写作建议

- **工具用名不细写**：Kali Linux 可提，具体命令不写。
- **攻击类型用名不细写**：SQL 注入 / 钓鱼可提，具体 payload 不写。
- **用结果和心理写戏**：代码戏核心是"时间紧迫 + 门槛紧张 + 后果严重"，不是算法本身。
- **让专业人员说"行话"**：真实感来自行业术语的自然使用。
- **让错误发生**：真实黑客攻击 50% 以上失败 / 被识别，这才有戏剧性。
