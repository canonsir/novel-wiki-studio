# 奢侈品 / 服装 / 时尚

## 定位

都市文显富 / 都市文品位 / 言情文配饰等场景的常用参考。错把"轻奢当顶奢"或"用过时品牌"会被懂行读者嘲笑。

## 一、腕表（男性顶级象征）

### 顶级（真·顶奢，男主最终登顶后戴）

| 品牌 | 代表系列 | 价格区间 |
|---|---|---|
| 百达翡丽 Patek Philippe | 鹦鹉螺 / 大师系列 / 复杂功能 | 20-500 万+ |
| 爱彼 Audemars Piguet | 皇家橡树 / 皇家橡树离岸 | 20-200 万 |
| 江诗丹顿 Vacheron Constantin | Overseas / 传承系列 | 15-200 万 |
| 理查德米勒 Richard Mille | RM 系列 | 50-1000 万 |

**写作提示**：
- 百达翡丽鹦鹉螺是"商务顶级含蓄"的最佳选择；
- 爱彼皇家橡树是"富二代张扬但有品位"；
- 江诗丹顿是"老派世家的首选"；
- 理查德米勒是"新贵 / 运动员 / 名流炫耀"。

## 四、男性西装

### 定制与成衣

- **意式顶级定制**：Brioni、Kiton、Caraceni（真·顶级手工，20-50 万一套）。
- **英式萨维尔街**：Henry Poole、Anderson & Sheppard（王室御用，30-100 万）。
- **成衣顶级**：Tom Ford、Zegna、Brioni 成衣线、Hugo Boss 顶级线。
- **意式新贵**：Dolce & Gabbana、Versace（张扬）。
- **英伦传统**：Dunhill、Burberry（经典风衣）。

### 领带 / 领结

- Hermès 丝巾（成为男性领带是极高品位）。
- Charvet（法式顶级）。
- Brioni 领带。

### 皮鞋

- **顶级手工**：John Lobb、Edward Green、Berluti、Corthay。
- **商务顶级**：Church's、Ferragamo、Tod's。
- **意大利时尚**：Prada、Gucci、Louis Vuitton。

**写作细节**：顶级手工皮鞋需要**定期上油保养**，一双可以穿 10-20 年。

## 十、常见误用

| 误用 | 正确 |
|---|---|
| 让所有女主都戴 Chanel | 根据气质和经济背景分配 |
| 顶级富豪戴劳力士水鬼"炫富" | 水鬼在真顶级面前只是基础 |
| Birkin 包随便买 | Hermès 需要配货或二手溢价 |
| 混搭多个顶级品牌一身 | 真顶级会讲究一致风格 |
| 把奢侈品和"庸俗炫耀"等同 | 老钱喜欢低调，新贵才显 |
