# 车辆与交通（都市文高频硬设定）

## 定位

都市 / 江湖 / 悬疑题材中，车是身份、财力、品位、追逐戏的综合载体。写错车能让懂车读者立刻弃书。本页提供可直接查用的真实车型清单与"显富 / 低调 / 实用 / 江湖"四种定位。

## 五、警用 / 军用 / 执法

- **警车**：帕萨特 / 迈腾 / 别克君威 / 大众途昂（现代警用主力）。
- **特警 / 武警**：丰田陆巡、三菱帕杰罗、国产猛士。
- **军用**：解放军 EQ2050（勇士）、东风猛士。

## 六、机场 / 跨境

### 商务航班

- 国内头等舱 2-3 万 / 单程；跨境头等 5-15 万；私人飞机 100 万+ / 次。
- 常用机型：波音 737 / 777 / 787；空客 320 / 350。

### 私人飞机

- **湾流 G650** / **巴航工业莱格赛** / **庞巴迪环球快车**：顶级富豪。
- **塞斯纳 奖状 CJ4**：中小企业老板。

### 游艇

- **山海型游艇**：50-200 万（入门豪游）。
- **远洋游艇**：500 万 - 数亿（真顶级富豪才有）。

## 七、追逐戏的真实边界

### 市区高速限速

- 中国市区限速 60 km/h；高架 80 km/h；环城高速 100 km/h；高速公路 120 km/h。
- 真实事故率在超过 120 km/h 急剧上升。

### 性能数据参考（可引用）

| 车型 | 0-100 km/h | 极速 |
|---|---|---|
| 保时捷 911 Turbo S | 2.7 秒 | 330 km/h |
| 法拉利 SF90 | 2.5 秒 | 340 km/h |
| 布加迪 Chiron | 2.4 秒 | 420 km/h |
| 普通家用轿车 | 10-12 秒 | 180-200 km/h |

### 追逐戏物理约束

- **市区 100 km/h 以上基本碾撞或撞行人**。
- **急转弯 60-80 km/h 侧滑风险极大**。
- **摩托车灵活但耐久差**，一次刮擦可能完败。
- **直升机追击**：真实警用直升机巡航 200 km/h，但有航空管制。

## 八、改装（禁区与边界）

### 法律边界

- 中国改装严格：外观 / 轮毂 / 排气都有限制。
- 非法改装：动力提升（涡轮）、拉花（商业用途）、灯光（透镜 / 氙气改装）、座椅（赛车座）。
- 可轻度改装：隐形车衣、普通音响、合规轮毂。

### 江湖 / 跨境走私改装

- **真实情节可写**：防弹玻璃 / 加厚钢板 / 隐藏武器舱。
- **禁写**：具体改装工艺、具体材料、具体购买渠道。

## 九、常见误用

| 误用 | 正确 |
|---|---|
| 让主角初期开法拉利 | 真实富豪也要有积累过程 |
| 把 "开 BBA" 等同顶级富豪 | BBA（奔驰宝马奥迪）在真顶级面前是中产标志 |
| 让顶级富豪开**宽体改装车** | 真顶级多数低调，宽体是"新贵炫耀" |
| 把 F1 速度直接拿来写 | F1 在赛道，街车性能有限 |
| 把劳斯莱斯写成老爷车 | 当代幻影 / 库里南是现代车，不是古董 |
| 让女性角色一上来开豪车 | 女性顶级角色可开豪车，但要有背景支撑 |
