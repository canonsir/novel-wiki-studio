# 武器硬设定（枪械 / 刀具 / 爆炸物）

## 定位

本页规定**武器真实能力边界**与**写作合规红线**。小说武器戏必须参考本页，禁止写入可直接复制的制造 / 改装 / 使用细节。

## 合规红线（最高）

### 严禁写入

- **枪械改装、重装、消音器自制、全自动改造**的具体步骤。
- **自制炸药、燃烧弹、化学毒剂**的配方 / 比例 / 流程。
- **军用武器的内部结构 / 零件编号 / 维护手册级细节**。
- **精确射击参数**（弹道计算 / 风偏 / 距离修正公式）。

### 可以写入

- 武器**外形、重量、口径、射程**的常识级描述。
- 使用武器的**动作、后坐力、声音、硝烟**感受。
- 中弹后的**疼痛、出血、意识变化**。
- **执法人员**合法使用枪械的程序。

## 中国枪支法律（硬约束）

- **《中华人民共和国枪支管理法》**：
  - 民用：仅限**猎枪、运动射击**，需省级公安颁证。
  - 严禁民间持有军用武器。
  - 收藏品枪支必须去击发装置。
- **刑法 128 条非法持有枪支罪**：3 年以下有期；情节严重 3-7 年。
- **刑法 125 条非法制造 / 买卖枪支罪**：3-10 年起步，严重者无期或死刑。
- **"仿真枪"**：击发功率超过 1.8 焦耳/平方厘米可能被认定为枪支。

**小说角色持枪必须有明确来源和法律风险**，不写来源 = 向读者暗示可轻易获取 = 合规问题。

## 枪械分类（常识级）

### 手枪

| 名称 | 口径 | 场景 |
|---|---|---|
| 中国 54 式 | 7.62×25mm | 老式军警 |
| 中国 92 式 | 9×19mm | 现代警察 / 军队 |
| 格洛克 17 | 9mm | 国际警用 / 民用 |
| 沙漠之鹰 | .50 AE | 大威力猎用 |
| 贝雷塔 M9 | 9mm | 美军老配 |

- **真实后坐力**：9mm 手枪一拳反弹 10-15 cm。
- **弹容**：标准 15-17 发；换弹夹 2-3 秒。
- **有效射程**：50 米内准，100 米外基本靠运气。

### 冲锋枪 / 步枪

| 名称 | 口径 | 场景 |
|---|---|---|
| AK-47 | 7.62×39mm | 民兵 / 跨境武装 |
| M4 | 5.56mm | 美军 / 特警 |
| 中国 95 式 | 5.8mm | 现役主力 |
| MP5 | 9mm | 近战特警 |

### 猎枪

| 名称 | 口径 | 场景 |
|---|---|---|
| 双管霰弹枪 | 12 号 | 农村猎枪 / 老式 |
| 莫斯伯格 500 | 12 号 | 常见 |

### 狙击枪

- **M24 / 巴雷特 M82 / 中国 88 式**。
- 真实狙击射程 800-1500 米；需要观察手。
- 小说可写但需要明确训练背景和装备链。

## 刀具（现代可用）

### 常见

- **军刀**：15-20 cm，重砍，军警用。
- **匕首**：10-15 cm，刺击为主。
- **折刀**：便携，街头常见。
- **瑞士军刀**：功能刀，不是武器。
- **战术刀**：钢材硬，刀刃薄，刺击强。

### 中国法律

- **《管制刀具暂行规定》**：
  - 匕首 / 三棱刮刀 / 弹簧刀 / 带有锁定装置的折刀：管制。
  - 刀身长度超过 12 cm：可能管制。
  - 携带管制刀具公共场所可被治安拘留。

## 爆炸物（极严格）

- **写入禁区**：具体配方 / 比例 / 引信 / 投放。
- **可写**：
  - "炸药包放在柱子底"（笼统描述）。
  - 爆炸后现场的烟尘 / 火光 / 伤者。
  - 拆弹时间紧迫（但不能写拆弹步骤）。
- **执法人员处置爆炸物**可笼统描述，细节交给专业人员。

## 弹道与伤势（可写细节）

### 伤势规律

- **擦伤**：出血多但不致命。
- **贯穿**：如避开大血管和内脏可救。
- **卡在体内**：手术取弹。
- **要害（心 / 头）**：现场致命率 70-90%。
- **腹部**：延迟性致命（内出血 / 感染）。
- **四肢**：失血 500 ml 可能休克。

### 现场音响

- 近距离枪响：如炸雷，可致暂时性耳鸣甚至失聪。
- 消音器：电影化，真实"消音"仍有 100 分贝以上。
- 枪烟 / 火药味：持续数分钟。

## 常见误用

| 误用 | 正确 |
|---|---|
| 任意获取军用枪 | 必须有明确来源（走私 / 偷取 / 遗留），并有法律风险 |
| 枪战不换弹夹 | 15 发打完必须换，换弹夹 2-3 秒窗口 |
| 中弹像被打了一拳 | 中弹是爆裂性损伤 + 瞬间失能 |
| 消音器真的"消音" | 仍有 100-130 分贝 |
| 民用枪随便买到 | 中国民用枪严格管控，剧情必须符合法律 |

## 对小说武器戏的建议

- **武器来源线必须真实**：走私（跨境背景）、祖传（家族旧账）、偷取（情节推动）。
- **数量稀少**：不是每个小弟都有枪；越真实越可信。
- **代价感**：开枪 = 刑事案件 = 公安介入；比徒手打斗的后果链长很多。
- **执法边界**：公安 / 特警用枪有明确程序（警告 → 鸣枪 → 射击非要害 → 射击要害）。
