# 军事 / 特种兵 / 退伍背景

## 定位

都市男频高频设定："兵王回归"、"退伍特种兵当保镖"、"战神下山"。本页提供**军队编制、军旅生活、退伍安置的常识级事实**，让军旅背景人物可信。武器操作细节见 `weapons.md`，徒手战斗力上限见 `martial-arts.md`。

## 合规红线（最高）

- 严禁写：真实部队的**驻地位置、编制人数、装备参数、调动规律、作战细节**。
- 严禁写：**窃密、叛变、军贸**的可操作情节；抹黑军队形象、虚构军队参与违法活动。
- 部队番号在小说中一律**虚构**（如"东南战区某特战旅""利刃突击队"），不套用真实番号。
- 跨国作战 / 雇佣兵情节：不写真实国家冲突，地点与国家虚构化（参见 `../china/geography-folk/real-to-fictional-map.md`）。
- 可以写：军人的**生活习惯、语言气质、情感模式、战友情谊、退伍处境**。

## 军队常识

### 军衔体系（军官）

| 等级 | 军衔 | 大致职务 |
|---|---|---|
| 将官 | 上将 / 中将 / 少将 | 战区、军级主官 |
| 校官 | 大校 / 上校 / 中校 / 少校 | 师、旅、团、营 |
| 尉官 | 上尉 / 中尉 / 少尉 | 连、排 |

- **大校**是中国特有军衔，介于上校和少将之间，常见于师长 / 旅长。
- 士兵：列兵 → 上等兵 → 下士 → 中士 → 上士 → 四级军士长 → 一级军士长（士官金字塔尖，全军稀少，极受尊敬）。

### 编制（常识级，小说用虚构部队）

- 班（约 9 人）< 排（3 班）< 连（3 排，约 100 人）< 营 < 团 / 旅 < 师 / 军。
- 现代改革后主体是**军旅营**体制，"师""团"在很多部队已撤编，写现代背景别张口就是"师长团长"。
- 五大战区：东部、南部、西部、北部、中部（小说中可虚构为"东南战区"等模糊说法）。
- 常见兵种：步兵、装甲兵、炮兵、侦察兵、通信兵、工兵、防化兵、陆航、空降兵、海军陆战队、武警特战。

### 特种兵真实样貌

- 选拔来源：基层部队骨干 + 淘汰制集训，**不是入伍就能当**；全程高比例淘汰，留下的是体力、意志、协同三者顶尖的人。
- 核心能力：**射击、格斗、泅渡、攀登、爆破（小说只写概念不写操作）、野外生存、侦察渗透、班组协同**。
- 特种兵强在**小队体系**：观察手、狙击手、爆破手、通信兵各有分工，不是满编兰博。落单的特种兵没有影视作品里那么神。
- 真实训练强调**痛苦、枯燥、重复**：泥潭、防毒面具跑、48 小时不休、生食、战俘演练，多数人靠战友情撑下来。
- 退役特种兵进入民间后：法律上就是普通公民，持械、伤人同样犯罪；真有人犯罪，刑侦系统照样抓（参见 `../china/law-enforcement/police-daily.md`）。

## 军旅生活细节（可直接入文）

- **时间感**：吹号 / 哨声作息，起床出操、整理内务、熄灯；退伍多年仍可能早起、被子叠成豆腐块。
- **语言习惯**：回答"是！""到！""明白！"；说话简短、不绕弯；讨厌磨叽和空话。
- **行为痕迹**：走路带风、落座选背靠墙面向门的位置、进电梯扫视环境、对爆炸般的声响警觉；唱歌只唱军歌且嗓门大。
- **称谓**：战友之间叫"老兵""班长"（班长是尊称，不一定真带过兵）；对主官叫职务不叫哥。
- **情感模式**：对部队感情极深但嘴上不说；战友情是过命关系，一封电话从千里外赶来合理；对家人普遍有亏欠感。
- **经济状况**：军官待遇在当地属中上稳定，士官因岗位差异大；不是每个退伍兵都身怀巨款，多数人回地方要重新讨生活。

## 退伍 / 转业安置

### 退役方式

- **义务兵退伍**：服役 2 年，拿退役金，回原籍，多数自谋职业。
- **士官退役**：服役满 12 年（含）以上可选择**由政府安排工作**（常见去向：事业单位工勤、国企、辅警）；不满 12 年一般拿钱自主就业。
- **军官转业**：计划分配进机关 / 事业单位（要降职安排，如营长转业当主任科员），或**自主择业 / 逐月领取退役金**。
- 还有**复员**（放弃安置拿一笔钱）和退休（高级士官、服役满一定年限军官）。

### 退伍兵的典型处境（戏剧富矿）

- 脱节感：在部队学的本领地方用不上，简历空白，同龄人已工作多年。
- 常见去向：安保 / 保镖、健身教练、司机、自己开小店、考编考公（有专项岗位和加分）。
- 心理落差与创伤后应激（PTSD）：真实存在但国内小说常写过头——失眠、警觉、噩梦可以写，"见人就打"是病化军人，不可取。
- 战友情网：退伍兵互相拉一把、合伙做事、也可能被昔日战友拉下水（涉黑团伙爱招退伍兵，是真实的社会问题，可写其挣扎与拒绝）。

## 常见误用

| 误用 | 正确 |
|---|---|
| 二十出头"特种兵王"，履历里服役十年 | 年龄对不上：18 入伍，拔尖特战骨干至少 25+；顶级士官多为中年 |
| 退伍兵随身带军刀 / 手枪 | 退伍即平民，枪支弹药严禁留存，军刀多为礼仪纪念物 |
| 一个人打垮几十个黑帮 | 受 `martial-arts.md` 硬上限约束：1v3 同级是现实极限 |
| 特种兵公开炫耀番号战绩 | 军人保密意识深入骨髓，真有本事的人最忌讳吹嘘 |
| 军官随口喊"师长""团长"指挥现代合成旅 | 军旅营体制下职务体系已变，且指挥有严格程序 |
| 退伍安置是"国家包分配好工作" | 仅服役满一定年限有安置资格，且岗位多为基层，多数人要自谋出路 |
| 兵王回都市秒变商业奇才 | 军队不教做生意，商业线必须给出学习与资源过程（参见 `finance-business.md`） |

## 小说应用建议

- **适合的主角原型**：沉默寡言的退伍保镖 / 小保安、被战友委托照顾其家人、看不惯地方恶霸出手、给女总裁当司机兼安全顾问。
- **能力展示分寸**：用**观察力、急救、纪律性、应急处置**立人设，少用一打多；高光战斗要有代价（参见 `medicine-pharmacology.md` 伤势恢复周期）。
- **戏剧冲突来源**：地方恶势力 vs 军人底线、昔日战友歧途（劝回或对决）、军属被欺辱、任务遗案 / 承诺、融入 civilian 生活的笨拙与温情。
- **情感线**：职业军人长期缺位亲密关系，"钝感硬汉 + 主动型女主"反差有效；军嫂 / 等待母题自带泪点。
- **身份压制桥段**：慎用"一个电话来一个连"式特权幻想，违反真实也踩平台雷区；可用合规的战友情、组织程序解决问题。
