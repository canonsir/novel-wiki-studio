# common/constraints/

**可勾选 checklist 库**。所有 Agent 评审 / 发布前把 checklist 对完一遍，缺项必须补齐。

## 结构

```
constraints/
├── README.md                              # 本文
├── platform-fanqie-checklist.md           # 番茄小说
├── platform-redfruit-checklist.md         # 红果 AI 短剧 / 投放素材
├── national-redlines-checklist.md         # 国家网络内容红线
└── genre-profiles/
    ├── urban-male.md                      # 都市男频
    ├── xianxia.md                         # 玄幻 / 仙侠
    └── romance-female.md                  # 言情女频
```

## 使用总规则

1. **发布前必须对 checklist**，所有 L1 / L2 条目必须勾选。
2. **逐条勾选**，不能一键全选。
3. **按责任 Agent 分工**：reviewer-agent 过平台 + 红线；author / editor 过题材 profile。
4. **发现红线触碰立即停产**，交 reviewer-agent 走修复流程。
5. **checklist 自身可更新**：发现新规则 / 新案例，先更新 checklist 再发布。
