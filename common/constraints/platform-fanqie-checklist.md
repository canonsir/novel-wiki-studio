# 番茄小说发布 checklist

发布到番茄小说正文的每一卷 / 每一次申报前必须勾选。配合 `national-redlines-checklist.md` 使用。

## 一、作品信息

- [ ] 书名符合番茄"小程式简单好记"的推荐。
- [ ] 简介 200-500 字，不剧透全书。
- [ ] 分类（都市 / 玄幻 / 言情 / ...）与内容匹配。
- [ ] 标签不超过 5 个，优选"都市 / 逆袭 / 江湖 / 后宫 / 热血"等高频男频标签。
- [ ] 封面图不含真人肖像 / 真实品牌 / 真实地标。
- [ ] 作者署名已完成实名认证。

## 二、正文结构

- [ ] 每章 3000-5000 字；短于 2500 字视为未展开。
- [ ] 章末留钩子（未解问题 / 迫在眉睫的危险 / 情感未决）。
- [ ] 首章首段 300 字内出现主角、处境、钩子。
- [ ] 全文无"水文"：空洞环境、重复情绪、对白同质被最小化。
- [ ] 无逻辑不连贯、无人物突兀。

## 三、国家红线（见 `national-redlines-checklist.md`）

- [ ] 所有法律红线项已勾选。
- [ ] 未成年人、犯罪、民族、宗教、历史真实人物均合规。

## 四、番茄平台专属

- [ ] 不含恶意水文（重复相似内容、无意义符号、拼凑无衔接）。
- [ ] 不含不当盈利（引导私下交易 / 外部打赏 / 非法集资）。
- [ ] 不含批量无意义内容（AI 直出未润色）。
- [ ] 不含攻击引战 / 人肉网暴。
- [ ] 不含摸索平台漏洞 / 传授违规经验。

## 五、成人情感尺度

- [ ] 成人情感采用"高张力非露骨"表达。
- [ ] 不写具体性器官 / 性行为细节。
- [ ] 不写强迫 / 偷拍 / 师生权力差浪漫化。
- [ ] 女性角色作为独立人物存在，非奖励 / 工具。
- [ ] 师生恋 / 师徒恋必须有年龄 / 身份 / 权力差的真实后果。

## 六、暴力与爽文边界

- [ ] 爽点兑现（打脸 / 逆袭 / 地位跃迁）频率合理。
- [ ] 代价感知（身体 / 关系 / 资源 / 声誉）真实呈现。
- [ ] 反派有合理动机，不脸谱化。
- [ ] 暴力描写服务于剧情，不单为刺激。
- [ ] 犯罪有法律后果或道德代价。

## 七、章节节奏

- [ ] 每 2-3 章小兑现。
- [ ] 每 5-8 章中型逆转。
- [ ] 每卷至少两个大高潮。
- [ ] 连续两章受压后必须有反击或希望。
- [ ] 章末钩子强度平均 ≥ 3（1-5 分制）。

## 八、技术合规

- [ ] 无乱码 / 多余空行 / 排版错乱。
- [ ] 无 AI 直出痕迹（人物说明过渡、无意义反复、"总之"等 AI 腔）。
- [ ] 繁简体统一，错别字控制在每章 2 处以内。
- [ ] 对白引号、标点、省略号规范。

## 九、更新频率

- [ ] 签约后保证日更或日 2 更。
- [ ] 不"坑文"（无故断更 7 天以上）。
- [ ] 预留 10-20 章存稿应对突发。

## 十、处置风险

- [ ] 可能被平台处置：驳回修改 / 停止分发 / 删除下架 / 限制功能 / 账号封禁。
- [ ] 发布记录已存入 `reports/`。
- [ ] 处置后恢复流程已明确。
