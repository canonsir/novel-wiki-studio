# 玄幻 / 仙侠 profile

玄幻 / 仙侠 / 都市玄幻 / 修真题材的创作约束。

## 核心承诺

- **修炼升级**：清晰的境界 / 等级体系，层层突破。
- **因果报应**：天道 / 轮回 / 阴阳五行的内在规律。
- **门派对立**：正邪 / 不同道统的世界观。
- **身世之谜**：主角有"不凡血脉 / 隐藏身世"。
- **异宝争夺**：法宝 / 丹药 / 功法 / 妖兽的驱动力。

## 世界观硬设定（必须一开始定清楚）

### 1. 境界体系

- 清晰可量化的 N 层境界（如：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 大乘）。
- 每层有具体差异（寿命 / 力量 / 感知范围 / 法力类型）。
- 主角初始境界 + 升级节奏明确。

### 2. 功法体系

- 功法分类（炼体 / 炼气 / 剑道 / 丹道 / 器道 / 阵法 / 符箓）。
- 阴阳 / 五行 / 八卦 / 天干地支 做底层逻辑参考（见 `knowledge-base/china/philosophy/daoism.md`）。
- 功法有属性（火 / 水 / 木 / 金 / 土 / 雷 / 风 / 冰 / 光 / 暗）。

### 3. 法宝 / 丹药 / 异兽

- 分品级（凡 / 下 / 中 / 上 / 极品 / 仙品）。
- 来源可追溯（炼制师 / 门派 / 异兽掉落 / 远古遗迹）。
- 消耗代价（灵石 / 寿命 / 功力 / 血肉）。

### 4. 门派 / 势力

- 正邪 / 道魔 / 儒道佛的三足或多足。
- 每派有明确道统、代表功法、祖庭。

### 5. 大陆地理

- 东胜神洲 / 西贺牛洲 / 南赡部洲 / 北俱卢洲（道教四大部洲）。
- 或自定义大陆名 / 州名 / 山海名。
- 每个区域有特色（天气 / 资源 / 门派 / 异兽）。

## 规则硬约束

- **一旦定下规则不能违反**：如筑基不能飞剑，就全书不能破例。
- **破例必须有大代价**：如主角以筑基杀金丹，必须付出失去寿命 / 道心受创等。
- **因果守恒**：杀业必有反噬 / 心魔 / 劫数。

## 主角类型

- **血脉 / 身世**：隐藏的皇族 / 神灵 / 异兽后裔。
- **初始废柴**：常规起点，突然逆袭。
- **穿越 / 重生**：外来者视角（都市玄幻常用）。
- **妖 / 魔 / 人 / 鬼混血**：天然立场复杂。

## 修炼节奏（硬要求）

| 层级 | 频率 | 举例 |
|---|---|---|
| 每日修炼 | 常态化描述 | 吞吐天地灵气、服食丹药 |
| 境界突破 | 每 10-20 章 1 次 | 从筑基到金丹的详细描写 |
| 大境界突破 | 每卷 1-2 次 | 元婴 / 化神等关键节点 |
| 瓶颈期 | 可有 | 突破不了，必须出去历练 |

## 情感线约束

- 女主可以是同道中人，有自己的修炼线。
- 师徒恋 / 道侣情：若写，必须符合境界同步、情感真实。
- 后宫慎用（仙侠传统主张"一心一人"，但现代仙侠多元）。

## 冲突层级

| 层级 | 对象 | 场面 |
|---|---|---|
| 门内 | 师兄弟 / 内门外门 | 比试、争夺资源 |
| 门外 | 其他宗门 / 散修 | 大比、合作、火并 |
| 大陆 | 多宗联合 / 魔门 | 大战、禁地探险 |
| 跨界 | 异界入侵 / 天劫 | 终极战 |

## 禁区

- [ ] 禁止武力 / 境界设定随意突破（破规必须代价）。
- [ ] 禁止"系统"喧宾夺主（可有，但不能替代主角成长）。
- [ ] 禁止无代价"飞升"（登仙必须有大牺牲）。
- [ ] 禁止无规则金手指（主角逆天必须有机缘来源）。
- [ ] 禁止世界观前后矛盾（第 1 章和第 500 章的规则不同）。

## 文化底色

- **道家 / 佛教 / 阴阳**：核心灵感来源。
- **《山海经》 / 《封神演义》 / 《西游记》 / 《聊斋》**：常用典故库。
- **《淮南子》 / 《抱朴子》 / 《云笈七签》**：进阶参考。

## 风格基调

- 第一人称 / 限知第三人称。
- 对白占比 20-30%。
- 环境描写 15-20%（修真世界的"异感"重要）。
- 修炼描写 10-20%（境界突破要仪式感）。
- 心理描写 15-20%。
- 动作场面 20-30%（法术战必须具象）。

## 爽感来源优先级

1. **境界突破**（最高）：从被压制到压制别人。
2. **异宝入手**：功法 / 丹药 / 法宝到手。
3. **身世揭露**：发现自己是"选中的人"。
4. **情感兑现**：道侣相依。
5. **因果清算**：仇敌被天道报应 / 自己亲手处决。

## 可参考的畅销作品原型

- 《斗破苍穹》：废柴逆袭 + 修真等级。
- 《斗罗大陆》：魂环体系 + 唐门。
- 《遮天》：古风修真 + 顶级后台。
- 《仙逆》：道心路。
- 《凡人修仙传》：真实感 + 慢升级。
