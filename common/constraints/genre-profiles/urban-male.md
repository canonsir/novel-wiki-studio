# 都市男频 profile

都市 / 江湖 / 都市玄幻 / 都市后宫等男频题材的创作约束。

## 核心承诺（读者点进来期待的）

- **身份反差跃迁**：穷大学生 / 落魄青年 → 江湖 / 商业 / 政商顶层。
- **打脸 + 爽感**：对看不起主角的人逐级打脸。
- **情感扩展**：主角魅力叠加，艳遇多样化但有真实关系线。
- **势力升级**：帮派 → 家族 → 跨城 → 跨国 → 顶级后台。
- **后台揭示**：主角身世 / 父辈伏笔逐步揭开。

## 主角类型

- **苦出身**：穷大学生、城郊少年、下岗工人、穷律师。
- **初始无背景**：家人不显贵、不依靠家族。
- **一个记忆创伤或底线**（给主角心性来源）。
- **一个外形亮点**（身材 / 气质 / 眼神，不要颜值即正义）。

## 爽点节奏（硬要求）

| 层级 | 频率 | 举例 |
|---|---|---|
| 微爽 | 每章 1 次 | 言语制胜、小智谋 |
| 小爽 | 每 2-3 章 | 公开打脸、兄弟认可 |
| 中爽 | 每 5-8 章 | 地位跃迁、重要盟友 |
| 大爽 | 每卷 1-2 次 | 组织重建、家族翻盘、身世揭示 |

## 不可或缺的类型元素

- **江湖规矩**（见 `knowledge-base/china/jianghu/etiquette-and-rules.md`）。
- **大哥 / 师父类导师**（见 editor-agent 建议）。
- **忠诚兄弟班底**（至少 3-5 人，各有特色）。
- **反派层级**（街霸 → 帮派 → 家族 → 跨城组织 → 顶级）。
- **多层后台**（父辈伏笔 / 师门渊源 / 国家力量）。

## 情感线约束

### 女性角色设计

- **至少 3 条独立情感线**，各代表不同主题：
  - 一条"现实生活锚点"（患难伴侣 / 平民底色）。
  - 一条"精神共振"（高层女 / 智性匹配）。
  - 一条"创伤修复"（主角帮她 / 她也帮主角）。
- 每个女性角色必须**独立成立**：有自己的事业、朋友、欲望，不是等主角拯救。

### 情感尺度（合规必读）

- 非露骨：吻 / 拥抱 / 心跳 / 气息描写 OK，具体性行为不写。
- 边界明确：成年人之间，自愿为前提，所有初夜 / 关键亲密戏必有情感铺垫。
- 没有强迫浪漫化、没有师生权力差浪漫化。
- 女性可以主动表达欲望，不以"被动等待"为唯一模板。

### 多女关系（后宫）

- 可写，但必须符合：
  - 女性互不消解彼此（不写"宫斗"互坑）。
  - 主角有真实情感负担（代价感）。
  - 不写一夫多妻合法化（现实合规）。
  - 情感主次清晰，不是"同等爱 N 个"。

## 对手设计

- **反派也是主角**：有自己的成长线 / 内心逻辑 / 关系网。
- **强对手要有强规则**：第一次打输才有后续反转。
- **政商 / 后台级 Boss**：不正面武力对抗，而是"规则 vs 规则"的较量。

## 节奏硬约束

- **第一章**：300 字内出钩子，1000 字内出主角处境，3000-5000 字内第一次冲突。
- **前 10 章**：每章至少一个"读者愿意翻下一章"的理由。
- **第 20-30 章**：第一次大逆转 / 身份跃迁。
- **每卷**：至少两个大高潮 + 一次价值变化。

## 禁区

- [ ] 禁止一开场就"全知全能"。
- [ ] 禁止反派纯脸谱化（除非功能性串场）。
- [ ] 禁止女性"工具化""奖品化"。
- [ ] 禁止爽点不兑现代价（打脸后要有后续麻烦）。
- [ ] 禁止"水文"（无价值变化的章节）。
- [ ] 禁止上帝视角泄密。
- [ ] 禁止"升级靠系统 / 金手指"（可以有，但不能喧宾夺主）。

## 风格基调

- 第一人称或限知第三人称。
- 过去时为主。
- 对白占比 25-35%。
- 环境描写 10-15%（功能性，不堆砌）。
- 心理描写 15-20%（必须外化为动作 / 决策）。
- 动作场面 15-25%。
- 文笔：接地气 + 偶有金句，不要过于文艺。

## 爽感来源优先级

1. **身份反差**（最高）：弱者突然变强，碾压势利眼。
2. **智慧碾压**：以计谋反杀，不只是暴力。
3. **关系兑现**：兄弟不离不弃、长辈认可。
4. **情感满足**：女性真心付出 / 主动选择。
5. **物质 / 地位**：豪车、豪宅、权力（但代价要清）。

## 可参考的畅销作品原型

- 《古惑仔》：江湖兄弟底色。
- 《斗罗大陆》唐门体系：组织升级。
- 《遮天》：古风 + 顶级后台。
- 《飞狐外传》：传统武侠 + 跨城线。
- 《情陷美女老师》（本仓已归档）：师生 + 江湖 + 家族棋局。
