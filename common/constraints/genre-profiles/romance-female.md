# 言情女频 profile

现代言情 / 古代言情 / 青春言情 / 女尊 / 甜宠 / 虐恋等女频题材的创作约束。

## 核心承诺

- **心动与悸动**：女主与男主之间的情感发展。
- **成长弧线**：女主从被动到主动、从依附到独立。
- **情感满足**：被珍视、被看见、被尊重。
- **逆袭 / 独立**：女主有自己的事业 / 价值。
- **浪漫与现实的平衡**：既要梦幻也要真实感。

## 女主类型

- **白月光型**：温柔、善良、聪慧，有自己的坚持。
- **飒女型**：独立、果断、有事业心。
- **成长型**：从柔弱到强大。
- **穿越 / 重生型**：带着现代意识应对古代 / 虚构世界。
- **身份反差型**：隐藏身份（公主 / 商界千金 / 特工）。

## 男主类型（避免霸道总裁同质化）

- **冷峻深情型**：面冷心热，为女主一人破例。
- **温柔治愈型**：细心、体贴、懂女主。
- **腹黑型**：聪明狡黠，但对女主真心。
- **成长型**：与女主一起成长。
- **反差萌型**：外冷内萌 / 外强内弱。

## 情感节奏（硬要求）

| 阶段 | 频率 | 关键情节 |
|---|---|---|
| 相遇 / 初见 | 第 1-3 章 | 冲突或暧昧的第一次见面 |
| 心动 | 第 5-15 章 | 一方对另一方产生心跳 |
| 牵绊 | 第 15-50 章 | 共同经历事件，关系加深 |
| 确认 | 第 50-80 章 | 互相承认心意 |
| 考验 | 第 80-120 章 | 外部压力 / 内部误会 |
| 兑现 | 终局 | 修成正果 / 美满结局（HE 为主流） |

## 常见套路（可用但要创新）

### 偶遇类

- **误会邂逅**：撞车 / 相撞 / 误会抢劫。
- **职场相遇**：新上司 / 同事 / 下属。
- **童年重逢**：小时候认识，长大再见。
- **契约结婚 / 恋爱**：从假到真。
- **宿敌转情人**：从针锋相对到互相理解。

### 冲突类

- **门第差距**：灰姑娘与王子的现代版。
- **误会 / 第三者**：古典误会线。
- **身份隐瞒**：女主 / 男主有秘密。
- **过去阴影**：前任 / 旧情 / 创伤。

## 情感尺度（合规必读）

### 甜宠向

- 吻戏 / 拥抱 / 心跳 / 气息 / 耳垂发红 OK。
- 关键亲密戏可以暗示（镜头拉远 / 留白）。
- 不写具体性行为细节。
- 可写"初夜"但以情感铺垫为主，细节留白。

### 虐恋向

- 可以有"短期分离"、"误会"、"痛苦"。
- 但必须有兑现 / 和解 / 救赎。
- 不写强迫 / 伤害合理化。

### 禁区

- 不写强迫 / 偷拍 / 控制狂浪漫化。
- 不写师生 / 师徒权力差浪漫化。
- 不写家暴 / 精神控制作为"真爱证明"。
- 不写未成年人情感（18 岁以下角色绝对不涉及）。
- 不写出轨合理化（现代都市题材尤其）。

## 女性成长弧

**现代言情必须的**：女主必须有自己的事业 / 价值，不能"全部围绕男主"。

- 女主的事业线应与情感线并重。
- 女主的自我认同不以男主为唯一标准。
- 关键决策女主自己做（而非男主替她决定）。
- 结局不是"嫁给男主"而是"选择与男主共同生活"。

## 配角设计

### 女性配角

- 闺蜜：真诚支持 / 偶有误解。
- 女反：有合理动机，不是单纯"抢男主"。
- 女性亲属：母亲 / 姐妹 / 女儿有独立人格。

### 男性配角

- 男二：对女主有感情但有自知之明。
- 兄弟 / 兄长：为男主增色不抢戏。
- 男性反派：权力 / 欲望 / 控制欲合理化。

## 冲突层级

| 层级 | 对象 | 场面 |
|---|---|---|
| 内心 | 自我怀疑 / 犹豫 | 独白 / 关键决策 |
| 两人 | 误会 / 价值差异 | 冷战 / 争吵 / 和解 |
| 家庭 | 父母反对 / 门第差距 | 餐桌对峙 / 家族大战 |
| 职场 | 事业危机 / 竞争对手 | 商战 / 办公室博弈 |
| 过去 | 前任 / 旧情 / 隐瞒 | 真相揭露 / 和解 |

## 禁区

- [ ] 禁止"玛丽苏"（女主无特点但人人爱她）。
- [ ] 禁止男主"控制狂浪漫化"。
- [ ] 禁止女主完全依赖男主生存。
- [ ] 禁止"误会靠巧合解决"（必须靠人物成长）。
- [ ] 禁止反派无动机"硬搞女主"。
- [ ] 禁止"真爱至上"消解伦理（如出轨 / 师生恋美化）。

## 风格基调

- 第一人称 / 限知第三人称 / 双 POV 都可。
- 现在时 / 过去时 / 现在时为主。
- 对白占比 30-40%。
- 环境描写 10-15%（气氛烘托）。
- 心理描写 20-30%（女频读者爱看心理）。
- 情感细节描写 15-25%（男主的小动作 / 微表情）。

## 情感描写技巧

- **五感全开**：视觉 / 听觉 / 嗅觉（男主的 cologne）/ 触觉 / 心跳。
- **外化情绪**：不写"她好开心"，写"她抿了抿唇，指尖轻轻敲桌沿"。
- **暧昧时的沉默**：一个眼神胜过千言万语。
- **肢体语言**：伸手但犹豫 / 想触碰又收回。

## 可参考的畅销作品原型

- 《杉杉来吃》顾漫：甜宠轻小说。
- 《何以笙箫默》顾漫：虐恋 → HE。
- 《微微一笑很倾城》顾漫：甜宠 + 游戏。
- 《三生三世十里桃花》唐七：古风虐恋。
- 《太子妃升职记》鲜橙：女尊 + 穿越。
