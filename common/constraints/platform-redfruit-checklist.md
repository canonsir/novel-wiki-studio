# 红果漫剧 / 短剧 AI 素材 checklist

红果投放 AI 正片 / 投放素材前，reviewer-agent + adapter-agent 共同勾选。配合 `national-redlines-checklist.md` 使用。

## 一、作品层级信息

- [ ] 作品标题不超过 15 字，钩子强。
- [ ] 剧本摘要包含"钩子 + 冲突 + 爽点兑现"。
- [ ] 作品分类（都市 / 玄幻 / 言情 / 悬疑）与内容匹配。
- [ ] 封面图不含真人肖像 / 真实品牌 / 真实地标。
- [ ] 已完成 AI 素材声明（"本故事纯属虚构"、"AI 文生视频，无真人肖像输入"）。

## 二、分集结构

- [ ] 单集时长 3-5 分钟。
- [ ] 单集 15 秒内出钩子。
- [ ] 单集至少 1 个小兑现（60-90 秒一个节拍）。
- [ ] 单集结尾挂钩下一集。
- [ ] 全剧 60-100 集（红果主流长度）。

## 三、分镜与场景

- [ ] 每集有完整分镜表（镜号 / 时长 / 景别 / 角色 / 动作 / 对白 / 环境 / 情绪）。
- [ ] 单镜头平均 2-5 秒；长镜头 ≤ 10 秒。
- [ ] 场景切换不超过每集 15 处。
- [ ] 关键情绪转折有特写镜头。

## 四、AI 可生成资产 5 件套

- [ ] 人物 look：发型 / 服装 / 配饰 / 身材 / 外形标签。
- [ ] 场景光影：时辰 / 色温 / 氛围 / 构图。
- [ ] 关键道具：材质 / 状态 / 用途。
- [ ] 动作要点：核心动作 / 表情微动作。
- [ ] 环境声：背景音效 / 关键音效。

## 五、国家红线（见 `national-redlines-checklist.md`）

- [ ] 所有法律红线项已勾选。

## 六、红果平台专属

- [ ] 不使用真人肖像输入。
- [ ] 不使用真实品牌 / 商标（咖啡 / 服装 / 车辆都虚构化）。
- [ ] 不使用真实地标（北京→帝都、上海→魔都，见 `knowledge-base/china/geography-folk/real-to-fictional-map.md`）。
- [ ] 投放素材不以色情 / 毒品 / 赌博 / 血腥 / 未成年人作吸睛点。
- [ ] AI 生成的面孔不与现实名人相似（有争议时重新生成）。
- [ ] 版权音乐 / 字体 / 素材已声明来源。

## 七、尺度边界

### 情感戏

- [ ] 成人情感采用高张力非露骨表达。
- [ ] 亲密戏不写具体性行为。
- [ ] 吻戏 / 拥抱 / 调情可以，但不过度。

### 暴力戏

- [ ] 格斗戏不含过度血腥。
- [ ] 枪战 / 刀战 不展示具体武器制造 / 改装。
- [ ] 死亡镜头不猎奇化。

### 犯罪戏

- [ ] 不展示具体犯罪流程（制毒 / 制爆 / 洗钱 / 走私）。
- [ ] 犯罪必须有后果（司法 / 自毁 / 道德）。
- [ ] 公权力立场正。

## 八、人物设定

- [ ] 主角有明确欲望 - 恐惧 - 代价曲线。
- [ ] 反派有合理动机。
- [ ] 女性角色独立成立，不是奖励 / 工具。
- [ ] 配角不"工具人"化（至少有一个独立情感 / 决策点）。
- [ ] 未成年人角色严格合规。

## 九、技术合规

- [ ] 画面无水印 / 版权 LOGO。
- [ ] 分辨率 / 帧率符合红果上传标准。
- [ ] 字幕准确、无错别字。
- [ ] 音画同步。

## 十、投放素材专属

- [ ] 投放钩子集中 10-20 秒内。
- [ ] 投放版本可以独立成立（不依赖前情提要）。
- [ ] 投放版本自带"本故事纯属虚构"字样。
- [ ] 投放版本不含诱导性成人暗示。

## 十一、追溯

- [ ] checklist 快照存入 `reports/lint/<yyyy-mm-dd>-redfruit-check.md`。
- [ ] 每集档案保留分镜 + 资产 + 合规备注。
