# 国家网络内容红线 checklist

每一次发布前，reviewer-agent 必须对以下所有项目逐条勾选。**任何一项触碰视为 L1 红线，必须修改后才能发布。**

## 一、法律红线（最高）

- [ ] 不含煽动分裂国家、颠覆国家政权、推翻社会主义制度的内容。
- [ ] 不含散布谣言、扰乱经济和社会秩序的内容。
- [ ] 不含渲染暴力、恐怖主义、极端主义的内容。
- [ ] 不含煽动民族仇恨、民族歧视，破坏民族团结的内容。
- [ ] 不含侮辱、诽谤他人（包含历史人物 / 真实在世人物）的内容。
- [ ] 不含淫秽色情、低俗、庸俗内容。
- [ ] 不含宣扬邪教、迷信、宗教极端主义的内容。
- [ ] 不含侵害他人合法权益（名誉 / 肖像 / 隐私 / 著作权）的内容。
- [ ] 不含损害国家荣誉和利益的内容。

## 二、未成年人保护

- [ ] 不性化、剥削、物化未成年人（18 岁以下）。
- [ ] 不描写未成年人严重暴力、吸毒、犯罪的具体细节。
- [ ] 对年龄不明角色，默认按未成年人高标准处理。
- [ ] 不写针对未成年人的性暗示、恋童情节。
- [ ] 校园欺凌必须给出受害者保护与施害者后果。
- [ ] 不教唆未成年人犯罪 / 自残 / 自杀。

## 三、犯罪与危险行为

- [ ] 不写可直接复制的犯罪方法（制毒 / 制爆 / 制枪 / 洗钱 / 走私）。
- [ ] 不写可直接复制的自残 / 自杀方法。
- [ ] 不美化毒品 / 赌博 / 卖淫嫖娼 / 色情。
- [ ] 犯罪必须有后果（法律 / 道德 / 社会）。
- [ ] 不以犯罪为主要感官卖点或教学内容。
- [ ] 不写具体医药 / 化学 / 武器配方。

## 四、历史与真实人物

- [ ] 不戏谑消费重大公共事件、灾难、真实案件。
- [ ] 不侵害英雄烈士 / 革命先烈的名誉。
- [ ] 不消解主流历史叙事（抗战 / 革命 / 建国）。
- [ ] 不虚构有关真实在世人物的违法 / 不堪情节。
- [ ] 真实历史人物只用大众共识信息，不编造。
- [ ] 真实机构 / 公司 / 品牌出现敏感情节必须虚构化。

## 五、民族 / 宗教

- [ ] 不描写有具体民族冲突的仇恨性情节。
- [ ] 不嘲讽特定民族的生活习惯 / 语言 / 文化。
- [ ] 不涉及新疆 / 西藏 / 内蒙的政治敏感议题（见 `knowledge-base/china/geography-folk/real-to-fictional-map.md` 虚构化处理）。
- [ ] 不亵渎任何宗教的核心教义 / 神祇 / 圣物。
- [ ] 不把具体宗教与恐怖主义 / 极端主义挂钩。

## 六、国家标识

- [ ] 不戏谑国旗、国徽、国歌。
- [ ] 不虚构解放军 / 公安 / 国安 / 司法工作人员的不堪情节。
- [ ] 不杜撰党政领导人（真实在职）的言行。
- [ ] 使用公权力角色时，主体立场必须正。

## 七、商业违规

- [ ] 不含诈骗、非法集资、传销的教唆内容。
- [ ] 不含侵犯知识产权（抄袭、盗版、未授权改编）。
- [ ] 不含金融类 / 医疗类 / 法律类的具体操作建议（避免被当作专业咨询）。
- [ ] 不进行违规营销 / 引导私下交易。

## 八、不良低质

- [ ] 标题与内容相符。
- [ ] 不低俗性暗示 / 猎奇炒作。
- [ ] 不过度血腥 / 残忍 / 惊悚仅为刺激。
- [ ] 不批量重复 / 乱码 / 拼凑百科 / 复制教材。
- [ ] 逻辑连贯 / 人物有动机 / 场景有变化。
- [ ] 不"水文"（空洞环境描写 / 重复情绪 / 对白同质）。

## 九、合规处置

- [ ] 发现 L1 条目触碰：立即停产，由 reviewer-agent 走修复流程。
- [ ] 发现 L2 条目触碰：修改到合规。
- [ ] 发现 L3 条目触碰：建议修改。
- [ ] L4 风险提示：告知用户并记录。

## 十、追溯

- [ ] 每次发布前 checklist 快照存入 `reports/lint/<yyyy-mm-dd>-national-redline-check.md`。
- [ ] 发现误放文件（原稿副本 / 密钥 / 测试数据）立即清理。
