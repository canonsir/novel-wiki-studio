# 小说质量评分表

每项 0–5 分。0=缺失，3=可用，5=有辨识度且稳定。总分不是审美真理，用于定位问题。

| 维度 | 核心问题 | 通过线 |
|---|---|---:|
| 概念与差异化 | 一句话是否有独特冲突与机制？ | 3 |
| 主角能动性 | 是否主动选择并承担后果？ | 4 |
| 动机可信度 | 行动是否由欲望、信息和压力支持？ | 4 |
| 因果链 | 关键节点能否用“因此/但是”连接？ | 4 |
| 冲突升级 | 是否不仅靠敌人变强？ | 3 |
| 人物关系 | 关系是否在场景中变化？ | 3 |
| 世界规则 | 规则、边界、代价是否一致？ | 4 |
| 信息控制 | 悬念公平，揭示时机合理？ | 3 |
| 情绪回报 | 承诺是否兑现、代价是否真实？ | 3 |
| 场景效率 | 每场是否产生状态变化？ | 4 |
| 语言与声音 | POV 清晰、人物声音可区分？ | 3 |
| 细节与可视化 | 具体、个体化、服务戏剧？ | 3 |
| 连续性 | 时间、空间、伤势、知识一致？ | 4 |
| 伏笔 | 有投放、强化、回收账本？ | 3 |
| 节奏与留存 | 开头快进场，中段变化，结尾推动？ | 3 |
| 原创与合规 | 无抄袭、隐私、低俗和平台高风险？ | 5 |
| 视频适配 | 关键内容可外化，有视觉/声音抓手？ | 3 |

## 一票否决

- 核心内容侵犯版权或实质性洗稿；
- 存在严重违法有害内容或未成年人性化内容；
- 关键剧情依赖未铺垫规则且无法修复；
- 多处核心连续性矛盾导致故事无法成立；
- 批量低质、重复、逻辑不连贯的 AI 文本。

## 修订顺序

先修结构与因果，再修人物动机，再修场景与信息，最后修句子。不要在会被删除的章节上做精细润色。
