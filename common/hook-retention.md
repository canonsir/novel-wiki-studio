# 吸睛与留存规则

吸睛不是标题党，而是快速建立“人物 + 异常 + 代价 + 未完成问题”。留存来自持续兑现，不来自每章硬造反转。

## 开篇前 1–3 个场景

尽快完成：

- 呈现主角有辨识度的行动方式；
- 引入一个打破日常的异常；
- 让主角做选择而非被动接收；
- 给出具体风险；
- 展示题材核心体验的样本；
- 留下可被读者表述的问题。

避免：大段世界史、群像名册、梦醒开场、无后果追杀、信息不足的故弄玄虚。

## 五类钩子

- **结果钩**：一个行动即将产生后果。
- **秘密钩**：信息不对称将改变关系。
- **选择钩**：两个选项都付出代价。
- **倒计时钩**：期限明确且正在缩短。
- **意义钩**：旧信息被重新解释。

同一类连续使用会疲劳，应轮换。

## 章节留存曲线

开场再激活问题 → 小回报 → 新阻力 → 中点变化 → 代价/发现 → 部分回报 → 新推动。每章既“还债”也“借债”：至少回收一个此前承诺，再提出一个由回收自然产生的新问题。

## 回报频率

长悬念需要短回报支撑。回报可以是线索、能力验证、关系靠近、幽默、胜利、真相片段、世界奇观。禁止只开坑不回收。

## 情绪节奏

强刺激后给处理空间；连续高压会麻木。用希望制造可失去之物，用安静放大下一次变化。情绪波动应由选择和后果产生。

## 标题与简介

- 标题传递类型、核心意象或独特机制，不承诺正文没有的内容。
- 简介先写冲突和差异化，不从世界史开始。
- 使用具体困境，不使用“且看主角如何……”等空模板。
- 不以低俗暗示、严重不符正文的夸张标题或敏感炒作换点击。

## 数据化但不被数据绑架

可记录读者流失章、评论困惑点、最受欢迎关系/场景，但只把数据当证据。修订前判断问题属于承诺不清、进展过慢、人物不可信、信息过载还是回报不足。
