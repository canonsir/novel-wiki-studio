## 一、问题诊断

"**霍惊鸿**"命名问题分析：
- "**惊鸿**"二字出自《洛神赋》"翩若惊鸿，婉若游龙"——**本意是形容女性之美**（曹植写洛神）
- 但在武侠 / 都市大女主语境里，"惊鸿"因**韵律硬朗**（去声 + 阳平 + 阳平）和**三字连读**（霍-惊-鸿）常被读成**男性字号**（如陆小凤、楚留香、沈浪 式）
- 加上"**霍**"姓本身被《射雕》霍都 / 现代电视剧中"霍少""霍家长子"用得太多，男性印象大于女性
- **结论**：此名有性别读感歧义，适合改

## 五、推荐一揽子方案（三选一）

### 方案 A · 仅改最严重（最小改动）
- 霍惊鸿 → **霍栖兮**
- 季繁星 / 穆清 保留
- **优点**：改动最少 / 风险最低
- **缺点**：中性名问题未根治

### 方案 B · 全部改（推荐）
- 霍惊鸿 → **霍栖兮**
- 季繁星 → **季婉宁**
- 穆清 → **穆清岚**
- **优点**：女主群女性识别度全部达标 / 短剧改编友好（选角一秒看懂性别）
- **缺点**：3 名改动 / 工程量稍大

### 方案 C · 混合
- 霍惊鸿 → **霍栖兮**（必改）
- 季繁星 → 保留（繁星二字可作中性艺人名合理化）
- 穆清 → **穆清岚**（强化女警识别度）
- **优点**：季繁星本身中性感较弱 + 艺名"洛神"已够女性识别
- **缺点**：读者初遇"季繁星"仍可能短暂歧义

### 作者建议：**方案 B 全部改**（短剧改编时性别识别度 = 选角速度 = 效率）
