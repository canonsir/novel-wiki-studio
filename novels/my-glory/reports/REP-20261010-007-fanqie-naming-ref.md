## 一、番茄男频都市/爽文 爆款命名的 8 条规律

### 规律 1：**"xxx 的 xxx"所属格**（最高频套路）
- "我在xxx当xxx" / "我的xxx是xxx" / "重生之xxx的xxx"
- 例：《我的岳父是刘备》《我在修仙界开地府》《我的岳父是朱元璋》
- 作用：第一人称 + 关系错位 + 身份暗示

### 规律 2：**反差冲击型**（装逼 + 平凡）
- "**最低调的xxx**" / "**都市最强xxx**" / "**我真不是xxx**"
- 例：《都市最强仙帝奶爸》《我真不是演员》《最低调的首富》
- 作用：标题即戏，一行传达反转

### 规律 3：**超长信息密度型**（短视频时代新爆款）
- "**xxx，xxx，没想到我xxx**" / "**全家读我心声xxx**" / "**穿越到xxx，xxx**"
- 例：《我岳父是李世民，开局就让我造反》《全家读我心声后，我带着祖宗飞升》
- 作用：封面即剧情梗概；1 秒钩住点击

### 规律 4：**身份转换型**（金手指/逆袭核心）
- "**从xxx开始**" / "**xxx之路** / **xxx之子**"
- 例：《从笑傲江湖开始横推诸天》《神豪之子》《龙王殿之子》
- 作用：读者第一眼知道"主角路径"

### 规律 5：**单字/双字名+副标题**（文艺型）
- 《xx·xxxx的xxx》
- 例：《道诡异仙》《诡秘之主》《超脱》
- 作用：封面力强；但吸粉速度中等

### 规律 6：**神话/文脉前缀**（本作适合）
- "**天师** / **北辰** / **紫微** / **玄策** / **御前** / **太医** / **帝都**"
- 例：《帝国的脊梁》《北辰之子》《天师在六零》《御前茶博士》
- 作用：带文脉重量 + 高辨识度

### 规律 7：**后宫暗示型**（男频主流）
- "**xxx和他的xxx们**" / "**xxx的小xxx**" / "**我有xxx个xxx**"
- 例：《我有一座道观》《我在诡异世界有个群》
- 作用：读者第一秒知道是群像/后宫

### 规律 8：**感叹号/反问号强势型**（短剧改编最爱）
- "**xxx，但xxx？**" / "**xxx？！**" / "**xxx？你管这叫xxx？**"
- 例：《躺平？你管这叫躺平？》《重生 60 年代，但我是神豪》
- 作用：短剧封面吸粉之王

## 三、按番茄读者数据反推：本作最佳命名策略

### 核心原则（番茄男频都市 2024-2026 爆款共性）

1. **主角名在标题 top 3 字内**（如"北辰"/"顾北辰"）→ 读者前 3 秒识别
2. **至少含 1 个"**反转信号词**"**（如：真不是 / 没想到 / 装 / 其实 / 原来 / 居然 / 才知道）
3. **封面 15 字内**（标题过长封面压字）
4. **避开**"**我的**"开头（番茄 2024 后期已过饱和）
5. **带题材气质词**（都市用"岳父/老师/校董/帮主/少主"；文脉用"北辰/紫微/天师"）

### 本作命名三方向·最终推荐

#### 方向 1：**番茄主流 - 文脉爆款型**
**《北辰诀》**（⭐⭐⭐⭐⭐）
- 二字"北辰" + "诀"字（功法感 + 决裂感 + 爽文味）
- 短剧封面上一个"诀"字即可成为视觉中心
- 搜索唯一度最高
- 读者 3 秒知道：都市 + 命盘 + 爽文 + 文脉

#### 方向 2：**番茄短剧爆款型**
**《我爸把我扁担赶出家门，没想到我成了五家议会之首》**（⭐⭐⭐⭐）
- 规律 3 + 规律 8 混合
- 开场即结局 → 读者第一眼知道整本书故事弧
- 短剧封面可做"扁担老爹 vs 议会首席"分屏对比图

#### 方向 3：**番茄男频后宫型**（原方案 B 升级）
**《众星拱北辰》**（⭐⭐⭐⭐）
- 命理 + 后宫群像暗示（众星）
- 原推荐，保留
