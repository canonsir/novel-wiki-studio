## 一、原书名《我的荣耀》诊断

| 维度 | 评估 | 问题 |
|---|---|---|
| **记忆度** | ★★☆ | "我的荣耀"过于通俗 / 平淡；番茄 / 红果搜索排名难 |
| **性别识别** | ★★★★ | 偏男频 OK |
| **题材识别** | ★★ | 读不出是都市 / 爽文 / 门阀 / 命理，像军旅或青春文 |
| **爽感暗示** | ★★ | 没有"反转 / 逆袭 / 爽点"信号 |
| **短剧吸粉** | ★★ | 短剧封面上这个名字无视觉记忆点 |
| **文学格局** | ★★★★ | 终章答题的"荣耀"内核好 |
| **搜索重复** | ★☆ | 全网搜索与多本已有同名 / 近似书重合（王者荣耀、各种"荣耀"系列） |

**结论**：原名**作为内核词保留 OK**（终章答题就是"我的荣耀"），但作为**书名不够抓**。建议改。

## 二、改名策略

本书的四联坐标系（DEC-005）：
- 都市 **逆袭** + 打怪升级 + 爽文 + 后宫

本书的真实文脉底盘：
- **五家议会 / 杀破狼 / 北辰 / 顾家支系 / 淮军-湘军-漕运-内务府-北洋**

改名需要同时满足：
1. 读得出"**男主逆袭 + 门阀**"题材
2. **性别识别明确**（男主）
3. 带**视觉 / 命理 / 文脉**暗示
4. 短剧封面上有记忆点
5. 搜索不重合

## 四、作者 TOP 3 推荐（综合强推）

### 🏆 第 1 名：**《众星拱北辰》**

- **优点**：
  - 书名 = 全书叙事主轴（终章落地格局）
  - 《论语·为政》出处 → 文脉底盘的最直接体现
  - "**众星拱北辰**"七字自带画面感 + 命理暗示 + 后宫群像暗示（众星 = 后宫 + 兄弟 + 命盘）
  - 短剧封面可用"顾北辰 + 群星环绕"视觉设计
- **缺点**：
  - 比"北辰令"稍长；短剧封面字较密
- **可拆**：
  - 番茄小说版："《众星拱北辰》"
  - 短剧改编版："《我的荣耀：众星拱北辰》"（原名作为副标题保留）

### 🏆 第 2 名：**《北辰令》**

- **优点**：
  - 二字名短 / 冲击力强
  - 终章道具（九头兽 + 北辰令合铸）名实呼应
  - 短剧封面神器：一枚戒指 / 一面令 = 一个单画面传达全书内核
  - 搜索唯一度最高
- **缺点**：
  - 单独看"北辰令"读不出"都市题材"（像修仙 / 玄幻）
- **可拆**：
  - 《北辰令·门阀逆袭》副标题方案

### 🏆 第 3 名：**《老师，北辰来接光了》**

- **优点**：
  - 短剧吸粉型；灵魂 App "接光" + 师生错位 + "北辰"真名
  - 短剧封面写满钩子（师 / 生 / 匿名 / app）
  - 开场即戏，直接出流量
- **缺点**：
  - 书名太短剧化，长篇小说格局感不足
- **可拆**：
  - 短剧专用名："《老师，北辰来接光了》"
  - 小说正名："《众星拱北辰》"
  - **双名双发**：小说正名 + 短剧专用名各走各的渠道（最佳策略）
