# 蓉城

> 真实原型：成都（按硬约束虚构化，见 kb/china/geography-folk/real-to-fictional-map.md）。

## 真实文脉

- **袍哥文化**：哥老会发源地之一，"袍哥人家，绝不拉稀摆带"。
- **茶馆文化**：吃讲茶断纠纷；是城市人情网络的物理节点。
- **锦江码头**：历史漕运与现代物流叠加的中间地带。
- **青城山道教**：张天师创教地；主角后期武学/十二段锦的师门背景候选。

## 分区（故事定位）

| 区域 | 故事定位 |
|---|---|
| 城东 | 夜场文化：海迪 / 狼舞；大专校园周边；顾北辰起步 |
| 城南 | 老城区赌档：肥猫势力、皇城赌场；后期天下会统一 |
| 城北 | 批发市场 / 老派堂口：白袍会 / 卜立国 |
| 城西 | 房地产商业区：厉家产业压迫 |
| 城郊青城山 | 道家十二段锦师门候选 |
