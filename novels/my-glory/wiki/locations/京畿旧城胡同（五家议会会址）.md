# 京畿旧城胡同（五家议会会址）

- **真实原型**：北京老城胡同（虚化为『京畿旧城』）
- **故事定位**：S5-S6 议会舞台
- **关键细节**：一进院落 → 二进 → 三进；三进后堂设五席位

## 短剧 / 视频改编备注

灰砖红墙 + 檐角铜铃 + 五席位银 / 玉 / 铜 / 乌银 / 鹰徽戒摆列
