# Arc 1 c001-c030 scene-level 细纲

> 本页是 Arc 1 **开写前最后一张图**。每章落实到 scene 粒度，确保 30 章前后承接严丝合缝、爽点递进不断、伏笔链自然。

## 二、章节细纲（30 章，每章 1 段梗概 + 承接钩子）

### 【第一幕 · 相遇与反杀】c001-c005

#### c001 《白鹿的瞬间》✅ 已写

- **开场钩子**：顾北辰介绍自己名字 + 刷灵魂 App 星球广场
- **中段爽点**：接光 → 识破中间坐标被操纵 → 识破折叠刀仙人跳 → 认出美女老师
- **章末钩子**：**卡座里"九头兽戒指"持有人也在刷灵魂 App**
- **伏笔种**：九头兽戒指 / 灵魂 App 后台操纵 / 顾崇岳口诀"要去的地方先看周围站着什么人"

#### c002 《纸条上的名字》

- **承接**：从九头兽戒指持有人（厉擎苍）视角起笔 → 他看见顾北辰扶温书宁出门的侧影 → 嘴角冷笑
- **场景 1**：主角扶温书宁走出红屋 → 街角雨 → 温书宁第一次抬头看主角：**"你叫顾北辰？"**
- **场景 2**：温书宁递纸条 → 揭底：**温景同 500 万赌债 + 厉擎苍逼婚** → 温书宁："**你走。你走了，他找不到你**"
- **场景 3**：主角不走 → 继续送 → 街头有一辆加长车停住 → 下来一个西装男（厉擎苍手下严律师）→ "**温小姐，你该回去了**"
- **章末钩子**：严律师看主角的学生证 → 一张冷笑脸 → **"你叫顾北辰？好名字。顾家的北辰？"**（第一次本家姓氏被外人点名）

#### c003 《顾家的北辰》

- **承接**：严律师点出"顾家的北辰"→ 主角心里"**我爸是顾崇岳，一个在蓉城修自行车的老头**"→ 他是在装吗？
- **场景 1**：严律师带温书宁上车 → 走前对主角说"**明天你辅导员会找你**"
- **场景 2**：主角走回学校 → 第一次意识到父亲身份有问题 → 翻开自己钱包，看那枚父亲塞给他的黄铜钥匙（听澜轩钥匙伏笔种）
- **场景 3**：宿舍 → 程星野等着他 → 班级群已经炸了："**顾北辰约开校董家儿子未婚妻**"→ 爽点锚点："**星野拍桌：'我 cao，北哥这是把事干大了啊！'**"
- **场景 4**：半夜 → 温书宁用灵魂 App 匿名发第二条瞬间给主角 → "**今天的事，是我拖累你了**" → 主角回："**我爸从小把我往街头赶，没拖累一说**"
- **章末钩子**：第二天凌晨，主角宿舍门被敲响 → 辅导员王老师：**"顾北辰，跟我去办公室。有人等你。"**

#### c004 《处分通知下来之前》

- **承接**：辅导员带主角到办公室 → **严律师已经在了** → 一叠"学生处分申请"推到桌面上 → "**勒令退学**"
- **场景 1**：严律师出示咖啡厅卡座的监控截图（c001 没拍到的"九头兽戒指"持有人用灵魂 App 刷到了那条瞬间的证据）→ 主角："**那个人是不是叫厉擎苍？**"
- **场景 2**：严律师笑 → "**顾同学，你需要知道三件事：第一，厉擎苍先生和温老师已订婚；第二，温老师父亲欠厉家 500 万；第三，你和温老师昨晚的事，监控都有。**"
- **场景 3**：主角第一次爽点反击 → 以"**昨晚是温老师主动在灵魂 App 匿名发瞬间，我是接光的那一个**"反将一军 → 严律师："**那说明温老师的 app 使用记录没问题，接光的人才有问题**"
- **场景 4**：辅导员拉主角出门 → "**你爸是校董？不，北辰——你爸是谁？**"（第二次外人问"你爸是谁"）
- **章末钩子**：主角回宿舍 → 门口站着一个人 → 不是程星野 → 是**一个穿旧呢大衣的老头**，手里拎着一个黄铜算盘 → "**温书宁的父亲**"

#### c005 《听澜轩的旧算盘》

- **承接**：温景同站在宿舍门口 → "**顾同学，我能跟你聊一下吗？不是为了书宁，是为了你爸**"
- **场景 1**：温景同带主角到**听澜轩茶馆**（蓉城·城南老地标，S1-S3 情报据点伏笔种）→ 茶馆老板看温景同的眼神说明"**他是常客**"
- **场景 2**：温景同第一次揭：**"20 年前，我在京畿教过一个学生。他叫顾崇岳。"** → 主角震住
- **场景 3**：温景同："**我不知道你爸为什么被赶出京畿顾家。但他取名'北辰'——那不是普通人能取的名字。**" → 主角："**那是什么名字？**" → 温景同："**那是在等众星归位的名字。**"
- **场景 4**：温景同咳嗽 → 从兜里掏出一把黄铜算盘 → "**这是我年轻时教书用的。书宁小时候用这个学算术。你拿去。**" → 主角："**为什么给我？**" → 温景同："**因为你明天开始，要跟厉家打擂台。你需要一个计数的东西。**"
- **章末钩子**：主角回宿舍 → 手里的黄铜算盘沉得像一块铁 → 父亲顾崇岳居然是温景同的学生 → **第一次"父辈伏笔"启动**

### 【第二幕 · 退学危机与爸的号码】c006-c012

#### c006 《班群里的截图》

- **承接**：主角回宿舍，程星野在等他 → 班群已经疯传"顾北辰勾引老师"截图 + 温老师未来婆家声明
- **场景 1**：星野挡在主角前面怼班群喷子（兄弟情戏种）→ 爽点锚点：**星野的硬核直播反击**
- **场景 2**：第一次公开打脸信号——主角微博签到位用"**蓉城·听澜轩**"的定位发了一张黄铜算盘的照片 → **听澜轩**三个字在校园群里引起一个老师的注意（温书宁）
- **章末钩子**：温书宁用灵魂 App 匿名发第三条瞬间"**我爸见过你了。他说了什么？**"

#### c007 《第一次见温书宁的教室》

- **承接**：温书宁第二天到学校上课 → 主角专门去蹭她的课
- **场景**：课堂上温书宁讲古诗十九首"**行行重行行，与君生别离**" → 她的目光扫过教室最后一排的主角 → 第一次师生身份错位的公开场合
- **章末钩子**：下课铃响 → 温书宁走到最后一排 → "**顾同学，放学后听澜轩，我有话跟你说**"

#### c008 《温老师的真实身份》

- **承接**：听澜轩阳台 → 温书宁与主角对面坐着
- **场景**：温书宁第一次主动揭底："**我爸是你爸的学生。但我爸还有一件事没告诉你——**" → 揭开**温景同和顾崇岳在京畿的往事（父辈伏笔第二层）**
- **章末钩子**：阳台外的巷子里，一辆黑色奔驰慢慢停下 → **"厉家的车"**

#### c009 《律师第二次来》

- **承接**：严律师在听澜轩阳台外的车里喊话："**温小姐，厉少请您回去**"
- **场景**：主角与严律师第二次交锋 → 爽点锚点：主角用温景同给的黄铜算盘"算了一下"厉家欠温家的"20 年前京畿旧账"
- **章末钩子**：严律师脸色一变 → 掏出手机打给厉擎苍 → "**少爷，顾北辰知道旧账的事**"

#### c010 《我爸给了我一个号码》

- **承接**：主角终于回家 → 蓉城·城南小院 → 父亲顾崇岳坐在院子里修自行车
- **场景 1**：主角第一次问父亲："**爸，你是顾家的北辰吗？**" → 顾崇岳沉默半天 → "**我是顾崇岳。北辰是你**"
- **场景 2**：顾崇岳从口袋里掏出一张皱巴巴的纸条 → 一个电话号码 → "**这个人叫洪四海。你叫他海哥。他欠我一个人情。如果你被厉家逼到了墙根，去柳巷找他**"
- **章末钩子**：顾崇岳把扁担靠在墙上 → "**但我希望你永远不要用这张纸条。**"（反差 → 读者立刻知道一定会用）

#### c011 《处分通知书到了》

- **承接**：主角回宿舍 → 辅导员已经把处分通知书送到宿舍门口
- **场景**：主角一边读通知书一边笑 → 星野："**北哥你笑什么？**" → 主角："**我爸给了我一个号码。**"
- **章末钩子**：主角掏出手机 → 拨海哥的号码 → "**喂，海哥吗？我是顾崇岳的儿子，顾北辰**"

#### c012 《柳巷见海哥》

- **承接**：主角从电话里接到"**今晚八点，柳巷老张家烧烤**"
- **场景 1**：主角到柳巷 → 建国哥烧烤摊 → 后巷楼上房间 → 海哥坐在里面抽烟
- **场景 2**：海哥第一句："**你和顾崇岳一个模子刻的。**" → 第二句："**你爸救过我一命。现在轮到我还你。**"
- **场景 3**：海哥 + 主角 第一次打配合——用海迪夜场的渠道 → 把厉擎苍的"500 万赌债协议"在**地下交易圈的黑名单登记**（爽点锚点：江湖信用机制）
- **章末钩子**：海哥的手下冲进房间 → "**海哥，不好了，温老师的爸出事了。**"

### 【第三幕 · 温景同病倒与赌场救美预埋】c013-c020

#### c013 《温景同病倒》

- **承接**：主角 + 海哥冲到温书宁家 → 温景同倒在书房地上
- **场景**：120 到医院 → 医生查出"**慢性药品瘾引发的内分泌紊乱**"（画面感收敛：不写药品细节，只写**事后症状**）
- **章末钩子**：主角看见病房外角落里站着一个穿西装的人 → **严律师**

#### c014 《医院走廊的对峙》

- **承接**：主角走出病房 → 严律师在走廊
- **场景**：严律师："**顾同学，500 万，一次性支付，温老师父亲就能治好。我们厉家不是没有诚意**"
- **章末钩子**：温书宁从病房出来 → 她的眼里第一次没有克制 → "**滚**"

#### c015 《温景同叫出"崇岳"》

- **承接**：半夜病房 → 温景同醒来 → 看见主角在床边
- **场景**：温景同迷迷糊糊："**崇岳……你怎么来了……**"（第一次把主角认成父亲）→ 温书宁在旁边震了一下 → 她第一次看着主角说"**你爸真的是我爸的学生**"
- **章末钩子**：温书宁的手机响 → 她接 → 挂 → "**是厉擎苍。他说明天来医院看望'岳父'**"

#### c016 《第一次反杀预热》

- **承接**：主角回宿舍 → 跟星野 + 海哥 开"**明天怎么办**"会议
- **场景 1**：海哥教主角"**先占道义制高点，再出手**" → 爽点锚点：**江湖规矩第一课**
- **场景 2**：主角在灵魂 App 匿名发瞬间（第一次主角主动用 app）→ "**蓉城·城南某医院，有个 500 万的赌债，有人想用它绑婚。要不要来当个见证？**" → **情绪标签"看戏"**
- **章末钩子**：这条瞬间 24 小时内接光 100+ → 其中有**蓉城·城北白袍会卜立国老爷子**（S2 伏笔种）

#### c017 《医院反杀厉擎苍（第一次爽点大戏）》

- **承接**：早上 10 点医院走廊 → 厉擎苍带着严律师和保镖来
- **场景 1**：厉擎苍进病房 → 温景同闭眼不理 → 温书宁冷着脸站着
- **场景 2**：厉擎苍扫一眼 → 看见病床边站着主角 → "**顾同学，你怎么在这？**"
- **场景 3**：主角打开手机 → 把海哥连夜让蓉城地下交易圈拉的"**500 万赌债黑名单证据**"投到病房电视上
- **场景 4**：厉擎苍脸色大变 → 严律师想抢遥控器 → 海哥的人堵在门口
- **爽点锚点**：主角一句话"**厉少，你爹的 500 万赌债，蓉城地下已经公投作废了。按江湖规矩，温老爷子的债，解除了。**"（公开打脸 1）
- **章末钩子**：厉擎苍冷笑 → "**顾同学，你'爸'的位置，我倒要看看是不是真这么稳**"（第一次外人暗示主角的"爸"是真有背景）

#### c018 《厉擎苍电话给厉天鸿》

- **承接**：厉擎苍走出医院大楼 → 掏出手机打给父亲厉天鸿
- **场景**：厉擎苍："**爸，蓉城地下圈子集体给顾北辰撑腰。他爸到底是什么人？**" → 厉天鸿冷冷回："**查**"
- **章末钩子**：厉天鸿掉下电话 → 走到窗边 → 看着蓉城的夜景 → **一句自语：'顾崇岳……你的儿子长大了'**（真·父辈伏笔）

#### c019 《温书宁第一次来家》

- **承接**：主角回蓉城·城南小院 → 温书宁跟着来
- **场景**：顾崇岳在院子里修自行车 → 看见温书宁 → 愣住 → "**你……你是温景同的女儿？**"
- **爽点锚点**：**父辈相认**（后台空降型爽点，不是打脸，是温情型）
- **章末钩子**：顾崇岳走进屋 → 拿出一本旧书 → **《淮军铭字营记事》**（真实文脉底盘首次出现）

#### c020 《淮军铭字营》

- **承接**：顾崇岳翻开书 → 第一页是一张合影 → 父亲年轻时和 20 个人站在一起
- **场景**：顾崇岳第一次向主角讲**顾家在京畿的真实身份** → 爽点锚点：**身份揭底第一层**（主角身份升级）
- **章末钩子**：顾崇岳合上书 → "**但是北辰，我希望你永远不要去京畿**" → 门外有人敲门 → 是**穆清岚**（女警，c020 首次登场）

### 【第四幕 · 500 万代偿 + 退学钩子】c021-c030

#### c021 《女警穆清岚的档案》

- **承接**：穆清岚亮出警官证 → "**顾崇岳同志，蓉城·城南派出所。有一份档案要给您核实**"
- **场景**：穆清岚私下跟主角："**我以前读过你爸写的那本书。有一件事你爸没告诉你——你爸被京畿顾家驱逐，是因为护住了一个人**"
- **章末钩子**：穆清岚："**那个人叫裴云归。你妈。**"（主角母亲线启动）

#### c022 《妈妈的乌银手链》

- **承接**：主角回屋问父亲 → 顾崇岳沉默半天 → 从柜子里拿出一个铁盒
- **场景**：铁盒里是**乌银手链**（裴家内族女性信物，S1 伏笔种）→ 顾崇岳："**你妈是裴家的人**" → 主角第一次知道自己有裴家血脉
- **章末钩子**：乌银手链上刻着一个字——**"归"**（裴云归的"归"字）→ 顾崇岳："**但她离开你的时候，只带走了一半的手链。另一半，我不知道在谁手里**"

#### c023 《鬼组杀手试探》

- **承接**：第二天 → 主角在学校门口被一个黑衣女人拦住
- **场景**：女人出示一枚"**乌银令碎片**"（另一半手链的变体伏笔）→ "**我是裴家的。你妈的手链另一半，你想要吗？**" → 爽点锚点：**身份揭底第二层**
- **章末钩子**：女人消失前留下一句："**三天后，蓉城·皇城赌场。你温老师的爸的 500 万，是谁给平的？——你以为是你，还是另有其人**"

#### c024 《海哥查到真相》

- **承接**：主角冲到海哥的狼舞 → 海哥已经查完
- **场景**：海哥："**那 500 万，的确是有人替温老爷子代偿了。但是不是我们。**" → "**是谁？**" → 海哥："**是**我**查不到的级别。只有一种可能——是京圈。**"
- **章末钩子**：海哥递来一张纸 → "**代偿人只留下一个标记：**九头**。**"

#### c025 《九头兽的意义》

- **承接**：主角回宿舍 → 翻开父亲给的《淮军铭字营记事》
- **场景**：书后附一张山海经图页 → **"九头相柳"** → 父亲在旁边批注："**此为京圈灰色资本的旧标。护信者戴之，吃人者亦戴之**"
- **章末钩子**：主角回想 c001 咖啡厅卡座里的**九头兽戒指** → 一秒"**我去年买了个表**"

#### c026 《柳巷夜话》（海哥+星野+九思+主角 四人聚）

- **承接**：主角把所有线索摆到柳巷烧烤摊
- **场景**：**贺九思（半仙）首次登场**（通过海哥引线，S2 伏笔提前种到 Arc 1 末）→ 四人（主角 + 海哥 + 九思 + 星野）第一次聚
- **章末钩子**：贺九思掏出一张**蓉城势力分布图** → "**蓉城三方。城西厉家。城东海迪。城北白袍。你站哪一方？**"

#### c027 《温书宁被绑预埋》

- **承接**：主角还没来得及回答 → 温书宁电话 → "**你……你快来，有人在我家楼下**"
- **场景**：主角 + 海哥 + 星野 冲到温书宁公寓 → 公寓门开着 → 温书宁不见了 → 只留下一枚**蓝色硬币**（后期揭：皇城赌场筹码）
- **章末钩子**：主角捡起硬币 → "**皇城赌场。**"（Arc 2 预埋 → 其实留到 Arc 3 皇城赌场戏）

#### c028 《温书宁短暂逃回》

- **承接**：半小时后 → 温书宁独自回到公寓
- **场景**：她回来的时候眼里有光 → "**我没被绑。是我爸让我做了场戏。他说……他说让顾北辰知道，'退路是永远有的'**"
- **爽点锚点**：**温书宁第一次主动做戏保护主角**（关系升级信号）
- **章末钩子**：温书宁递来一个**听澜轩的旧钥匙** → "**我爸让你去听澜轩找一样东西**"

#### c029 《听澜轩的旧账簿》

- **承接**：主角用钥匙打开听澜轩阳台上的一个旧抽屉
- **场景**：抽屉里是一本**旧账簿** → 记录了"**20 年前京圈顾家被谁陷害的全部明细**" → 主角第一次知道**父亲是被谁逼走的**（父辈伏笔第三层）
- **章末钩子**：账簿最后一页写着——"**裴云归之死，非自然**"

#### c030 《退学 + 500 万代偿 + 帝都电话》（Arc 1 大结局）

- **承接**：主角捧着账簿回宿舍 → 门口躺着三样东西
- **场景 1**：**勒令退学通知书**（学校盖章）→ 爽点锚点：主角撕了（公开打脸信号）
- **场景 2**：**一份 500 万代偿协议**（代偿人署名"**九头**"）→ 爽点锚点：主角不签，但折成飞机扔出窗外
- **场景 3**：主角回家 → **父亲顾崇岳正接着一个电话** → "**是……我知道了……北辰马上会去**" → 挂了电话
- **场景 4**：顾崇岳回头 → "**北辰，京畿顾家来人了。你姑奶奶明天到蓉城。她要见你**"
- **章末钩子**（Arc 1 → Arc 2）：**三件事同时发生**：
  1. 温书宁的父亲温景同第二次下药昏迷
  2. 皇城赌场放话"3 天后，温老师的父亲欠债要平"
  3. **京畿顾家的姑奶奶抵达蓉城**（S5 本家对质 Arc 的第一位引路人）
