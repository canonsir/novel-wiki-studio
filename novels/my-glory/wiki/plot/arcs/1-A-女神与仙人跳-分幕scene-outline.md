## 二、第二幕 c008-c016 完整 scene outline + grill-me 六问

### c008 《医院走廊的墨绿领巾》(POV:顾北辰)

**scene 粒度**
- scene 1:主角冲到蓉城·城南人民医院急诊 → 温书宁已经先到 → 墨绿领巾被雨淋湿 → 温景同在抢救室 → 心电图线上下不规则
- scene 2:主角守在抢救室外 → 温书宁从主角 T 恤的下摆上抓到一处——这一次她没抬手就抓了 → 这是"**担**"关系升级的第一次肢体信号
- scene 3:严律师严振声出现在急诊走廊尽头 → 他手里没拎他的老派小皮箱 → 他第一次穿**便装**:灰色高领毛衣 + 深色大衣 → 他在走廊灯下走过来

**章末钩**:严振声走到主角和温书宁面前,**说第一句话**——"**顾先生,温小姐,这不是厉少让我来的。**"(第一次严振声**不以厉家代表**身份出现)

**grill-me 六问**:
1. **motivation_now**:温书宁为何先到 → 她在 c007 末接到医院电话时主角还在听澜轩阳台;她先走,主角 15 分钟后到(交通线合理)
2. **resource_from**:严振声为何来 + 为何便装 → 他是**董三爷**的徒弟(c005 已埋);今日早八点那通电话里"**未命名 ID**"是顾崇信,但真正拨号给王老师的是严振声**替顾崇信**打的——他知道整件事的轨迹;今晚他的**便装**来访是他**个人意愿**,不是厉家派
3. **opponent_counter**:厉擎苍为何不派人到医院挡 → 厉擎苍昨晚在红屋咖啡厅卡座被识破后,**今早**他已经通过严振声知道"**认账**"事件;他对父亲厉天鸿的汇报还没出结果;**24 小时内**他不会先出手,只会**观察**(c018 scene outline 已暗合)
4. **cost_of_win**:主角到场的代价 → 他**没能看温景同最后一眼清醒**(温景同已经昏迷);他对**温书宁的"担"关系**升级,但他**完全失去了对父亲顾崇岳的联系**(c003 空号 → 今晚未回建设巷)
5. **info_how_known**:温书宁手机里是谁的电话 → 她爸的**私人保姆**(c007 已暗示温景同在书房昏迷倒地)
6. **state_continuity**:章首回响 c007 末"**蓉城·城南人民医院 急诊 昏迷**" ✅

### c009 《严振声的三页纸》(POV:顾北辰)

**scene 粒度**
- scene 1:医院走廊 → 严振声递主角三页纸 → 第一页是**乙丑年冬·老三房京畿失踪事件 · 老派人家内部口供档案**;第二页是**丁亥年秋·温景同签欠条**原件照片(**不是**温书宁手里那张,是**厉家内部版**);第三页是**今晚** → 一张**九头兽戒指**的样图(厉擎苍私戴 vs 厉天鸿公戴的差异对照)
- scene 2:严振声说:"**顾先生,这三页纸给您之后,我和厉家的关系就断了。我不是来倒戈的。我是来替董三爷还乙丑年秋那笔老账的**。"
- scene 3:主角问:"**你为什么现在给我**?" → 严振声答:"**因为今早在您开口'认账'之后,老派人家欠您一个说法。**老派人家**的说法,不能等到您明天上阳台**之后**给——必须在您上阳台**之前**给**。"
- scene 4:主角用黄铜算盘拨了一下 → 他对严振声说:"**三页纸我收。但是**明天上阳台**我**不**用它。**"

**章末钩**:严振声合上他的大衣:"**顾先生,如果您明天上阳台不用这三页纸,那您用什么?**" → 主角从 T 恤口袋里掏出那把**黄铜钥匙** → "**我用**听澜轩阳台**第三根竹柱底下**的那本**旧账簿**。**"

**grill-me 六问**:
1. **motivation_now**:严振声为何今晚断关系 → 他是董三爷徒弟(c005 已埋);"**认账**"事件后,老派人家内部的礼制启动,**他必须选边**;他选"**替董三爷还乙丑年秋旧账**"
2. **resource_from**:三页纸从哪来 → 严振声是厉家首席老派文书,**他本来就持有这三份档案**(他在厉家内部 20 年的位置);他只是把它从**厉家卷宗室**拿出来
3. **opponent_counter**:厉天鸿为何不先销毁三页纸 → 厉天鸿**今早**正在京畿和顾崇信通电话,他的注意力在"**顾崇岳的儿子真会认账**"这件事上,还没到"**档案室清理**"这一步;**12 小时**延迟窗口合理
4. **cost_of_win**:主角今晚收下三页纸的代价 → 他从此与厉家**正式结仇**(不是暗线,是明面);温景同的 500 万账务进入"**老派人家内部清算**"流程,**他替温景同背了明面责任**
5. **info_how_known**:主角如何知道旧账簿的存在 → c004 温景同在听澜轩阳台亲口说过"**听澜轩阳台第三根竹柱底下的抽屉**" ✅
6. **state_continuity**:章首回响 c008 末严振声"**这不是厉少让我来的**" ✅

### c010 《听澜轩旧账簿·第一次打开》(POV:顾北辰)

**scene 粒度**
- scene 1:主角从医院出来 → 不回宿舍 → **直接**打车去听澜轩 → 时间是深夜 23:40 → 听澜轩已经关门 → 阳台灯还亮着
- scene 2:老板是蓉城·城南老派人家的**第三代**守门人 → 他看见主角,**没问**,**直接**让他从后门上阳台
- scene 3:主角走到阳台 → 第三根竹柱底下 → 他用黄铜钥匙 → 旧抽屉打开 → **里面只有一本旧账簿**
- scene 4:账簿第一页:**乙丑年秋·景同自书 · 顾崇岳在京畿家塾的学员名单** → 顾崇岳是唯一一个被单独圈出来的名字
- scene 5:账簿第二页:**乙丑年冬·景同自书 · 顾崇岳失踪当日的目击记录** → 温景同亲笔:"**崇岳走时,留下黄铜算盘。他说以后让他的儿子来还。他的儿子现在应该还没出生。但是我等**。**"
- scene 6:账簿第三页:**丁亥年秋·景同自书 · 五百万担保单签字当日** → 温景同亲笔:"**今日签字,替老三房顶半截。另外半截,留给崇岳的儿子。**崇岳**的儿子**今年**十九岁,**在蓉城某三流大专**读大二**。**他**叫**顾北辰**。**"
- scene 7:主角合上账簿 → 他发现——温景同**五年前**就知道他顾北辰的名字 → 温景同**五年前**就在**等**今天

**章末钩**:账簿最后一页**是空白的** → 空白页上有一行**最新的墨迹**(**今早**写的) → 温景同亲笔:"**北辰,今日起,我**替**崇岳**押最后一步。你**替**我**押**最后一步。**"

**grill-me 六问**:
1. **motivation_now**:主角为何今晚直接去听澜轩 → c004 温景同说过"**明天辅导员办公室之后再回来打开**";但今晚温景同已经昏迷,**明天**可能来不及;主角**提前**打开合理
2. **resource_from**:听澜轩老板为何让主角直接上去 → 老板是**守门人**第三代 → 他认识温景同 → 他认识**黄铜钥匙**的样式(老派人家内部识别物)
3. **opponent_counter**:为何没有厉家 / 顾崇信的人提前在听澜轩等 → 听澜轩是**老派人家内部地标**,**不是**厉家 / 顾崇信的地盘;顾崇信明天上阳台**才算**上门,**今晚**不能先派人(**老派礼制**)
4. **cost_of_win**:主角提前打开账簿的代价 → 他**破坏**了温景同"**明早再打开**"的节奏;**但**他**也**赢得了"**明早上阳台时手里有牌**"的筹码
5. **info_how_known**:温景同"**五年前**就知道主角名字" → 读者需要**信息来源**:c007 温书宁揭"**乙丑年秋五人合影**",**老三房 → 温景同** 本来就有通讯线(c007 scene 3 已暗示温景同和顾崇岳有**父辈通讯**);温景同**五年前**从顾崇岳处得知儿子叫顾北辰,合理
6. **state_continuity**:章首回响 c009 末主角"**我用听澜轩阳台第三根竹柱底下的那本旧账簿**" ✅

### c011 《老榕树底下的父亲》(POV:顾北辰)

**scene 粒度**
- scene 1:主角从听澜轩阳台下来 → 时间是凌晨 01:30 → 听澜轩门口老榕树底下 → **一个穿旧呢大衣的老头**在树底下站着
- scene 2:主角走近 → **是他爸**顾崇岳 → 他爸穿的是**老派人家**的**第二代守门人**服(c010 的听澜轩老板是**第三代**;顾崇岳是**第二代**)
- scene 3:顾崇岳对主角说:"**北辰,**我**就**知道**你**今晚**会提前打开**。**所以**我**今晚**先**在**这里等**。**"
- scene 4:主角第一次问:"**爸,你是老三房的嫡长子吗?**" → 顾崇岳沉默半天 → "**我是**。**我**也是**乙丑年冬**从京畿失踪的那个人**。**但是**今晚**在**这里**的我**,**不是**老三房**的**嫡长子**。**是**你**老子**。**"
- scene 5:主角第一次问:"**爸,**明天**顾崇信上阳台**,**我**要**怎么**办**?**" → 顾崇岳说:"**北辰**,你**不是**顾崇信**的**堂侄**。**你**是**我顾崇岳**的**儿子**。**你**不**按**老派礼制**上阳台**。**你**按**你**自己**的**'**认账**'**上阳台**。**"
- scene 6:顾崇岳**走**了 → 他**走**之前**对**主角说**:"**北辰**,**明天上阳台**之前**,**先**上**蓉城·城南**人民医院**。**老温**醒**不醒**不是你**能决定**的**,**但是你**可以**让**他**醒**着**的时候**知道**——**你**不是**替**我**押**最后**一步**。**你**是**替**老温**押**最后**一步**。**"

**章末钩**:主角站在老榕树底下 → 他**父亲**消失在**雨里** → 他**手里**握着**那本旧账簿**和**三页纸**和**黄铜算盘** → **他**第一次**在**他爸**离开**的**雨里**说:"**我去年买了个表**。**"(**父亲的暗号在**雨里被儿子**接下来**)

**grill-me 六问**:
1. **motivation_now**:父亲为何今晚现身 → 他**今早**离开建设巷之后,一直**在**老派人家**内部走动**;c004 温景同说"**他给我打了第二个电话 没在**",**说明**他**早上**打过**第二**个电话**没打通**;**今晚**他**在**听澜轩门口**等**,**是因为**他**预判**到**主角会提前打开账簿**
2. **resource_from**:父亲为何有**第二代守门人**服 → 他**乙丑年冬**从京畿失踪,**是**到**蓉城·城南**听澜轩**托庇**的 → 他是**听澜轩守门人**第二代(本章首次揭底,c019 父辈相认强化)
3. **opponent_counter**:顾崇信为何不派人在**听澜轩门口**等 → 老派礼制:**阳台**是**正堂**,**门口**是**街**;**对手**不能**先**守**在**街**上(c010 已埋同一礼制)
4. **cost_of_win**:父亲今晚见面的代价 → 他**破坏**了"**先消失再出现**"的口诀;**他**选择**今晚**出现**,是因为**他**知道**明天上阳台**他**不能**出现**(**顾崇信**上阳台**时**,**父亲**不能**在场**——否则**老三房**嫡长**身份**会**被**顾崇信**反打**成**"**父辈**同在**算什么**认账**")
5. **info_how_known**:父亲**凭什么**知道**主角今晚会去听澜轩 → 父亲**知道**温景同**今早**走**之前**托**书宁**转告"**顾北辰替我押最后一步**"(c007);父亲**知道**温景同**今天**病倒(**老派人家**信息网**自动**传递);父亲**预判**合理
6. **state_continuity**:章首回响 c010 末温景同"**北辰,今日起,我替崇岳押最后一步。你替我押最后一步**" ✅

### c012 《清晨回医院》(POV:顾北辰)

**章末钩**:主角出病房 → **走廊**那一头 → 三个人**正**在**走来** → 第一个是**董三爷**(c005 的那位老派人家退休文书);第二个是**韦老**(c007 乙丑年秋五人合影里最左边那位南都书画行);第三个是**顾崇信**(**第一次**正面出场)

**grill-me 六问**:
1. **motivation_now**:主角清晨为何回医院 → 父亲 c011 末的叮嘱 ✅

3. **opponent_counter**:顾崇信为何**提前**到医院 → **老派礼制**:**对手**在**上阳台之前**可以**先探望病人**;顾崇信**今早**先探望温景同是**老派人家**的"**同门友见病**"礼制(**不是**提前出手)
4. **cost_of_win**:主角清晨回医院的代价 → 他**失去**了**独自**上阳台的筹码;**顾崇信**在**阳台**之前**先见面**,**打乱**主角原定的"**在阳台正面对决**"节奏
5. **info_how_known**:温景同"**崇岳,我等你二十八年**" → c004 已埋"**他等了二十八年**" ✅
6. **state_continuity**:章首回响 c011 末父亲叮嘱 ✅

### c013 《三老站在走廊尽头》(POV:顾北辰)

**scene 粒度**
- scene 1:医院走廊尽头 → 三老走近
- scene 2:董三爷**第一次**对主角**鞠躬**(c005 他只对主角**颔首**;今日**升级**为**鞠躬** — 他承认主角**老三房嫡长**的身份)
- scene 3:韦老**第一次**正面出场 → 他从南都来 → 他对主角说:"**顾少爷,**我**年轻**时**在**乙丑年秋**听澜轩**认过**令尊**。**今天**我**从**南都**来**,**是**替**南都书画行**对**乙丑年秋**那笔**旧账**作证**。**"
- scene 4:**顾崇信**第一次正面说话 → "**北辰堂侄**,**你**昨天**在**辅导员办公室**说**的那句**'**认账**',**我**听**到**了。**今天**我**不**是来**审**你**。**我**是来**问**你**三件事**。**"
- scene 5:主角没动 → 他说:"**崇信堂叔**,**三件事**,**到**阳台**上**问**。**不**在**走廊**。**"
