# 灵魂 App

- **类型**：匿名社交平台（本书世界观内的虚构品牌）

本书世界观中的匿名社交 App。为规避真实品牌植入（见 `common/constraints/platform-redfruit-checklist.md` L49、`common/constraints/national-redlines-checklist.md` L48），本作全程使用虚构品牌名**"灵魂 App"**。

> **叙事口径升级（2026-10-10）**：本作放弃原稿"**漂流瓶**"这一过时玩法叙事（漂流瓶是微信/QQ 2010 年代旧机制，年代感不符合本作设定）。改用灵魂 App 自有的三件套功能作为主叙事机制：**瞬间 / 星球广场 / 灵魂回响**。

## UI 元素特征（可视化锚点）

- **主色调**：**暗紫 + 星光蓝**（契合"灵魂"概念）
- **用户头像**：默认为**随机行星图标**（木星 / 土星 / 冥王 / 海王 / 天狼 / 牵牛 / 织女 等；用户升级后可自定义星球）
- **用户资料**：昵称 + 一句话简介 + 情绪标签（如"烦闷 / 想找人聊天 / 深夜无眠"）
- **主色元素**：所有互动都以"星光流转"动画表达，而非普通社交 App 的点赞红心

## 核心玩法三件套（改编版定稿）

### 1. 瞬间（Moments / 匿名动态）

- 用户以**行星昵称**发布文字 / 短视频 / 语音；最长 180 字 / 60 秒
- 瞬间自动打上**定位标签**（如"蓉城·城南"），但不显示精确坐标
- 瞬间 24 小时后进入"星云库"（不再出现在广场，但可通过搜索找到）
- 瞬间支持**情绪标签**：烦闷 / 深夜无眠 / 想找人聊天 / 不想一个人 / 想认识新朋友

### 2. 星球广场（信息流 / 发现）

- 按同城 + 情绪标签 + 匹配度向用户推送**同城用户的瞬间**
- 用户可以**灵魂回响**（匿名语音回复，60 秒内）或**星光点亮**（匿名心动）
- 广场的页面像一张星空图，瞬间以**行星泡泡**的形式漂浮

### 3. 灵魂回响（匿名速配）

- 对一条瞬间发起**灵魂回响**（60 秒匿名语音）
- 发送方和接收方双方都是行星昵称，看不到真实身份
- 若接收方选择**"接光"**（即接受回响），则进入 10 分钟的匿名语音通话
- 通话结束后双方可选择"**同轨**"（继续加好友 + 交换联系方式）或"**散落**"（结束，互不留痕）

### 4. 灵魂约见（Offline Mode）

- 同轨后的两位用户可以申请"**灵魂约见**"模式
- 系统分配一个**中间坐标**（基于双方定位算法），双方同时同意后才解锁对方的大致位置
- 约见模式启动后，彼此可以看到对方到达进度（距离公里数 / 预计到达时间）
- 本机制在剧情中用于温书宁与顾北辰的开篇见面

## 剧情功能

- **开篇 Hook**：温书宁深夜以行星昵称"**白鹿**"发布一条瞬间——"**人生无奈，放纵一次。同城谁接光，就和谁见。**"情绪标签"**不想一个人**"。主角顾北辰（昵称"**北辰**"，默认未改）在星球广场刷到后发起**灵魂回响**（60 秒语音），接光，同轨。
- **伏笔载体**：
  - "白鹿"昵称——与温书宁后期的"学术气质 + 文学素养"形成一致（鹿鸣 / 鹿柴 / 文人意象）
  - 顾北辰未改昵称——留下"**顾北辰**"真名可被反向搜索的隐患（S2 鬼组通过这个线索交叉验证主角身份）
  - "灵魂约见"的中间坐标机制——解释为什么两人约在红屋咖啡厅（既不是温书宁地盘，也不是顾北辰地盘）
- **S2 深化**：鬼组霍惊鸿第一次接触主角时，使用的也是灵魂 App（代号"**叉**"）。两人隔着 app 对话多日后才线下见。
- **S3-S4 退场**：主角与温书宁 / 霍惊鸿关系确认后，灵魂 App 作为叙事工具功能性退场，但保留为"回望初识"的回环道具。

## 合规注意

- 不以本 App 名义鼓励"陌生人约见 → 真实见面"行为；叙事中温书宁的约见是"走投无路的例外"，而非平台正常用法。
- 不写具体注册 / 实名 / 账户破解细节。
- 本品牌与现实中任何真实 App 无关；在后续章节中若需提及公司背景，统一虚构为"灵枢科技（上海）"。
- 不以本 App 的具体技术细节（算法 / 匹配机制 / 推送权重）作为可复刻的产品教程。
