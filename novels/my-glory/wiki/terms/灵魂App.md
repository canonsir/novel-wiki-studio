# 灵魂 App

- **类型**：匿名社交平台（本书世界观内的虚构品牌）

本书世界观中的匿名社交 App。开篇"漂流瓶约见"机制所在的平台。为规避真实品牌植入（见 `common/constraints/platform-redfruit-checklist.md` L49、`common/constraints/national-redlines-checklist.md` L48），本作全程使用虚构品牌名**"灵魂 App"**。

## UI 元素特征（可视化锚点）

- 主色调：**暗紫 + 星光蓝**（契合"灵魂"概念）
- 核心玩法：
  - **漂流瓶**：匿名投放文字 / 语音；24 小时自动消失
  - **心动匹配**：双盲算法推荐
  - **匿名聊天**：主叫方头像默认为**随机动物图标**（兔 / 狐 / 猫 / 鹿 / 鲸）
- 用户资料：昵称 + 一句话简介 + 情绪标签（如"烦闷 / 想找人聊天 / 深夜无眠"）

## 剧情功能

- **开篇 Hook**：主角顾北辰捞到温书宁扔出的"放纵一次"漂流瓶，构成全书第一组师生错位 + 身份差。
- **伏笔载体**：后续被厉家 / 鬼组用于交叉验证温书宁身份（S2 中段）。

## 合规注意

- 不以本 App 名义鼓励"陌生人约见 → 真实见面"行为；叙事中温书宁的约见是"走投无路的例外"，而非平台正常用法。
- 不写具体注册 / 实名 / 账户破解细节。
- 本品牌与现实中任何真实 App 无关；在后续章节中若需提及公司背景，统一虚构为"灵枢科技（上海）"。
