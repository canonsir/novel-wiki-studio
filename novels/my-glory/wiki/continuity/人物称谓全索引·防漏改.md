# 人物称谓全索引·防旧名残留

> 本页解决一个高频坑：改名表 continuity-naming-map 只记录了"主名→主名"，但人物在原稿中常以**小名 / 外号 / 简称 / 口头称呼 / 戏称**出现（如夏梓妍→夏老师、夏某某），这些别名很容易在改编中漏掉，导致旧名残留。
>
> author-agent 每写完一章，**必须以本页为 lint 对照表**自检；reviewer-agent 发布前再过一遍。
> 本页的"禁止词"列不得出现在正文 / 现行 wiki（raw/ 只读除外）。

---

## 一、使用方法

每章落稿前运行：

```bash
# S1 开写时将增加该脚本
python3 scripts/lint_sensitive.py novels/my-glory --check-naming
```

脚本会扫描所有"禁止词"列中的旧名、旧外号、旧简称。命中即报错。

## 三、常见坑场景清单

### 3.1 对白中的称呼坑

❌ "**夏老师**，你快走。"（原稿第 4 章）
✅ "**温老师**，你走。"

❌ "**李少**，别过来！"
✅ "**厉少**，别过来！"

❌ "**南哥**，你收拾得这么人模狗样打算去哪？"（原稿第 1 章）
✅ "**北哥**，你收拾得这么利索要出门？"

❌ "**张星**堵着宿舍门……"
✅ "**星野**堵着宿舍门……"

### 3.2 道具 / 文书 / 卷宗坑

- **学生证**：原稿写"陈照南"→改编必须写"顾北辰"
- **档案 / 户口 / 身份证**：主角身份文件按 Wiki 定名
- **父辈信件 / 回忆**：涉及顾崇岳 / 裴云归时，不得混入"陈正坤 / 赵云归"
- **校园处分通知 / 教务文书**：涉事学生姓名、老师姓名都要对齐

### 3.3 回忆 / 内心独白坑

- 主角回忆童年"妈妈叫我"→用"阿辰"（父亲口头）或"北辰"
- 主角回忆父亲——用"爸"或"顾崇岳 / 老顾"，不写"陈家"
- 女主回忆父亲——用"爸"或"温景同 / 温父"，不写"夏家 / 老夏"

### 3.4 媒体 / 公告 / 校园网坑

- 班级群、校园公告、娱乐新闻、报纸标题、警方卷宗、议会记录——全部按新名
- 原稿第 3 章"校园网视频"涉及主角本名——必须改为新学籍

## 五、每章 lint 清单（强制）

- [ ] 本章所有角色称呼是否对齐"允许称谓"列？
