# 玄鉴台

## 基本资料

| 项 | 内容 |
|---|---|
| 机构名 | 玄鉴台 |
| 性质 | 国家一级非公开监察机构；对"门阀级 / 江湖级非法人团体"做合法-非法边界的审查与裁定 |
| 行政序列 | 不走司法 / 不走公安 / 不走国安；直接向最高一级汇报 |
| 规模 | 核心编制约 200 人；外线观察员 500+ |
| 总部 | 帝都西山之麓（虚构） |
| 成立年代 | 虚构年代（约 20 年前）|

## 命名出处

- **玄**：出自《道德经》"**玄之又玄，众妙之门**"——幽深 / 看不透 / 窥测万物
- **鉴**：察 / 镜 / 评判（如"借古鉴今"）
- **台**：中国历史上一级机构名惯例（钦天台 / 御史台 / 鉴察台）

本作借此意象：玄鉴台的职能即**从暗处审视浮于水面以上的权力结构**——门阀 / 组织 / 跨国资本的"合法性边界"由玄鉴台裁定。

## 职能

1. **审查**：对门阀 / 江湖 / 跨国资本的运作做合法性评估
2. **裁定**：对不合规部分提出"合规化改造"方案（而非强制取缔，为"柔性制度化"）
3. **外线**：在国家不方便公开出面的场景作中介（如五家议会改制）

## 组织结构

- **玄鉴主**：机构一把手，身份不公开；对最高一级直接汇报
- **三司**：
  - **玄察司**：情报 / 外线观察员
  - **玄裁司**：合规判定 / 法律团队
  - **玄行司**：行动执行队（仅在裁定成立后动用；非警察 / 非军队）
- **外线观察员**：遍布商业 / 江湖 / 文化圈的"冷眼人"

## 剧情功能

### S6d Arc 17 「五家议会洗牌」· 正式进场

- **进场时机**：Arc 17 开场
- **进场方式**：以 **"玄鉴台代表"** 身份进入五家议会秋分正会
- **功能**：
  - 推动五家议会从"门阀黑箱"向"**国家监管透明机构**"的制度化改造
  - 不强行取缔，而以"合规化改造"作为折中方案
  - 为顾北辰"北辰之位"的最终合法化提供国家背书

### 伏笔链：项玄冥 ↔ 玄鉴台

- **项玄冥**（S3 末-S4 入场）的 "**玄**" 字 → 与"**玄鉴台**"的"玄"字呼应
- 伏笔种：项玄冥一直是**玄鉴台的外线观察员**（S3 末-S4 以"神龙基地背后高人"身份登场；S6c 项玄冥国家身份揭开 → S6d 玄鉴台正式进场）
- 伏笔收束：Arc 17 玄鉴台代表进场时，项玄冥与之对话→ 读者此刻知道项老一直是玄鉴台的人
- 这个伏笔自然化处理：**不说明"项老是玄鉴台"**，只通过**"玄"字的重复 + 对话中的默契**让读者脑补

## 合规注意

- **不以"玄鉴台"名义**代替任何真实国家机构（公安部 / 国安部 / 中纪委 / 监察委）
- **不写**具体内部运作流程 / 任何可识别为真实机构的程序
- **玄鉴台**作为**虚构国家机构**出现，但其行为符合"**法治 + 国家正当监管**"的方向
- 项玄冥的"玄"字呼应**仅作为叙事巧合 + 伏笔**，不以此构建真实机构体系
