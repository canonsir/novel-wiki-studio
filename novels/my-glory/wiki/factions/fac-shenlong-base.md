# 神龙部队 / 神龙基地

## 定位

- **历史渊源**：承黄埔军校式国家选拔与特种部队训练传统（kb/crafts/military-special-forces.md）
- **故事定位**：最高等级训练与荣耀组织；S4 全卷主舞台
- **创立者**：国家级（具体部委 / 军种在小说中模糊化，统称『总队』）
- **大本营**：西北戈壁某军事封闭区（具体坐标虚构化）

## 组织结构

- 镇山长辈：项玄冥（表面是守门老人）
- 院长（Officially）：肖院长（见 `char-xiao-yuanzhang` 待建）
- 教官团：十二人分武 / 医 / 情三系
- 学员层：挑战赛积分制

## 行事准则 / 门规

三入三出：入队绝对忠国家 / 入营绝对守军纪 / 入阵绝对护战友；三出：出事即出队、出叛即出命、出圈即出名（除名）。

## 规模

常驻学员约 200；现役教官 12；运维 60

## 识别标志

黑灰迷彩 + 龙鳞袖章（左臂）+ 十二段锦训练场

## 短剧 / 视频改编备注

戈壁 + 黑灰迷彩 + 龙鳞袖章 + 十二段锦训练场；S4 挑战赛大场面必拍。
