# 五家议会

> 本页 `canon: proposed`。

## 定位

京畿旧城胡同私宅的门阀议会，顾 / 霍 / 裴 / 秦 / 韩 五家各出一人，大事四票通过。门阀议会而非黑帮联盟；五家在中央均有人身居要职。

## 五家速览

| 家族 | 历史根基（可查） | 现代业务 | 软肋 |
|---|---|---|---|
| 顾家 | 淮军 李鸿章部曲"铭"字营 + 洋务轮船招商局 | 中东能源 / 港口 / 煤炭矿产 | 本家内斗、被逐支系的继承权 |
| 霍家 | 清代内务府皇商 / 御医系 | 顶级私立医院 / 军医 / 高端医疗器械 | 医疗资质 / 舆论反噬 |
| 裴家 | 清代江南漕运世家 + 晋商票号 | 金融私募 / 文化传媒 / 拍卖行 | 资金链 / 跨境制裁 |
| 秦家 | 民国北洋奉系残脉 + 军统情报系 | 安保集团 / 情报 / 跨境雇佣兵 | 涉外武装 / 政审红线 |
| 韩家 | 清末湘军 曾国藩部曲 | 医药生物 / 临床审批 / 生物科技 | 临床审批 / 医疗伦理 |

## 规则（草案）

- 春分 / 秋分两次正会；临时会由任一家族提议、过半数响应召开。
- 大事四票通过（设计上让任意单家不可独裁）。
- 议题范围：家族跨业兼并、涉国资质调度、门阀代表国家公务安排、门阀继承人身份争议。
