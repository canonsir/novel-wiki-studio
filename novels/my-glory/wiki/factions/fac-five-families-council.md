# 五家议会

## 定位

- **历史渊源**：现代五大家族联席制度（见 fac-gu-family / fac-huo-family / fac-pei-family / fac-qin-family / fac-han-family）
- **故事定位**：门阀议会；非黑帮联盟
- **创立者**：民国遗脉重整；1980 年代重启
- **大本营**：京畿旧城胡同私宅

## 组织结构

- 五家各一代表、各一票；大事四票通过
- 春分 / 秋分正会；临时会由任一家提议、过半数响应召开
- 议题范围：家族跨业兼并、涉国资质调度、门阀代表国家公务、门阀继承人身份争议

## 行事准则 / 门规

五家之上有国法；国法之内有家规；家规之下有人情。

## 规模

5 席代表 + 若干记录员 + 外脉旁听

## 识别标志

北极星 + 五辅星图样的会徽；五家令牌（金 / 玉 / 乌银 / 鹰徽戒 / 湘军帅印）

## 短剧 / 视频改编备注

旧城胡同 + 五家令牌 + 北极星会徽；S5-S6 最高级大场面。
