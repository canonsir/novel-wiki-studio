# 爽点节奏保障方案（逆袭 + 打怪升级 + 爽文 + 后宫）

> 本页是**写作时的硬节奏模板**。author-agent 每写一章必须对照本页；reader-agent 发布前对照本页评爽点兑现度。
> 核心哲学：**红线不动 + 画面感代偿 + 爽感加码**。详见 `DEC-20261010-005`。

---

## 一、四联坐标系

本作创作的四维坐标系：

| 轴 | 定义 | 兑现频率 | 风险 |
|---|---|---|---|
| **逆袭轴** | 身份 / 阶层 / 地位的公开反转 | 每 5 章 ≥ 1 次公开打脸 | 单调化 → 要类型轮换 |
| **升级轴** | 境界 / 积分 / 门第 / 装备 / 技法 / 后台 可见进步 | 每 10 章 ≥ 1 次可量化升级 | 失去真实感 → 升级要有代价 |
| **爽文轴** | 单章节奏：钩子-转折-回报 | 每章 ≥ 3 个爽点锚点 + 章末钩子 | 过度套路 → 要有新花样 |
| **后宫轴** | 女性群像的独立情感线 + 独占回报 | 每 20 章 ≥ 1 位核心女主独家戏份 | 工具人化 → 每人有独家属性 |

---

## 二、单章爽点结构模板（3000-5000 字 / 章）

每章必须包含至少 3 个"爽点锚点"，分布如下：

```
开场钩子（0-20%）：
  ├─ A. 悬念 / 冲突 / 身份错位 入场
  └─ 必须让读者在第一屏（手机 2-3 屏滚动）看到钩子

中段冲突（20-80%）：
  ├─ B. 第一个爽点锚点：小规模打脸 / 身份揭示 / 后台曝光
  ├─ C. 第二个爽点锚点：资源 / 装备 / 关系升级
  └─ D. 第三个爽点锚点：伏笔种 / 女主互动 / 文化加码

章末钩子（80-100%）：
  ├─ E. 更强悬念入场
  └─ 下章入点在钩子之后（而非从头讲起）
```

**反模式**（禁止）:
- "整章铺垫没有爽点" → 必须拆分或合并
- "爽点全部堆在章末" → 读者在中段流失
- "章末钩子只是'结果来日分晓'" → 必须是具体人物 / 对象 / 事件

## 三、逆袭轴·打脸类型六分法（强制轮换）

每 5 章至少 1 次公开打脸。连续 2 次打脸禁止使用同一类型，必须轮换：

| 类型 | 核心手法 | 典型场景 | 原稿参考 |
|---|---|---|---|
| **1. 身份错位** | 对方不知主角真实身份→主角被轻视→身份揭露→对方跪 | 网吧少年遇到装 X 富二代 / 老师遇到门阀真少爷 | S1-S3 常用 |
| **2. 后台空降** | 对方正要动手→主角长辈 / 组织 / 国家力量空降→对方闪尿 | 项玄冥 / 神龙基地 / 五家议会信物出现 | S3-S5 常用 |
| **3. 技术碾压** | 对方以为是硬实力对决→主角瞬间秒杀 → 对方破防 | 挑战赛 / 十重天宫 / 打擂 | S4 密集 |
| **4. 文化内行** | 对方装文化人 → 主角用冷门典故 / 道学 / 诗词碾压 → 对方哑口 | 五家议会 / 青花会 / 洛神赋 场景 | S5-S6 发力 |
| **5. 道义制高点** | 对方以恶立场挑衅 → 主角以义正辞严 / 江湖规矩压制 → 对方被孤立 | 吃讲茶 / 五家议会 / 门规 | S2-S6 均可 |
| **6. 伤势反转** | 对方以为主角重伤 → 主角其实留后手 / 诈败 → 翻盘 | 街头反杀 / 挑战赛 / 鬼组刺杀 | S1-S4 常用 |

## 四、升级轴·六维成长感

每位主要角色（主角 + 核心兄弟 + 核心反派）在每卷至少有 1 维可见升级：

| 维度 | 可见度载体 | 顾北辰案例 |
|---|---|---|
| **境界** | 道家十二段锦 / 十重天宫层数 | S1 外经 → S4 内经初 → S6 内经大成 |
| **积分 / 排名** | 神龙挑战赛积分 | S4 入场 → S4 末前十 → S5 前三 → S6 第一 |
| **门第** | 顾家支系 → 本家承认 → 外脉首席 → 议会一席 | S5 本家认亲 → S6 议会立席 |
| **装备 / 信物** | 乌银手链 → 乌银令 → 顾家族徽戒 → 北辰令 | 收集进度条式 |
| **技法 / 武学** | 街头搏击 → 道家十二段锦 → 十重天宫 → 自创 | 招数名可记忆 |
| **后台** | 洪四海 → 项玄冥 → 神龙基地 → 五家议会 | 后台层级可见提升 |

**铁律**：升级必须有**代价**。
- 境界突破：至少 1 位亲近之人受伤 / 死亡 / 消失
- 门第认亲：至少 1 段过往被剥夺 / 1 位旧友远离
- 后台空降：欠 1 份人情需在后续偿还

### 5.2 后宫张力管理（画面感 + 点到即可）

**写什么**（保留）:
- 独占时刻：女主在公开场合为主角出头 / 挡刀 / 认领
- 关系升级信号：称谓变化 / 距离变化 / 肢体距离变化（手-肩-背-怀）
- 独家对白：这女主对主角说过而别人没听过的一句话
- 独家道具：这女主留下的物件（围巾 / 耳钉 / 戒指 / 乐谱 / 卷宗 / 发丝）
- 独家回报节点：主角危难时这女主独家出现

**不写什么**（画面感代偿）:
- 床戏过程 / 性器官描写 / 生理反应
- 女主之间的"宫斗撕 X"（降俗）
- "主角今晚要宠幸谁"类选择题
- 女主沦为性对象的内心描写

**张力承载替代**:
- 两女主第一次同场→用**称谓冲突**（都叫"北辰"）引爆
- 女主暗战→用**公开场合的礼节细节**（谁敬茶 / 谁先开口 / 谁坐侧位）承载
- 独占感→用**公开承认关系**替代"独占身体"（如议会场合主角携谁入场）
- 争宠→用**各自为主角做的实事**（情报 / 掩护 / 救命 / 政治资源）比拼

### 5.3 女主独家戏份分布

每 20 章至少 1 位核心女主独家戏份（独立 POV 可选 / 独立危机 / 独家回报）。

**铁律**：
- 每卷至少 2 位核心女主有独立危机场景
- 女主危机不能全靠主角救（她也要有自救桥段）
- 女主智商 / 情商不低于主角（避免恋爱脑）

## 六、画面感代偿笔法库（统一样本）

### 6.1 亲密画面感

❌ "他进入她的时候她的身体是热的……"
✅ "灯灭。窗外路灯一盏一盏在雨里消失。她没说话。他也没说话。第二天六点，闹钟响。她先醒。"

❌ "她把头埋在他胸口哭"
✅ "她的额头抵在他第二颗纽扣的位置。那颗纽扣是他母亲缝的。他没有动。"

❌ "他们做了那件事"
✅ "后来她在他的衬衫上留下过一个指甲印，很浅，三天就消了。但他记得。"

### 6.2 性威胁画面感

❌ "厉擎苍扯下她的浴巾，露出完美胴体"
✅ "厉擎苍的手停在半空。她闭上眼。那一秒的沉默让走廊的空调声都变响了。"

❌ "我要让你们轮番品尝她"
✅ "'你今晚哪儿也去不了。'厉擎苍说这句话的时候，窗外有烟花。那烟花是别人家的。"

### 6.3 反杀画面感

❌ "他拿起铁棍一棍一棍把那人砸成肉泥"
✅ "门外传来瓶子落地的声音。那人跪下去的时候，膝盖先碰到地毯。地毯是米色的，第二天酒店换了新的。"

❌ "红酒瓶砸在厉擎苍头上，玻璃碴插进眼睛"
✅ "红酒瓶砸下去的时候，厉擎苍右边的眉骨裂了。酒液顺着他的脸流下来，顾北辰看了一眼，发现那瓶酒是 1982 年的拉菲——不，是**仿品**。"

### 6.4 粗口画面感

❌ "我操你妈的"
✅ "'妈的。'他吐了口痰。"

❌ "艹你丫的"
✅ "'我去年买了个表。'他慢慢站起来。"（主角专属声线）

### 6.5 后宫张力画面感（关系升级）

❌ "温书宁和霍凝烟都想要他"
✅ "温书宁递茶的时候用的是右手。霍凝烟站在侧位，没动。'老师，'顾北辰接过茶，'她喝不惯这个。'温书宁的手停了一下，看了霍凝烟一眼，又添了一杯。"

❌ "季婉宁扑进了他怀里"
✅ "季婉宁走到他面前的时候，台下还在喊安可。她没有碰他。只是把那束花——她唱整首洛神赋时手里一直攥着的那束花——放在了他脚边。"

## 七、每章 lint 清单（强制）

写完一章后，author-agent 必须自检：

- [ ] 开场钩子是否在第一屏？
- [ ] 本章爽点锚点是否 ≥ 3？
- [ ] 本章章末钩子是否是具体的人 / 物 / 事件？
- [ ] 本章是否包含任意敏感内容？若是，是否已用画面感代偿？
- [ ] 本章若涉及女主，是否有独家属性 / 独家对白 / 独家道具体现？
- [ ] 本章脏话计数是否 ≤ 15？
- [ ] 本章是否触及红线清单 L1 / L2？若有，是否已逐条收敛？
- [ ] 本章升级 / 打脸是否与前 5 章类型重复？若是，是否需要轮换？

---

## 八、每卷节奏总把关（editor-agent）

每卷完成后，editor-agent 验收：

- [ ] 卷内打脸类型是否已轮换覆盖至少 4 种？
- [ ] 卷内核心女主是否至少 2 位有独立危机戏份？
- [ ] 卷内至少 1 次境界 / 身份 / 后台可量化升级？
- [ ] 卷内至少 1 个文化锚点（紫微 / 道家 / 洛神 / 淮军祖训）落地？
- [ ] 卷末钩子是否指向下卷核心冲突？
