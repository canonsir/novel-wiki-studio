# 章节连贯性与完整性守则·开写铁律

> 本页是开写时的 **硬铁律**。author-agent 每章开写前必读；落稿前必查。
> 本守则来自归档版 《情陷美女老师》c001/c002 的教训复盘。

---

## 一、归档版七大教训（教训就是戒条）

### 教训 1：开场铺垫过长 → 读者前 500 字流失

- **归档 c001 问题**：545 行里，开场在网吧 + 周斌对话 + 吃泡面 + 翻 Soul + 匹配前 4 人 = 占了全章 **70%**；真正的"美女老师出场"要等到第 471 行
- **番茄男频读者的真实数据**：**前 500 字如果没有爽点 / 身份错位 / 画面感冲击 → 弃读率 60%+**
- **铁律**：**每章前 500 字内必须出现 1 个具体钩子**（身份错位 / 冲突 / 悬念 / 道具 / 对白）
  - c001 新版用 "北辰 + 名字出典 + 我爸给我取的名字"开场，然后 300 字内进入**灵魂 App 刷到白鹿**——这才是对的
  - **开场禁用**：吃泡面 / 翻朋友圈 / 跟兄弟水对话 / 翻滚大段心理活动

### 教训 2：章末突然断开 → 读者没有"下一章想看"的动力

- **归档 c001 问题**：主角推门走进红屋咖啡厅 → "**我推开门，走了进去。**" → **章节直接结束**。没有具体钩子、没有新信息、没有悬念。读者看完的感受是"**？？？**"
- **铁律**：章末钩子必须是 **具体的人 / 物 / 事件 / 对白**，不能是"心情纠结 / 走进门 / 心跳加速"
  - c001 新版用 "**九头兽戒指 + 对方也在刷灵魂 App**" 作为章末钩子——对象+动作明确
  - **禁用的钩子**："待会会发生什么" / "我不知道接下来怎么办" / "命运开始改变" / "一场风暴即将来临"

### 教训 3：章首承接断裂 → 读者感觉"中间少了一章"

- **归档 c002 问题**：c001 结束于"推门进去"（关键见面还没开始）→ **c002 开头是"沈雪瑶走后"** → 读者问："**他们见面说了什么？纸条怎么来的？老师为什么走？**"
- **铁律**：**章首第一句必须直接回响上一章末钩子的具体对象**
  - c001 末尾 → "九头兽戒指 + 对方也在刷灵魂 App"
  - c002 开头 → 从九头兽戒指持有人视角切 / 或从温书宁视角回望主角身影 / 或从主角识破那枚戒指的瞬间继续
  - **禁用**：主角一个人走路 / 内心独白承接前章；必须用**场景+对白+动作**承接

### 教训 4：场景切换无因果锚点 → 节奏断裂

- **归档 c002 问题**：从咖啡厅 → 河堤走路 → 发微信 → 到紫薇小区 → 等 15 分钟 → 看到老师 → 跟到巷子 → 烧烤摊 → 楼上房间 → 接电话 = **8 个场景切换**，每个之间只用"然后 / 后来 / 我打了辆车"衔接
- **铁律**：每次场景切换必须有一个"**触发性因果**"
  - 不是"我决定去 X"，是"**对方发消息说 X 等我**"
  - 不是"我想了想去 X"，是"**门外有人敲门，说 X 在 Y**"
  - 场景切换 = **外部事件推进**，不是内心决策

### 教训 5：主角独白过多 → 水文信号

- **归档 c001 问题**：主角在网吧想心事占 10%；在肯德基蹲点想心事占 15%；见面前紧张占 5% → **纯独白占全章 30%**
- **铁律**：**内心独白 ≤ 15%**；超过部分必须用**对白 + 动作 + 外部观察**改写
  - 内心独白好：**一句尖锐的判断**（如"**仙人跳**"三个字）
  - 内心独白坏：**三段话铺陈心情**（如"我站在原地，不知道该怎么办..."）

### 教训 6：事件逻辑撕裂 → 读者智商被侮辱

- **归档 c002 问题**：章末钩子"**沈雪瑶在我手里**"的截图发给班群 —— **但沈雪瑶明明就在主角身边的烧烤摊楼上**；逻辑错配，读者第一反应是"**作者智商有问题**"
  - 虽然后面会解释"截图是合成的"，但钩子的第一秒感受是**荒谬**
- **铁律**：**章末钩子必须在"读者第一秒"就逻辑成立**；即使之后会反转，第一秒也不能让读者觉得"作者编不下去了"

### 教训 7：爽文第一章没有爽点 → 整本书废了

- **归档 c001 问题**：主角被动 / 老师被动 / 周斌搞笑 / 蹲点观察 → 没有一处"主角装逼 / 身份反差 / 识破对手 / 以弱制强"的**爽点锚点**
- **铁律**：**每章至少 3 个爽点锚点**（见 `wiki/world/爽点节奏保障方案.md`）
  - **第一章必须是全书爽点密度之王**：读者第一章觉得爽，才会追下去

## 二、章节落稿前 lint 清单（强制 10 项）

每章落稿后，author-agent 必须自检：

- [ ] **开场 500 字内有 1 个具体钩子**（身份错位 / 冲突 / 对白 / 道具）？
- [ ] **章末钩子是具体人物 / 物 / 事件 / 对白**（不是心情）？
- [ ] **章首第一句直接回响上一章末钩子**？
- [ ] **场景切换 ≥ 2 次时，每次都有外部因果触发**（不是内心决策）？
- [ ] **内心独白 ≤ 本章字数 15%**？
- [ ] **章末钩子在"读者第一秒"逻辑成立**？
- [ ] **本章爽点锚点 ≥ 3 个**？
- [ ] **本章对白占比 ≥ 30%**（避免叙述流水）？
- [ ] **本章结束时留下的"下一章必问"是一个具体问题**（不是"下一步怎么办"）？
- [ ] **本章没有闪回 / 走神 / 内心独白超过 150 字**？

## 三、章节连贯链 lint（跨章）

写完一章后，必须对**前后两章**做链接 lint：

### 3.1 承接 lint（本章 → 上一章）

本章第一个场景的 **启动** 必须对齐上一章末钩子：

| 上一章末钩子 | 本章开场必须 |
|---|---|
| 具体人物（如 X 发现 Y） | 从 Y 的反应 / 对白 / 动作继续 |
| 具体对象（如 X 看到 Y 戒指） | 从 Y 戒指的特写 / 持有人视角继续 |
| 具体事件（如 X 发信息"下章见"）| 从接到信息的下一动作继续 |
| 具体对白（如 X 说"你今晚哪也去不了"）| 从 X 的下一句或 Y 的反应继续 |

**禁用**：
- 开头是"第二天早上"（跳过中间）
- 开头是"主角走在街上"（独白切入）
- 开头是"我决定 X"（内心决策）
- 开头是"后来我才知道"（上帝视角）

### 3.2 推进 lint（本章 → 下一章）

本章末钩子必须给**下一章的"必然"动作**留一个口子：

- **好的末钩子**：对方按下了那枚戒指的按钮
- **坏的末钩子**：我决定明天再想办法

好钩子的特征：
- 对方 / 外部事件已经发生，读者下章必然想知道
- 不依赖主角内心决策

## 四、每章结构模板（3000-5000 字）

```
┌─ 开场（0-500 字 / 10%）──────────────────────
│  承接上一章末钩子 → 具体对象登场 → 第一个爽点锚点
├─ 中段冲突（500-3500 字 / 60-70%）────────────
│  对白 + 动作主导（对白 ≥ 30%）
│  爽点锚点 2 和爽点锚点 3 发生
│  中段 ≥ 1 次关系 / 身份 / 信息 的升级
├─ 回报段（3500-4300 字 / 15-20%）─────────────
│  场景结论 / 关系确认 / 伏笔收束一条 / 道具落位
└─ 章末钩子（4300-5000 字 / 5-10%）────────────
   具体人物 / 对象 / 事件 / 对白 → 必然引出下一章
```

---

## 五、三个"开写前必问"

每章开写前，先回答这三个问题（写在 frontmatter 的 `pre_write_qa`）：

1. **本章要让读者"看到"的事情是什么？**（具体事件 1 个）
2. **本章的 3 个爽点锚点分别是什么？**（具体对象）
3. **本章末钩子是什么？读者下章必然想知道的具体问题是什么？**

回答不出来 → 禁止开写。
