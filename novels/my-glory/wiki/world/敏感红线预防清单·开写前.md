## 二、L2 必须收敛（可留剧情资产，不留执行细节）

### 2.1 色情 / 性暗示（原稿 259 处）

**原稿风险样本**：
- "黑木耳 / 粉木耳 / 艹起来肯定爽歪歪 / 破处 / 肉棒 / 五姑娘"
- 第 1-2 章仙人跳酒店床戏；第 24 章绑架温书宁情节；全书后宫戏
- "小伙伴"（指男性性器官）
- 露骨旁白 + 内心独白

**收敛规则**：
- 两性亲密戏全部"关门镜头"（镜头切黑 / 转场到次日 / 以道具 + 对白暗示）
- 内心独白去除所有"器官 / 生理反应 / 色情审美"描写；保留"情感 + 冲动"但不具象
- 不用女性身体部位做绰号 / 比喻（删除"黑木耳 / 粉木耳 / 鲍鱼"等）
- 不写"初夜 / 破处"作为爽点；温书宁的处女身份可作为情感重要性但不作为征服对象
- 后宫张力保留：以**独占 / 关系确认 / 社交对决**等外部冲突替代内部描写
- 原稿男主口嗨"我和我的小伙伴"保留为**人物口头禅化**（不特指器官，变成口头禅品牌）

**禁区示例**：
> ❌ "我进入她的时候她的身体是热的……"
> ❌ "破处的瞬间她喊得像一只……"
> ❌ "我忍不住盯着她的……"
>
> ✅ "灯灭。窗外路灯一盏一盏在雨里消失。第二天六点，闹钟响。她先醒。"
> ✅ "他的喉结动了一下，没说话。她把那件披风往上提了提，别过脸。"

### 2.2 暴力 / 血腥 / 性暴力（原稿 47 处明确性暴力威胁）

**原稿风险样本**：
- 第 3 章 "等会儿也有你的好处，我让你也干她 / 轮番品尝她"
- "一巴掌抽在她脸上，顿时浮现了五个手掌印"
- 后期大型团战的血腥描写

**收敛规则**：
- **性暴力威胁**保留**心理压迫感**，去除**具体施暴描述**：从"扯掉浴巾露出完美胴体"→"他的手停在半空，她闭上眼睛"
- **轮奸 / 群暴桥段** → 用"落单 + 包围 + 门关上 + 门外视角 + 事后结果"外化
- **打人出血** → 允许但不描绘血浆飞溅 / 骨折畸形；关键伤势按 kb/crafts/medicine-pharmacology.md 周期收敛
- **扇耳光 / 掐喉** 保留但不多次重复；一场戏最多一次强物理动作
- **主角反杀**保留，但不写"一瓶子砸碎脑袋，脑浆四溅"类画面；用"玻璃落地"+"对方跪倒"替代

**禁区示例**：
> ❌ "他拿起铁棍一棍一棍把那人砸成肉泥"
> ❌ "剧烈撕扯她的衣服，露出……"
>
> ✅ "门外传来瓶子落地的声音。那人跪下去的时候，膝盖先碰到地毯。"
> ✅ "他的手停在她肩膀上。她抬起下巴看着他。他松开了。"

**原稿风险样本**：

### 2.9 画面感代偿笔法（统一收敛哲学 - DEC-20261010-005）

> 本节为 **DEC-20261010-005** 落地规则：敏感内容不等于一刀切删除，而要用**画面感 + 点到即可**替代。
> 读者脑中有画面，纸上没有违禁词。写作时严格对齐 `wiki/world/爽点节奏保障方案.md` §6 笔法库。

#### 2.9.1 收敛哲学三条口号

1. **"镜头外发生，镜头里被看见"**——事件发生在镜头外，但角色反应 / 道具状态 / 下场时间让读者"看见"。
2. **"少一点动词，多一点名词"**——不写"他进入她"，写"灯灭 / 窗外路灯一盏一盏熄灭 / 第二天六点闹钟响"。
3. **"把爽感还给打脸，不还给房中"**——爽点集中在身份反转 / 公开羞辱 / 后台空降，而非内部肉体。

#### 2.9.3 情欲张力的"关门镜头六法"

床戏统一改"关门镜头"。author-agent 从以下 6 种中选一种，每本书同种技法连用不超过 2 次：

1. **物件法**：聚焦卧室外的一件物件，时间推移（路灯 / 闹钟 / 窗外烟花）
2. **声响法**：聚焦门外 / 窗外的声音（雨声 / 空调 / 街头喧哗）
3. **第二天法**：直接切到第二天的某个细节（她先醒 / 他煮了咖啡）
4. **道具痕迹法**：事后镜头，一个物件的状态变化（衬衫上的指甲印 / 床单边角 / 口红印）
5. **对白收尾法**：关门前最后一句对白，然后留白（她说"你走"→场景切）
6. **侧写法**：从第三人视角（走廊保洁 / 隔壁房客 / 清晨保安）外化事件已发生

#### 2.9.4 后宫张力的"独占不碰身"原则

**独占感**不靠"身体占有"承载，而靠以下 5 种外化：

| 外化手段 | 示例 |
|---|---|
| **称谓升级** | "顾同学"→"北辰"→"北哥"→"阿北"（每次升级在公开场合首发） |
| **公开场合携谁入场** | 五家议会主角带谁坐侧位 |
| **独家道具** | 温书宁的围巾 / 霍凝烟的耳钉 / 季婉宁的乐谱，只给她们一人 |
| **独家救命时刻** | 这女主在这场合独家出手（别的女主没在场） |
| **独家对白** | 一句话只对一个女主说过，别人都没听过 |

#### 2.9.5 爽点加码补足敏感收敛的流失

每收敛 1 处敏感剧情，必须在同一章 / 同一场景补 1 处"安全爽点"：

- 删一场床戏 → 加一次公开打脸
- 删一段性威胁 → 加一次身份揭底
- 删一段吸毒细节 → 加一段境界突破
- 删一段轮奸威胁 → 加一段反杀后对方"跪下来道歉"

**铁律**：收敛不能让章节变弱。弱 = 退稿 / 读者流失 / 平台降权。详见 `wiki/world/爽点节奏保障方案.md`。

## 三、L2 收敛（叙事资产保留，表达形式收敛）

### 3.1 脏话 / 粗口（原稿 478 处）

**原稿风险样本**：
- "操你妈 / 他妈的 / 我艹 / 我草 / 草尼玛 / 日你 / 艹你"
- 主角口头禅"我去年买了个表"（谐音转写）

**收敛规则**：
- **保留**主角口头禅"**我去年买了个表**"——这是本作人物声线资产，不动。
- **保留**"卧槽"类单字惊呼（短剧时代读者接受度高）
- **收敛**"他妈的" → 高频场合保留，用"妈的"（二字），不用"操你妈"（三字含性）
- **删除**"操你妈 / 日你 / 艹你 + 具体对象"的所有三字性器官型辱骂
- **删除**对女性的性器官型辱骂（见 3.2）
- 规则：**每章脏话上限 15 处**；由 lint 工具自动统计。

### 3.2 性别歧视 / 侮辱性别语（原稿 34 处）

**原稿风险样本**：
- "贱货 / 婊子 / 骚货 / 骚逼"（第 1 章就有大量使用）
- "好逼被狗草 / 好菜被猪拱"
- 女性物化叙事

**收敛规则**：
- **反派口中的辱骂**可以保留部分（厉擎苍可以说"贱人"），但不要**三连骂**；一场戏最多 1 次。
- **主角内心独白**对女性的物化判断**必须删除**："好逼被狗草 / 骚货 / 粉木耳"等
- **主角口头骂人**不骂到性别器官：改"他妈的" / "瞎他妈 X" / "操（单字）"
- 原稿第 1 章主角对温书宁的内心"骚货还是女神"类判断 → 改为**身份判断**（"学生身份 vs 女性身份 vs 老师身份"）而非物化
- 女性角色自身的言行有尊严，不写"等男人救"但也不走极端女强

### 3.3 枪支 / 武器 / 暴力细节（原稿 1046 处）

**原稿风险样本**：涉及枪、刀、炸弹的各类场景

**收敛规则**：
- 遵守 `kb/crafts/weapons.md`：严禁改装 / 配方 / 操作教程
- 民用场景以**冷兵器为主**（棒 / 刀 / 瓶 / 徒手）
- 枪支只给**合法持枪者**（警察 / 军人 / 境外雇佣兵）；主角方禁枪
- 爆炸物不写具体种类 / 配方；只写"爆炸发生后"的结果
- 遵守 `kb/crafts/martial-arts.md` 硬上限（1v3 现实边界 / 10 米外必死）
- 战力描写保留**街头感 + 残酷感**，但不堆砌血浆

## 四、本作专属 Hook 场景的收敛样例（第 1-3 章）

### 4.1 第 1 章「漂流瓶约见 → 咖啡厅」

- 原稿风险：主角内心独白物化温书宁；提及"约炮"若干次
- 收敛：
  - "约炮"→"**约见**"或"**赴约**"（一次性，不复用）
  - 主角内心独白：从"骚货"→"**没见过真人，先看看是什么情况**"
  - 保留"**我去年买了个表**"口头禅
  - 保留"**仙人跳**"叙事（主角有合理警惕）

### 4.2 第 2 章「酒店床戏 → 踹门抓奸」

- 原稿风险：床戏露骨 / 浴巾揭开 / 浴室洗澡偷窥
- 收敛：
  - 床戏**改为未发生**：主角进浴室 → 她坐在床边 → 她哭 → 门外响 → 她说"你走"
  - **删除**"去浴室外偷窥"情节
  - **删除**"摸索她私密处"
  - "我和我的小伙伴"保留（人物声线资产，口头禅化）
  - "初夜情节"**改为**：她答应嫁给厉是因为**父亲债务**，而非为了"把自己给谁"
  - 这样"她为什么扔漂流瓶"的动机就变成：**想找个干净的陌生人认识一下、给自己一个'我还是我'的证明**，而不是"放纵一次自毁"

### 4.3 第 3 章「反杀厉擎苍」

- 原稿风险："轮番品尝 / 扯掉浴巾 / 五个手掌印"
- 收敛：
  - 性威胁话术：**从"轮番品尝"→"'你今晚哪儿也去不了'"**（心理压迫，不具象）
  - **扯浴巾动作** → 删除；改为"**他摸了她的下巴**"
  - **扇耳光**保留 1 次，不写"五个手指印"
  - 红酒瓶反杀：保留；不写"玻璃碴插进眼睛"
  - 事后：厉擎苍被制服后**不写他下跪求饶**（原稿有）；改为**面无表情，眼神闪过冷意**（反派不塌房气质）
