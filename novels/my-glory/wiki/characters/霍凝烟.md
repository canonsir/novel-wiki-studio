# 霍凝烟

## 基本资料

- **身份**：核心女主 / 鬼组『叉』代号
- **年龄**：26 周岁（开篇）
- **外貌 / 体格**：身高 172 cm；利落马尾或低髻；颧骨突出、唇色偏淡；左耳背有一枚可拆的鬼组通讯耳钉；惯穿深蓝皮衣 / 窄身风衣
- **职业**：表面：霍家医疗板块外派高管；内里：鬼组五代号之一『叉』

## 背景故事

- 霍家内务府皇商 / 御医系嫡出；自幼被族中按鬼组苗子培养，18 岁入组；
- 鬼组五代号『罗刹 / 修罗 / 夜叉 / 叉 / 幺』，她是『叉』——擅长近身与医术结合的刺客式解决；
- 27 岁本应从鬼组轮退回霍家，但组内上一代组长（舅舅线路的裴无咎）替她做了延期；
- 开篇在蓉城执行一次与厉家边缘的任务时偶遇顾北辰，相互留了印象。

## 性格剖面

表面冷、礼貌到带刺；对自己人（鬼组同代）绝对忠诚；对主角从『猎物目标核对』到『主动破戒』。

## 能力线

近身格斗 / 急救 / 毒物辨识（遵守 kb/crafts/medicine-pharmacology.md）；精通家族旧式礼仪，可独立应对门阀场。

## 弧线

S2 登场但不表身份；S3 主角蓉城统一战中救急，身份揭开；S4 神龙基地同期；S5 议会上以霍家代表身份与主角并列；S6 认账。

## 短剧 / 视频改编备注

外形锚点：风衣 + 耳钉 + 低髻；动作锚点：出手必单招了结；声线锚点：短促、不带情绪的中音，但对主角一句『笨』会放很慢。
