# 温景同

## 基本资料

| 项 | 内容 |
|---|---|
| 本名 | 温景同 |
| 常用称呼 | 温景同（正式）/ 温父（内文行文）/ 老温（街面熟人）/ 温老爷子（后期晚辈）/ 爸（温书宁独白）|
| 性别 | 男 |
| 年龄（开篇） | 53 周岁 |
| 身高 | 172 cm |
| 体格 | 清瘦，眉骨突；左手无名指缺一节（年轻时翻车工伤） |
| 外貌 | 鬓角花白，眼下常年青黑；S1 开篇穿皱巴巴的旧呢大衣 |
| 职业 | 蓉城·城东旧书店"听澜书屋"店主（已停业一年；原为蓉城二中语文教师，退休） |
| 学历 | 师范大学古代文学专业本科，蓉城二中执教 25 年 |
| 婚姻 | 妻子孟氏早逝（温书宁 8 岁时病故） |

## 性格剖面

- **外在**：读书人气质，平时温吞寡言，手不离书。
- **内核**：对女儿有愧——妻子早逝后独自带大温书宁，前几年沉迷棋牌被人下套，赌债 500 万把女儿推入厉家视野。醒悟后戒毒戒赌，但身体垮了。
- **伤口**：半年前被厉擎苍派人用慢性药品诱发瘾症（下药过程不写）；在皇城赌场被设局欠下 500 万。
- **口头禅**："书比人靠得住。"（后期自嘲"我连这句话都辜负了。"）

## 在 S1 的功能

- **叙事麦高芬**：500 万赌债是厉擎苍勒索温书宁的唯一凭证。
- **动机母题**：温书宁"自毁式"去赴漂流瓶之约，根本不是放纵，是**为父赎身**的最后一次挣扎。
- **收敛要点**：下药 / 吸毒 / 戒毒过程**全部关门镜头**（见 `wiki/world/敏感红线预防清单·开写前.md` §2.3）。
  - ❌ 不写具体药品名、剂量、用法、注射方式
  - ✅ 只写"事后温书宁发现他开始反常"、"手抖"、"深夜不睡盯着墙"
- **道具锚点**：年轻时教书用的黄铜算盘（见 `wiki/objects/黄铜算盘`），后期成为父女和解的信物。

## 弧线

- **S1**：病倒 → 温书宁被勒索 → 顾北辰反杀解围 → 温景同第一次见顾北辰（S1 中后段），认出他是顾崇岳的儿子（埋顾家支系伏笔）。
- **S2**：被厉家二次下药 → 温书宁被绑作要挟 → 顾北辰组织化救援的催化剂。
- **S3**：进戒毒医院（关门镜头 / 不写医疗操作）→ 父女交心 → 把黄铜算盘交给温书宁。
- **S4-S6**：以观望角色支撑温书宁的后方；S5 议会场合首次公开承认顾北辰（"北辰这孩子，像他父亲"）。

## 能力与资产

- 教师人脉：蓉城教育系统二十年老人；S3 为主角提供合法化入场券之一。
- 古代文学功底：S5 议会场合"吃讲茶"级饭局的软性话语权（与温书宁同场）。
- 翻车工伤残疾：左手无名指缺一节——反派误以为他好欺负的视觉锚点，也是他年轻时拒绝某笔灰色收入的证据。

## 短剧 / 视频改编备注

- **外形锚点**：旧呢大衣 + 老花镜 + 布鞋；手里常攥一本旧书或黄铜算盘
- **动作锚点**：S1 开篇"手抖着翻书，书翻不开"（下药后遗症的侧写）；S3 戒毒"把黄铜算盘推到女儿面前，一句话都没说"
- **声线锚点**：沙哑中有书卷味；戒毒前后对比明显——戒毒前几乎失声，戒毒后恢复低缓

## 关系

- 父女 → `温书宁`
- 伤害者 → `厉擎苍`（下药） / `厉天鸿`（授意）
- 旧识 → `顾崇岳`（S1 中后段揭）—— 他曾教过顾崇岳语文课，是顾家支系在蓉城的唯一文化证据
- 后期旁观者 → `顾北辰`
