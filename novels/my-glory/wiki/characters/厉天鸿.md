# 厉天鸿

## 基本资料

- **身份**：天一集团董事长 / 阶段大 BOSS 之一
- **年龄**：58 周岁（开篇）
- **外貌 / 体格**：身高 178 cm；银灰油头；啤酒肚；眼袋深；惯穿定制三件套 + 白色法式袖扣
- **职业**：天一集团创始人 / 董事长；蓉城地产 / 商业综合体板块龙头之一

## 背景故事

- 祖籍粤东；80 年代从走私家电起家，90 年代转地产、2000 年代转商业综合体；
- 与青帮某脉有十五年的旧账联盟（S2-S3 调青帮进蓉城的关键）；
- 一直想通过儿子厉擎苍跨入五家门阀未遂；
- 最大的恐惧是『被看穿底色』——他本质是暴发户。

## 性格剖面

表面温和儒雅，私下阴狠；对儿子又宠又恨；对比自己有背景的人（主角）会先递烟后设局。

## 能力线

蓉城房地产 / 商业综合体掌控 + 青帮打手通路 + 政商灰色关系网。

## 弧线

S1 幕后出场；S2 直接出手；S3 天一集团被端 → 下落交由顾北辰亲手定调（可押送神龙线审讯或走司法程序）。

## 短剧 / 视频改编备注

外形锚点：三件套 + 法式袖扣 + 银灰油头；动作锚点：抽雪茄；声线锚点：温和的男中音，笑着说狠话。
