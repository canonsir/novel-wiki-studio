# 裴青鸾

## 基本资料

- **身份**：表姐 / 鬼组『罗刹』
- **年龄**：25 周岁（开篇）
- **外貌 / 体格**：身高 168 cm；长发高马尾；眼角微上挑如凤；左小臂内侧有一条青鸾刺青；惯穿黑色紧身衣 / 皮靴
- **职业**：表面：裴家拍卖行安保主管；内里：鬼组『罗刹』——现任首席

## 背景故事

- 裴云归兄长的女儿，裴家内族嫡出；
- 11 岁入鬼组培养体系，19 岁拿『罗刹』代号；
- 与主角有血缘（母系表姐），但父辈当年因裴云归出走事件与顾家结仇，身份隐瞒至 S4-S5 才揭。

## 性格剖面

刚烈，有一股冷到透明的狠劲；嘴里凶但对表弟不下杀手；对裴家族老的敬畏与反感并存。

## 能力线

鬼组现役战力顶级；一把反手匕首；轻功 / 翻跃是鬼组标杆。

## 弧线

S3 刺杀主角失败 → 身份不说；S4 神龙基地同期 → 身份半揭；S5 议会上两个姓氏（裴 / 顾）同场的尴尬 → 情感同盟；S6 守护主角完成命盘。

## 短剧 / 视频改编备注

外形锚点：青鸾刺青 + 高马尾 + 匕首；动作锚点：第一次刺杀主角时的匕首反握；声线锚点：短平快。
