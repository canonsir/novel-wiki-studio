# 故事总览

## 一句话故事

蓉城三流大专的网吧少年顾北辰（北哥）在一次匿名约见中卷入门阀继承人的仙人跳，被迫以街头狠劲反杀，一路从夜场打到帝都五家议会，最终在"众星拱北辰"的格局中完成命盘杀破狼聚齐的身世闭环。

## 读者承诺与独特卖点

**定调（见 `decisions/DEC-20261010-005`）**：**都市逆袭 + 打怪升级 + 后宫爽文**。
敏感内容统一采用"画面感 + 点到即可"收敛（不删剧情，改笔法）。

- **都市 + 真实文脉**：五姓七望门阀 + 淮军 / 湘军 / 漕运 / 内务府 / 北洋 真实历史根基，不是架空。
- **北辰 + 杀破狼命理主轴**：主角名出自《论语·为政》"北辰居其所而众星共之"；命盘杀破狼聚齐；"众星拱北辰"是全书叙事主轴与身世谜底。
- **四联爽点坐标系**（详见 `wiki/world/爽点节奏保障方案.md`）:
  - **逆袭轴**:每 5 章 ≥ 1 次公开打脸,6 种类型（身份错位 / 后台空降 / 技术碾压 / 文化内行 / 道义制高点 / 伤势反转）轮换
  - **升级轴**:境界 / 积分 / 门第 / 装备 / 技法 / 后台 六维可见进步
  - **爽文轴**:每章 ≥ 3 爽点锚点 + 章末钩子（强制）
  - **后宫轴**:6 位核心女主（温书宁 / 霍惊鸿 / 叶浅浅 / 季繁星 / 裴青鸾 / 穆清）各有独家属性 / 独家道具 / 独家回报节点
- **章末钩子驱动**：3000-5000 字 / 章；身份错位 → 地位逆转 → 公开打脸 → 资源升级 → 后台揭示。
- **三层版本**：番茄发布版 / 红果漫剧版 / 红果无尺度素材版，共享同一事件与因果。
- **收敛哲学三条**:"镜头外发生,镜头里被看见" / "少一点动词,多一点名词" / "把爽感还给打脸,不还给房中"。

## 核心戏剧问题

被豪门逐出的支系少年顾北辰，能否在不丢掉底层血性的前提下走到北辰之位？

## 主题问题（不预设答案）

荣耀是外界授予的位置，还是自己配得起的名字？

## 主角、目标、阻力、代价

- **主角**：顾北辰（北哥），蓉城三流大专大二学生。父亲顾崇岳是京畿顾家被逐支系。表面是网吧少年，骨子里是从街头打出来的孩子王。
- **目标**（分阶段）：
  - S1 保命 → 立足城南 → 不让女神老师温书宁被厉擎苍玷辱
  - S2-S3 蓉城统一（天下会）
  - S4 应神龙基地征召 → 揭开身世
  - S5 回京畿 → 冲击五家议会
  - S6 众星拱北辰 → 命盘杀破狼聚齐 → 定义自己的"荣耀"
- **阻力**：五大家族（顾 / 霍 / 裴 / 秦 / 韩）的历史恩怨、本家内斗、天一集团资本碾压、鬼组猎杀、神龙体系纪律、国家合规红线。
- **代价**：女神老师的处境、兄弟程星野的生死线、母亲裴云归的身份暴露、父亲顾崇岳的血仇、与裴青鸾（表姐 / 鬼组杀手）的身份困境。

## 主线因果摘要

1. 开场网吧少年 → 匿名约见（灵魂 App 平台）→ 遇校花美女老师温书宁 → 卷入厉擎苍仙人跳 → 街头狠劲反杀 → 露出家族血性 → 命运开端。
2. 城东立足 → 洪四海（海哥）引路 → 海迪 / 狼舞 → 挑战肥猫 → 老卜（白袍会）→ 蓉城三方博弈。
3. 遇霍惊鸿（鬼组"叉"）/ 裴无咎（舅舅、鬼组组长）→ 裴青鸾（表姐、罗刹）→ 身世第一次被揭。
4. 厉天鸿 / 天一集团全面施压 → 蓉城统一战 → 天下会立。
5. 项玄冥（项老）引入神龙基地 → 挑战赛 / 积分 / 十重天宫 → 道家十二段锦 → 杀破狼命盘首次聚齐（破军 = 军师贺九思 / 贪狼 / 七杀）。
6. 回京畿 → 五家议会 → 本家内斗 → 顾崇岳血仇清算。
7. 终局：秦枭 / 韩啸天 / 帝都反派决战 → "众星拱北辰"格局落地 → 大结局"我的荣耀"。

## 主要人物弧（核心 5 位，初稿）

- **顾北辰**：街头少年 → 蓉城霸主 → 神龙积分王 → 五家议会北辰 → "荣耀"的定义者。
- **温书宁**：被豪门捆绑的老师 → 自救 → 与顾北辰的师生错位 → 情感第一女主。
- **霍惊鸿**：鬼组"叉"→ 外冷内炽 → 核心女主。
- **厉擎苍**：豪门继承人 → 阶段大反派 → 终局前被清算。
- **程星野**：室友兄弟 → 军师线前期伙伴 → 杀破狼"破军"候补。

## 世界规则摘要

- **五家议会**：顾 / 霍 / 裴 / 秦 / 韩，京畿旧城胡同私宅，春分 / 秋分正会，四票通过。门阀议会而非黑帮联盟。
- **北辰 + 杀破狼命盘**：紫微斗数真实星曜；主角命盘杀破狼聚齐，名讳暗合北辰（紫微）。
- **真实武学硬上限**：遵守 `common/knowledge-base/crafts/martial-arts.md`（徒手 1v3 同级为现实上限）。
- **一级药剂**：神龙体系合法增强药，有剂量与副作用管理，不写配方。
- **三层发布版本**：共享同一事件与因果，不为过审删主线。
