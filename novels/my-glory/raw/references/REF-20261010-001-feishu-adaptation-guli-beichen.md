## 3. 编辑视角

- 主角名"顾北辰"文化含金量高：**北辰即北极星**，出自《论语·为政》"为政以德，譬如北辰，居其所而众星共之"；紫微斗数中紫微星即帝星，杀破狼（贪狼、破军、七杀）为将星格局——"北辰"一名天然嵌入全书命理体系，构成"众星拱北辰"的身世谜底。
- 风险控制：真实文脉只做背景与可信度增强，不得让设定说明压过爽点节奏；每章仍以打脸、升级、关系推进为第一优先级。
- 商业化检查：主角名"北哥"（原"南哥"）南北对转，好记有记忆点；五大家族文脉（军阀/将军/财富/皇亲/士林）各有鲜明标签，符合番茄男频审美。

## 4. 反套路创意提案

- **北辰星象主线**：全书命理主轴从"杀破狼"升级为"众星拱北辰"——主角顾北辰命盘杀破狼三星聚齐，而名讳暗合北极星/紫微，后期五大家族围绕他站位的格局，正是"北辰居其所而众星共之"的现代演绎。
- **真实文脉的现代转译**：五大家族各配一条真实历史根基（淮军/湘军/漕运/内务府皇商/北洋军统），现代化为能源、医药、金融、安保业务——历史不是架空标签，而是家族性格与软肋的根源。
- **组织名补渊源**：天下会→天地会/洪门传统；白袍会→四川袍哥（哥老会）文化；鬼组→粘杆处/锦衣卫式隐秘机构；神龙基地→黄埔军校式国家选拔体系——原名不动，渊源补实。

### 5.1 主角定名：顾北辰

| 项 | 设定 |
|---|---|
| 正式名 | 顾北辰（替换上一版"顾沉舟"） |
| 出处 | 《论语·为政》："为政以德，譬如北辰，居其所而众星共之。"北辰即北极星（勾陈一），古义为天之枢、众星所拱（朱熹《四书章句集注》："北辰，天之枢也"）。 |
| 命理意象 | 紫微斗数中紫微帝星对应北极星；主角命盘杀破狼（贪狼、破军、七杀）聚齐，名讳"北辰"暗合紫微，构成"杀破狼为将、北辰为帝"的命格伏笔。 |
| 道上称呼 | "北哥"（原稿"南哥"→南北对转，好记有记忆点）；亲近者称"北辰"；江湖后期尊称"北辰先生/顾爷" |
| 身世呼应 | 父亲顾崇岳被逐出京畿顾家，携子隐居成都；"北辰"之名是父亲取的——寓意"总有一天，众星会围着你转"，也埋下五家议会"众星拱北辰"的终局。 |
| 家族 | 顾家（原陈家，五大家族末位，主角本家） |

### 5.7 三层版本策略（不变）

- **番茄发布版正文**：允许犯罪、欲望、暴力、毒品作为负面冲突，但不宣扬淫秽色情、赌博、吸毒，不渲染暴力恐怖、不教唆犯罪。
- **红果漫剧版正片**：敏感过程用遮挡、声效、反应、道具状态与事后后果外化。
- **红果无尺度素材版**：不把最敏感镜头当吸睛卖点。
- 三层共享同一事件、人物状态与因果；红线压缩的刺激量由身份错位、地位逆转、公开打脸、资源升级与后台揭示补足。
