- **Decision**:

  ### 1. 命盘杀破狼三星（紫微斗数象征）

  本作主角 **顾北辰 = 紫微**（北辰 / 众星之主）。命盘杀破狼三星定位如下：

  | 命盘位 | 人物 | 对应原型 | 命盘属性 | 剧情位置 |
  |---|---|---|---|---|
  | **破军** | **贺九思（半仙）** | 军师型 / 决断 / 智囊 | 破旧立新 / 军师脑 | S2 入场 / S3-S4 定位 |
  | **贪狼** | **洪四海（海哥）** | 引路人 / 交际达人 / 善转圜 | 桃花 / 冒险 / 交际 | S1 Arc 1 c026 入场 |
  | **七杀** | **程星野（星子）** | 兄弟团冲锋 / 执行力 / 锋芒 | 杀伐 / 果决 / 独立 | S1 c001 入场（星野已出场）|

  **选型理由**：
  - **贺九思 = 破军**：原已固化。军师气质对应破军"破旧立新"位
  - **洪四海 = 贪狼**：
    - "海哥"的核心人格是**交际网络 + 善于转圜**（蓉城·城东海迪老板 / 夜场枢纽 / 引路人）
    - 贪狼在紫微斗数里是"桃花 + 交际 + 冒险"主星——与海哥身份气质 100% 吻合
    - 命盘聚齐时主角身边最早形成的三位非血缘兄弟：海哥（贪狼）/ 贺九思（破军）/ 程星野（七杀）
  - **程星野 = 七杀**：
    - 星野是主角原生兄弟团代表（c001 已出场）
    - 兄弟团冲锋型人格 → 七杀"杀伐果决 + 锋芒独立"配置
    - 名字"星野"本身就带"星"（命盘星曜意象），改编时无需调整
  - **杀破狼聚齐**在 S4 末完成（原 DEC-003 锁定）。入场顺序：七杀（c001 已入）→ 贪狼（c026 Arc 1 柳巷）→ 破军（S2 入场）→ 三星归位（S4 末）

  **额外说明**：原稿命盘仅粗略提过"杀破狼"概念；本次固化为**具体三人**后，后续写作中可通过**对白 + 命盘图 + 项玄冥口述**等方式自然展开，无需刻意说明"你是七杀"。

  ### 2. 跨境雇佣兵组织（S6 Arc 14 核心对手）

  **组织名**：**穷奇旅**

  | 项 | 值 |
  |---|---|
  | id | `fac-qiongqi-brigade` |
  | 命名出处 | 《山海经·西山经》"穷奇"——四凶之一，善辨逆顺，专食**忠厚守信之人** |
  | 本作定位 | 跨境雇佣兵集团；秦枭 S6a Arc 14 的核心打手通路；境外注册、跨境流窜 |
  | 组织特征 | 外黑内黑；没有价值观，只认金主；成员多为前东欧 / 西亚退役特种兵；总部虚构在"东瀛以南某无主岛" |
  | 符号 | 一只独角、九尾、长翅、豹纹的兽（穷奇原始形象）；队徽为穷奇头部侧影 |
  | 剧情功能 | 秦枭 Arc 14 通过"穷奇旅"对主角团发动跨境袭击；兄弟团中一人重伤 |

  **选型理由**：
  - **山海经意象**与本作知识库底盘呼应（见 `common/knowledge-base/china/philosophy/shanhaijing.md`）
  - "穷奇"的核心性格——**善辨逆顺，吃忠厚人**——与雇佣兵"颠倒是非，吃钱办事"的职业逻辑 100% 对应
  - 与反派厉擎苍的伏笔道具"**九头兽戒指**"（相柳九头意象）同属山海经意象，形成"反派都带山海经凶兽标签"的叙事呼应

  ### 3. 国家监察机构（S6 Arc 17 新引入）

  **机构名**：**玄鉴台**

  | 项 | 值 |
  |---|---|
  | id | `fac-xuanjian-tower` |
  | 命名出处 | 玄（《道德经》"玄之又玄，众妙之门"幽深 + 看不透）+ 鉴（察 / 镜 / 评判）+ 台（国家一级机构名惯例，如前朝"钦天台""御史台"）|
  | 本作定位 | 国家一级非公开监察机构；职能是对"**门阀级 / 江湖级非法人团体**"做**合法-非法边界的审查与裁定** |
  | 组织特征 | 不走司法序列；向最高一级汇报；成员多为前国安 / 前军方 / 前法律系统核心骨干；总部虚构在"**帝都西山之麓**" |
  | 剧情功能 | S6d Arc 17 议会洗牌时**正式进场**：以玄鉴台为中介，推动五家议会从"门阀黑箱"向"国家监管透明机构"的制度化改造 |
  | 关键角色 | 玄鉴台代表（Arc 17 新引入；暂定代号"**观天**"；待取名） |

  **选型理由**：
  - **"玄鉴"**二字既保留古意（钦天监 / 御史台 / 鉴察台 的历史脉络）又有现代监察的严肃感
  - "**台**"字直接勾连历史上的国家级一级机构（如御史台 / 钦天台），避免与现代真实机构（公安部 / 国安部）冲突
  - 项玄冥的"**玄**"字 + 玄鉴台的"**玄**"字 → **暗示项玄冥与玄鉴台的渊源**（S3 末-S4 项玄冥引北辰入神龙 → S6c 项玄冥国家身份揭 → S6d 玄鉴台正式进场 → 项玄冥可能一直是玄鉴台的外线观察员；伏笔链自然成立）
