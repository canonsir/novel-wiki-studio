# DEC-20261010-006｜原著烂尾授权：结尾完全重构 + 篇幅扩展许可

- **Status**: accepted
- **Date**: 2026-10-10
- **Context**:
  用户明确声明："**原著的小说结尾是烂尾草草收尾的，所以我们这次改编重构小说完全可以丰富、扩展、合理的闭环小说故事**"。

  原稿封板版（SRC-002 / 747 章 / 200 万字）在 S5 帝都门阀 → S6 终局阶段存在显著的"烂尾收束"问题：
  - 后期人物弧线交代不足（如项玄冥、秦枭、韩啸天的最终归宿）
  - 多条伏笔线悬置（鬼组后续、神龙基地深层、五家议会制度化落地）
  - 后宫归属草率（原稿多位女主结局模糊 / 工具化）
  - 命盘杀破狼聚齐与"众星拱北辰"的象征闭环未完整落地
  - 国家与江湖之间的最终平衡未写出
  - 大结局过于匆忙，缺少真正的"**荣耀**"主题答案

  改编重构不受原稿后段叙事量约束。

- **Decision**:
  本次改编**完全授权**：
  1. **结尾可以彻底重写**：S5-S6 阶段不以原稿后段为蓝本，由 editor-agent 重新设计
  2. **篇幅可扩展**：planned_length_words 上限从 250 万字放宽到 **300-350 万字**；planned_volumes 保持 6 卷，但各卷章节区间可按叙事需要上下浮动 10-30%
  3. **伏笔必须闭环**：所有在 S1-S4 种下的伏笔，必须在 S5-S6 完整收束，不留悬置
  4. **主题必须答题**：全书核心主题"荣耀是外界授予的位置，还是自己配得起的名字"必须在终章给出明确、情感可感、读者可带走的回答
  5. **后宫必须有明确归属**：核心 6 位女主（温书宁 / 霍凝烟 / 叶浅浅 / 季婉宁 / 裴青鸾 / 穆清岚）各有独立归宿点，不工具化

- **Options Evaluated**:
  1. 保留原稿结局（否决：烂尾不服务读者 + 用户已明确授权重写）
  2. 小修小补原稿结局（否决：若伏笔线自身悬置，小修也救不了）
  3. **完全重构 S5-S6 结局 + 篇幅扩展（用户选择）**

- **扩展边界**:

  ### 可扩展（鼓励）
  - S5 帝都门阀的章节数：原 120 章 → 可扩至 **140-180 章**
  - S6 终局的章节数：原 107 章 → 可扩至 **120-160 章**
  - S6 可以细分为更多 Arc：当前 3 Arc（秦枭之局 / 韩啸天终局 / 荣耀）可扩至 **4-5 Arc**
  - 新引入人物（如神龙基地同期挑战者、鬼组内部派系、五家议会外围）可加入
  - 新引入组织（如跨境雇佣兵 / 跨家暗局 / 国家级观察机构）可加入
  - 新引入文化锚点（如紫微斗数细化 / 道家十二段锦分段 / 淮军祖训具体化）可加入

  ### 必须守护（硬约束）
  - 命盘杀破狼聚齐（破军 / 贪狼 / 七杀）必须在 S4 完成，不可拖到 S6
  - "众星拱北辰"格局必须在终章落地
  - 北辰 + 顾家支系 + 五大家族 文脉底盘不变
  - 法律与安全红线不变
  - 原稿封板版（raw/）绝对不动

  ### 禁止触碰
  - 不改"北辰"主角名 + 不改"顾崇岳"父辈名 + 不改"裴云归"母亲名
  - 不改五大家族（顾霍裴秦韩）命名与真实历史根基
  - 不改天下会 / 鬼组 / 神龙基地 / 五家议会 的组织本体
  - 不改"杀破狼聚齐"的命盘象征系统

- **结尾改写待决议方向（editor-agent 待压测，由用户 ACK）**:

  ### 方向 A：传统爽文大团圆（通俗型）
  - 顾北辰入主五家议会之首席
  - 温书宁 / 霍凝烟 / 季婉宁为明面妻妾；叶浅浅 / 裴青鸾 / 穆清岚为暗线羁绊
  - 厉家 / 秦家 / 韩家 全部清算 → 五家议会洗牌为"顾霍裴 + 新秦新韩"
  - 杀破狼聚齐 → 命盘封神
  - 结局落点：家国天下 + 群芳满堂
  - **优点**：读者爽感最大化，短剧改编最吸粉
  - **缺点**：主题"荣耀"的哲思薄

  ### 方向 B：真实文脉收束（文学型）
  - 顾北辰拒绝北辰之位 → 走回听澜轩茶馆 → "荣耀不是议会给的位置"
  - 五家议会制度化为新的现代门阀机构（透明化 / 国家监管）
  - 温书宁与顾北辰公开成婚（独家正妻）；其他女主有独立归宿
  - 杀破狼聚齐后主动"散星"→ 不以命盘自锁
  - 结局落点：以退为进 + 本色归真
  - **优点**：主题闭环最完整，与"真实文脉"底盘呼应
  - **缺点**：读者可能觉得"不够爽"

  ### 方向 C：双层结局（推荐）
  - **明面层**：顾北辰入主五家议会 + 众星拱北辰格局 + 杀破狼聚齐（给足爽感）
  - **深层**：终章最后一章闪回听澜轩阳台 → 顾北辰对温书宁说"**我爸从前跟我说'我去年买了个表'——我现在懂了。他说的不是时间，是他跟自己的和解**。"
  - 后宫明确归属：温书宁独家正妻 + 霍凝烟 / 季婉宁 独立伴侣 + 叶浅浅 / 裴青鸾 / 穆清岚 终身羁绊
  - **优点**：既爽又有主题闭环；是本作四联坐标（逆袭+升级+爽文+后宫）与"真实文脉+命理主轴"的最佳平衡
  - **缺点**：对作者笔力要求高
