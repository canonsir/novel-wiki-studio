# DEC-20261010-005｜创作定调：主角逆袭 + 打怪升级 + 爽文 + 后宫（画面感 + 点到即可）

- **Status**: accepted
- **Date**: 2026-10-10
- **Context**:
  原稿《我的荣耀》为男频都市爽文，吸引力 engine 包含大量敏感元素：露骨色情（259 处）、性暴力威胁（47 处）、脏话（478 处）、赌博老千（341 处）、毒品（114 处）、真实地名（736 处）、枪支（1046 处）等。按 `敏感红线预防清单·开写前.md` 的三层红线做收敛后，原稿吸引力元素会被大幅削减——如一刀切删除，将丢失大量读者粘性与爽感节奏。

  用户决议：**红线必须守住**，但不能让收敛变成"剧情阉割"。应改用**合理优美语言 + 画面感 + 点到即可**的收敛哲学替代"删除式收敛"，并同步**将创作重心向更安全、更吸粉的四联爽文坐标系倾斜**：

  - **主角逆袭**（身份错位 / 公开打脸 / 身世揭底）
  - **打怪升级**（境界突破 / 积分登顶 / 装备 / 技法）
  - **爽文**（章末钩子 / 高频反转 / 资源指数升级）
  - **后宫**（情感多线 / 女性群像 / 张力管理）

  四项中前三项与国家红线及平台红线无硬冲突，是本作必须加码的新主承载面。
  第四项"后宫"是本作传统资产，需用**画面感 + 点到即可**的笔法做合规承载——不写具体性过程，但保留亲密关系的张力、独占感、关系升级的回报。

- **Options Evaluated**:
  1. 严格按红线一刀切删除所有敏感剧情（否决：丢失爽感 / 读者流失 / 原稿改编价值归零）
  2. 挑战红线边界冒合规风险（否决：平台封书 / 账号受限 / 短剧投放受阻）
  3. **收敛表达形式 + 加码爽文四联（用户选择）**：敏感内容保留剧情资产但改"画面感"笔法；同时把创作重心推向"逆袭 + 打怪 + 爽文 + 后宫"四联，用安全的高吸引力元素补足流失的敏感吸粉力

- **Decision**:
  本书正式定调为 **「都市逆袭 + 打怪升级 + 后宫爽文」**，以"画面感 + 点到即可"作为所有敏感内容的统一收敛哲学。

- **三层核心规则**:

  ### 规则 1：红线不动（已固化在 L1 清单）
  - 未成年性化 / 恋童：全部否决
  - 淫秽色情（具体性器官 / 床戏过程 / 施暴描写）：全部否决
  - 可复制犯罪教程：全部否决
  - 诽谤真实在世人物：全部否决
  - 民族宗教煽动：全部否决
  - 真实历史组织名（如青帮）：虚构化
  - 真实品牌 / 地名：虚构化

  ### 规则 2：敏感内容 → 画面感代偿（新增，详见敏感红线清单 §2.9）
  - **性 / 亲密**：关门镜头 + 道具 + 对白 + 事后反应；镜头切黑 / 转场次日；"喉结动了一下 + 她别过脸 + 第二天六点闹钟响"
  - **性威胁**：心理压迫 + 位置关系 + 禁区线；"他的手停在半空，她闭上眼"而非"扯掉浴巾"
  - **暴力反杀**：动作 + 道具落地声 + 对方状态；"玻璃落地 + 对方跪倒"而非"脑浆四溅"
  - **粗口**：高频处用"妈的"替"操你妈"；主角口头禅"我去年买了个表"保留作声线资产
  - **毒品 / 赌博 / 枪**：保留结果 + 后果 + 代价；不写配方 / 规则 / 操作

  "画面感"的目标：**读者脑中有画面，纸上没有违禁词**。

  ### 规则 3：爽文四联加码（新增，详见爽点节奏保障方案）

  **逆袭轴**：每 5 章至少 1 次公开打脸（身份错位 / 阶层碾压 / 后台揭示）
  **升级轴**：境界 / 积分 / 门第 / 后台 / 装备 / 技法六维成长感可见
  **爽文轴**：每章 ≥ 3 个爽点锚点（见节奏方案）；章末钩子强制
  **后宫轴**：核心女主 4-6 位（温书宁 / 霍凝烟 / 叶浅浅 / 季婉宁 / 裴青鸾 / 穆清岚），每人独立情感线 + 独立危机 + 独立回报节点，禁止"工具人女二"

- **收敛哲学·口号三条**（写作时内化）:
  1. **"镜头外发生，镜头里被看见"**——事件发生在镜头外，但角色的反应、道具的状态、下场的时间，共同让读者"看见"事件发生过。
  2. **"少一点动词，多一点名词"**——不写"他进入她"，写"灯灭 / 窗外路灯一盏一盏熄灭 / 第二天六点闹钟响"。
  3. **"把爽感还给打脸，不还给房中"**——爽点集中在"地位反转 / 公开羞辱对方 / 后台空降"等外部冲突，而非内部肉体细节。

- **Consequences**:
  - 新建 `wiki/world/爽点节奏保障方案.md`（强制开写时查）
  - 更新 `wiki/world/敏感红线预防清单·开写前.md` §2.9 增加"画面感代偿示范集"（统一笔法样本）
  - 更新 `novel.yaml` reader_promise / narrative.tone（增加 逆袭 / 升级 / 画面感 / 后宫张力）
  - 更新 `wiki/overview.md` "读者承诺"段
  - author-agent 开写时必须 reference 爽点节奏方案 + 敏感红线清单两份
  - reviewer-agent 发布前复查"画面感收敛是否到位 / 爽点节奏是否达标"

- **不改**:
  - 原稿封板版（raw/，只读）
  - 核心人物弧与结局（北辰 + 杀破狼 + 五家议会）
  - 五大家族 / 真实文脉底盘（淮军 / 湘军 / 漕运 / 内务府 / 北洋）
  - 组织骨架（天下会 / 鬼组 / 海迪 / 狼舞 / 白袍会 / 忠信帮 / 飞鸿帮 / 青龙帮 / 青花会 / 五家议会 / 天一集团 / 神龙基地）

- **Risk & Mitigation**:
  - 风险：后宫线被收敛过度，变成"柏拉图式友情"
    - 缓解：每位核心女主有**独占时刻**（独家对白 / 独家道具 / 独家回报）；关系确认用"公开场合的称谓升级"外化（从"顾同学"→"北辰"→"北哥"）
  - 风险：爽文过度而丢失文脉重量
    - 缓解：每卷至少 1 个"文化锚点"（紫微斗数 / 道家十二段锦 / 洛神赋 / 淮军祖训）作为资源来源的真实感支撑
  - 风险：打脸桥段同质化
    - 缓解：节奏方案中要求打脸类型轮换（身份错位 / 后台空降 / 技术碾压 / 文化内行 / 道义制高点 / 伤势反转 六类）
