- **Decision**:

  ### 1. 番茄长篇正名：《众星拱北辰》（5 字）

  - **出典**：《论语·为政》"为政以德，譬如北辰，居其所而众星共之"
  - **一词三钩**：
    - 「众星」= 五家议会 + 杀破狼三星 + 六位女主 + 兄弟团，全书所有势力与角色皆为"众星"
    - 「拱」= 从"仰拱"到"拱辰"的权力落位（归位 / 执棋 / 决局）
    - 「北辰」= 主角之名 + 命盘主位 + 终局之位（三位一体）
  - **叙事完整度**：
    - 前期（S1-S2）：主角名字"顾北辰"看似普通，读者不知道书名含义
    - 中期（S3-S4）：杀破狼三星（破军 / 贪狼 / 七杀）聚齐，"众星"开始显形
    - 后期（S5-S6）：五家议会 + 鬼组改制 + 玄鉴台监察，"众星"开始归位
    - 终局（S6e）：听澜轩阳台最后一个镜头，顾北辰坐北辰之位，书名彻底落地
  - **首尾呼应**：
    - c001 开场顾北辰介绍自己名字出自《论语》"为政以德，譬如北辰" ✅ 已埋
    - S6e 终章顾北辰在听澜轩阳台念出整句"为政以德，譬如北辰，居其所而众星共之" ← 终章闭环
  - **搜索唯一度**：极高，无撞名爆款（番茄前 500 榜单无同名）
  - **适配渠道**：番茄小说长篇连载 / 追更型读者 / 关心全书弧
