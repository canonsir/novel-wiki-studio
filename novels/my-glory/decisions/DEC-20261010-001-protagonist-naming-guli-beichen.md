# DEC-20261010-001｜主角定名顾北辰 + 五大家族真实文脉

- **Status**: proposed（待用户 review 确认）
- **Context**: 原稿《我的荣耀》主角名"陈照南"，道上称"南哥"；本次改编需与"杀破狼"命理体系、门阀世家世界观自洽。上一版曾改名"顾沉舟"，用户后续在飞书设定文档中明确指定"顾北辰"。
- **Options**:
  1. 保留原名"陈照南 / 南哥"：节省改名工作量，但失去命理文化含量。
  2. 顾沉舟（上一版）：有文脉但未与"北辰 / 紫微 / 杀破狼"主轴联动。
  3. **顾北辰 / 北哥（本次采纳）**：出自《论语·为政》"北辰居其所而众星共之"；紫微斗数中紫微帝星对应北极星；命盘杀破狼聚齐，构成"杀破狼为将、北辰为帝"的命格伏笔。"北哥"与原稿"南哥"南北对转，有记忆点。
- **Decision**: 采纳方案 3——顾北辰 / 北哥，并同步定下五大家族"淮军/湘军/漕运/内务府皇商/北洋军统"真实历史根基。
- **Rationale**:
  - 文化含金量：北辰出处明确（朱熹《四书章句集注》"北辰，天之枢也"）；紫微帝星是中国民间命理最高辨识度之一。
  - 叙事主轴：从"杀破狼"升级为"众星拱北辰"，五大家族围绕主角站位的终局格局自然成立。
  - 市场验证：都市+命理内核与门阀世家文脉在番茄 / 潇湘持续产出高热作品。
  - 保留原稿资产：主角血性、兄弟义气、江湖人情、后宫张力不动，仅在名字与家世上做实。
- **Consequences**:
  - 全书所有涉及"陈照南 / 南哥"的称呼改为"顾北辰 / 北哥"（亲近者"北辰"，江湖后期尊称"北辰先生 / 顾爷"）。
  - "陈家"升级为五大家族"顾家"，补上淮军系（李鸿章部曲"铭"字营）→ 洋务轮船招商局 → 现代中东能源 / 港口 / 煤炭矿产 的现代转译链。
  - 五家命名统一为 顾 / 霍 / 裴 / 秦 / 韩（取代原稿陈/杨/苏/张/林）。
  - 父母两线：父亲顾崇岳（原陈正坤）被京畿顾家驱逐，母亲改为裴家女裴云归（修复原稿"赵姓"矛盾）。
  - 影响文件：novel.yaml、wiki/characters/*、wiki/factions/*、wiki/world/*、drafts/manuscript、后续全部重构章节。
