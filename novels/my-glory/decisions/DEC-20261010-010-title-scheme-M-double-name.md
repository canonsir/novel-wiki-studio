  - 方案 M（双名双发）：番茄《顾少归来》+ 红果《少主的温教授》⭐ 终极强推
  - 方案 N：《顾家真少爷》
  - 方案 O：《六美环伺》

- **Decision**:

  ### 1. 番茄长篇正名：《顾少归来》（4 字）

  - **类型**：都市 + 热血 + 后宫 + 身份反差
  - **爆款模板**：战神归来 / 龙王归来 / 医圣归来 → "顾少归来"自带番茄顶流"归来系"气质
  - **一词三钩**：顾（姓氏，豪门感）+ 少（少主，年轻 + 身份反差）+ 归来（扁担赶家 → 本家回归，整本书故事线）
  - **搜索唯一度**：极高，本作专属，无撞名爆款
  - **适配渠道**：番茄小说长篇连载（追更型读者 / 关心全书弧）

  ### 2. 红果短剧专用名：《少主的温教授》（6 字）

  - **类型**：短剧 / 逆袭 / 师生恋 / 身份反差
  - **同级情感钩**：对标《情陷美女老师》的"动词 + 女性身份对象"结构，但不复用"情陷"和"美女老师"原词
  - **画面感**：少主（身份反差）+ 温教授（女性身份对象 + 高级感）
  - **适配渠道**：红果短剧 10 集爆款（第 1 集直接拍 c001 灵魂 App 接光 → 识破仙人跳 → 发现是老师）

  ### 3. 双名双发策略

  - 两版同时上线，一个主"**豪门归来**"钩（番茄），一个主"**少主恋教授**"钩（红果），吃两类用户，不打架
  - 共享同一事件与因果，正文、人物、剧情、Wiki 全部统一，仅书名与宣发文案区分

  ### 4. 衍生设定调整

  - **温书宁职业升格**：从"中文系新任讲师"升为"中文系副教授"，以适配《少主的温教授》书名中的"教授"身份，增强女性身份高级感与画面感
  - **内核词保留**："我的荣耀"保留为 S6e 最终章节名；"北辰诀"保留为 S4 命盘聚齐那场戏的小标题；"众星拱北辰"保留为 S6e 终章前那一卷卷名
  - **前几轮长名候选**转为宣发文案 / 简介黄金句：
    - "装了二十年废物，直到五家议会把我接回去" → 番茄简介黄金句
    - "温老师的匿名瞬间，被我接光了" → c001-c010 小节主标题 / 短剧试播片名备用
