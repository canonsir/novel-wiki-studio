# DEC-20261010-002｜组织名保留原名 + 补真实历史渊源

- **Status**: proposed（待用户 review 确认）
- **Context**: 上一版曾对天下会 / 鬼组 / 海迪 / 狼舞 / 白袍会 / 忠信帮 / 飞鸿帮 / 天一集团 / 神龙基地 / 青帮 等组织名做过整体改写；用户后续在飞书设定文档中明确表态："组织不改了，原来的好听；术语不改了"。
- **Options**:
  1. 继续沿用上一版的改名方案（长风会 / 无常阁 / 蓝湾会所 / ...）：失去原稿辨识度，也丢掉用户熟悉的叫法。
  2. **全部恢复原名，补真实历史渊源（本次采纳）**：保留原稿名字，背景线写实，兼顾辨识度与可信度。
- **Decision**: 组织名全部恢复为原稿原名，并为每个组织补一条可查证的真实历史渊源。
- **Rationale**:
  - 用户明确偏好：原名辨识度高。
  - 真实渊源背书：补洪门/袍哥/锦衣卫/粘杆处/黄埔军校等真实历史文脉，提升代入感而非替代原名。
  - 原稿资产保留：故事中已经出现过的组织关系、恩怨链不动。
- **Consequences**: 全书所有组织名回退为原名；每个组织页需新增"真实渊源"小节。涉及人物名"顾飞鸿"与主角"顾"姓冲突，老大改名贺飞鸿；其他人物名按 DEC-20261010-001 调整。
