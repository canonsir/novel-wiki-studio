  ### 一、篇幅
  - **全书预估**：**880-900 章 / 300-320 万字**（相比原稿 747 章 / 200 万字扩展 20%）
  - **novel.yaml 的 planned_length_words 保持 3000000**（上限 3200000，由作者在 S6 收束时裁决）

  ### 二、后宫归属（锁定）
  - **独家正妻**：**温书宁**（公开婚礼 / 听澜轩旁小院为家 / 文学 + 教育网络支撑）
  - **独立伴侣**（非正式明面）：
    - **霍惊鸿**（国家特勤身份常年在外 / 保持"叉"的默契伴侣关系 / 不公开）
    - **季繁星**（回娱乐圈继续洛神赋 / 议会场合"独家护航"级）
  - **终身羁绊**（情感 + 事业的终生盟友，非恋人）：
    - **叶浅浅**（校园教师 / 校园回忆守望者）
    - **裴青鸾**（改制后鬼组组长 / 血缘表姐 → 转镇场型姐姐）

  **铁律**：每位核心女主在 S6 终章前必须有独家戏份；工具人化 = 退稿。

  ### 四、终章主题答题（固化为写作铁律）

  S6e 最后一章的闪回场景必须包含以下三要素：

  1. **场景**：听澜轩茶馆的阳台（S1 听澜轩首次出场的同一位置）
  2. **人物**：顾北辰 + 温书宁 + 顾崇岳（父辈在场而非在远）
  3. **对白**：顾北辰的答题
     > "我爸从前跟我说'我去年买了个表'——我现在懂了。
     > 他说的不是时间，是他跟自己的和解。
     > 荣耀，是我跟自己的和解，不是别人给我的位置。
     > 但位置我也要——不是为了我爸，是为了下一个被扁担赶出家门的孩子，知道自己可以回来。"
  4. **道具**：顾北辰手里一枚戒指（**九头兽戒指残件 + 新铸北辰令合铸**）
  5. **收尾意象**：月色下的听澜轩 / 父亲念"我去年买了个表" / 温书宁递茶
