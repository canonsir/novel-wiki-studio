# Drafts

## 目录职责

- `manuscript/latest.md`：当前唯一完整阅读稿。旧完整稿不在目录中保留副本。
- `chapters/s1-*` 至 `chapters/s6-*`：按六部组织的最新分章重构稿与状态页。

分章稿可能比完整阅读稿更先进；只有用户确认采用并完成连续性检查后，才能合并到
`manuscript/latest.md`。章节状态、来源章号和最后更新时间必须写在 frontmatter 中。
