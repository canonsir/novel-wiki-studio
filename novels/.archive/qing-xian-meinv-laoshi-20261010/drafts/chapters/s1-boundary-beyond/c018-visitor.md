# 来客

第三天值班，霍寒的人来了。

晚上九点，我记完第六个进出记录——一个穿紫色西装的中年男人，陈校董那边的，来了二十分钟就走了——楼梯下面传来脚步声。

不是一个人，是三个。

我走到楼梯口往下看。三个穿黑色西装的男人走进院子。中间那个最高，三十五六岁，头发梳得整齐，戴着一副平光眼镜。他的左手腕上戴着一块浪琴表——人物档案里霍寒的标志性物件。

霍寒。

他比照片里更瘦一点，但肩膀很宽。他走路的时候，左边那个穿深蓝西装的（应该是保镖）会稍微滞后半步，右边那个（秘书？）会稍微领先半步。三个人之间保持着精确的距离。

他推开门，走进大厅。

我掏出手机给雷哥发了一条消息："霍寒来了。三个人，已经进大厅。"

十秒后，雷哥回了："盯着。海哥在等。"

我继续站在楼梯口。

五分钟后，我看见雷哥从二楼的办公室出来，走下楼梯。他没有穿背心，穿了一件灰色的西装外套，看起来稍微正式了一点。他走到大厅门口，迎上去。

"李总，海哥在等你。"

霍寒点点头。他说话的时候声音不大，但每个字都很清楚。"麻烦你带路。"

雷哥领着他走上楼梯。我让开了路。

霍寒经过我身边的时候，停了一下。

"你就是陈浩南？"

我愣了。他怎么知道我名字？

"是。"我点头。

他摘下平光眼镜，看了我一眼。他的眼睛很亮，不是那种凶狠的亮，是商人计算货物价值的那种亮。

"你长得很像一个老朋友。"他说。

我心里一紧。这句话，海哥说过。

"谁？"

"一个不重要的人。"他戴上眼镜，跟着雷哥往海哥的办公室走。

我站在原地，手机攥在手里。

走廊另一头，肥猫的办公室门开了一条缝。肥猫的眼睛从门缝里露出来，盯着霍寒的背影。

我记下了时间：九点零七分，霍寒进海哥办公室。

然后我走到走廊的另一端，靠在墙上，等着。

走廊里的灯很安静。只有海哥办公室的门底下透出一点光。

十分钟。二十分钟。三十分钟。

肥猫的办公室门关上了。雷哥从海哥的办公室出来，走到走廊另一头的窗户边，点了一根烟。烟的火光在黑暗中一闪一闪。

四十分钟。

海哥的办公室门开了。

霍寒走出来。他的脸上没有什么表情——既没有生气，也没有满意。他走下楼，三个保镖跟着。铁门开了，三辆车停在院子外面，黑色的。

雷哥送走他，回到走廊。他看见我，点了一根烟——这次没有在窗户边，就在我旁边。

"谈得怎么样？"我问。

雷哥吸了一口烟。"霍寒让海哥把你交出去。"

"海哥怎么说？"

"海哥说——'他是我这边的人'。"雷哥看着我，"然后霍寒说——'好，那我们就不是朋友了'。"

我沉默了。

"但他没有当场翻脸。"雷哥又说，"他说了，'给你三天时间考虑'。三天之后，如果海哥不把你交出去，他会自己来。"

"那海哥打算怎么办？"

雷哥摇了摇头。"海哥没说。但他刚才跟我说——'不管怎么着，别让这小子出事'。"

我看着雷哥手里的烟。烟味很浓，是那种便宜的烟。

"雷哥，"我说，"肥哥那边……"

"肥猫？"雷哥冷笑了一声，"他今天没出办公室。他怕。"

"怕什么？"

"怕霍寒知道他跟海哥的人走得近。"雷哥把烟头扔在地上，用脚碾灭，"霍寒是霍家老大。肥猫那个小角色，在他眼里跟蚂蚁差不多。"

我记下了时间：九点四十七分，霍寒离开。

"我今天的记录就这么多。"我把本子递给雷哥。

雷哥接过去，翻了翻。然后他看着我。

"陈浩南，"他说，"你知道你现在是什么处境吗？"

我知道。

"你是海哥跟霍寒谈判的筹码。"雷哥的声音很低，"三天之后，要么海哥交你，要么海哥跟霍家宣战。不管哪种，你都是第一个被推到前面的人。"

"那我该怎么办？"

雷哥看着我。他的眼睛里有一种我看不懂的东西——可能是同情，也可能是某种更复杂的情绪。

"你去见沈雪瑶。"他说，"她在三楼的包间里。今天下午海哥让她过来的。她说有件事要告诉你。"

我愣住了。"沈雪瑶在这儿？"

"在。"雷哥指了指走廊最里面的一扇门，"308。别让任何人看见你去。"

我点头，转身往走廊最里面走。

308号包间的门是关着的。我敲了三下。

"进来。"沈雪瑶的声音从里面传来。

我推开门。

包间里没有别人。只有她。她坐在沙发上，手里拿着一杯没有动过的茶。她今天穿了一件黑色的裙子，头发扎得很高，露出脖子上的皮肤。她的指节上的茧——我见过的——现在攥着茶杯。

"你怎么在这儿？"我问。

"海哥让我来的。"她站起来，"他说霍寒今天要来，让我躲在这里。"

"他刚走了。"

"我知道。我在里面听见了。"她看着我，"陈浩南，我需要告诉你一件事。"

"什么？"

"孟老板找过我爸了。"她的声音很平，但我能听出底下的颤抖，"他说如果我爸不还钱，他下个月就要收我们家的小馆子。"

"多少钱？"

"八百万。但他说——如果我愿意帮他做一件事，钱可以再拖。"

"什么事？"

她看着我。她的眼睛很红，但没有哭。

"他要我把海哥的事告诉霍寒。"

我浑身一震。

"什么？"

"孟老板跟霍寒有生意来往。"她的声音继续说，"他们想知道海迪的内部结构——雷哥和肥猫谁跟海哥走得近，海哥的资金从哪来，哪些人可以挖过去。"

"他让你当卧底？"

"他让我当线人。"她纠正我，"不是卧底。线人——就是把我知道的事告诉他。不用去海迪办公室偷文件，只要在饭局上、电话里、见面的时候说几句有用的话。"

"你答应了？"

她看着我。

"我还没有。"她说，"但我爸快撑不住了。我们家的小馆子是我妈留下来的。我不想让它被收走。"

我站在那里。包间里的空调吹得很冷。我看着她，看着她攥着茶杯的手，看着她脖子上露出来的皮肤，看着她扎得很高的马尾。

我应该生气的。我应该说"你怎么能考虑做这种事"。但我没有。

"你想怎么办？"我问。

她愣了一下。"你不怪我？"

"我怪你有什么用？"我走到她对面，坐下来，"你爸欠了八百万，孟老板说你当线人就宽限。霍寒现在要海哥交我。我们两个都在被人推着走。"

她的眼泪终于掉了下来。

"陈浩南，"她说，声音在抖，"我不想做线人。我不想背叛海哥。我不想让你出事。但我真的没有别的办法——"

"好。"我打断她，"那我们一起想办法。"

"一起？"

"一起。"我看着她，"你不用当线人。我们找海哥商量。孟老板跟海哥是上家关系，海哥应该能说话。"

她看着我，眼泪还在掉。

"你真的觉得能行？"

"不知道。"我老实地说，"但我们可以试试。总比你当线人好。"

她点头。她用手背擦了擦眼泪。

"好。"她说，"那明天？"

"明天。你跟我一起去见海哥。"

她又点头。

我站起来。"我该走了。雷哥在外面等我。"

"陈浩南。"她叫住我。

"嗯？"

"谢谢你。"她说，声音还是有点哑，"谢谢你相信我。"

我没有说"不客气"。我只是点点头，推开门，走了出去。

### 重写说明

**替换的真实地名**：建设巷→柳巷；青龙会/东华帮/东辉集团等保留

**核心变更**：
1. ✅ **第一部结尾大高潮**——霍寒正式登场海迪，与海哥正面谈判，给出三天期限。这是从"校园冲突"到"家族对峙"的关键升级点
2. ✅ **雷哥的蝴蝶刀**——人物档案里的锚点物件（蝴蝶刀传承），在关键场景中出现
3. ✅ **沈雪瑶的抉择**——她面临的不是"要不要当线人"，而是"要不要背叛海哥来救我爸"。主角选择不生气，选择一起想办法——保持了人物的有边界感
4. ✅ **后台线索**——霍寒说主角"长得很像一个老朋友"（和海哥说的同一个人？），身世线的双重暗示
5. ✅ **肥猫的立场**——他怕霍寒，不敢在今天露面。为后续内部背叛铺垫

**三条增长曲线**（第一部收尾）：
| 曲线 | 第一部末状态 |
|---|---|
| **势力** | 普通大学生 → 海迪值班 → 海哥的人 |
| **后台** | 霍寒跨城出现 → 三天期限 → 旧朋友伏笔 |
| **艳遇** | 嗖 匹配 → 投名状 → 真相 → 共同承担沈雪瑶债务 |

**伏笔埋入**：
1. 海哥和霍寒都提到主角"长得像一个老朋友"——这个人到底是谁？（身世线核心）
2. 沈雪瑶当线人的抉择——她最终会不会真的帮孟老板？
3. 肥猫怕霍寒——他会不会趁机投靠？
4. 三天期限——下一部的开头就要兑现

**与原稿的核心差异**：
- 原稿第一部结尾是"暴打高富帅+仙人跳"的爽点。重写版是"家族对峙+道德抉择+共同承担"的戏剧点。爽点变成了更深的、有代价的情绪高潮。
