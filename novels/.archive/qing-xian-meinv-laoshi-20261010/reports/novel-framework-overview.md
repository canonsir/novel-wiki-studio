# 小说整体框架概览

> 完整分部细节见 [[structure/structure-novel-volumes|分部结构方案]]。本页为高层 review 用，便于与拓扑图对照。

## 核心身份

- **书名**：《我的江湖》（暂定）
- **类型**：都市 + 成长 + 犯罪 + 情感
- **总规模**：6 部 / 747 章 / 205–225 万字 / 118–144 集短剧
- **核心主题**：一个获得力量的人，是选择成为支配他人的王，还是守住边界的人。
- **主角**：陈浩南（男主，大二屌丝 → 地下组织领袖 → 主动退离）
- **女主**：沈知微（青年教师，随母姓沈；父亲"夏启明"背负债务；主动调查+拒绝救援式占有）

## 三条增长曲线（贯穿全书）

| 曲线 | 内核 | 具体表现 |
|---|---|---|
| **艳遇** | 每段关系承载不同情绪、资源、风险 | 沈知微=禁忌理想/债务；罗莉=现实归属/患难；徐苗苗=组织协作；娜娜/刘园园/苏柒柒/雨姐/沈晴/段晨薇 分部递进 |
| **势力** | 每一部升一个主层级 | 校园 → 场所 → 组织 → 城区 → 跨城 → 跨境 → 家族 → 主动退离 |
| **后台** | 层级分明，每部只揭开一层 | 海哥 → 林老爷子 → 林青朝 → 苏轻侯 → 白立国 → 秦老头 |

## 六部核心冲突一句话总结

| 部 | 一句话冲突 | 主要对手 | 结尾钩子 |
|---|---|---|---|
| **S1 边界之外** | 一次匿名约见把屌丝大学生推进地下秩序的门槛 | 李振北（本地富二代）、肥猫（海迪内部） | 推开夜场铁门穿深色夹克 + "你长得像我认识的一个人" |
| **S2 立规矩** | 从执行者变成组织者，第一次主动打断对手的腿 | 肥猫（夺权尝试）、飞虹帮（外部）、狼舞风暴幕后 | 海哥让他杀一个人 + 徐苗苗条件合作 + 李振北回归 |
| **S3 会长** | 海哥之死造成的权力真空，用一次自己人的处决换来龙头位置 | 海迪旧部、疯鹰（军事夺权）、鬼组密信 | 林青朝背叛暗示 + 段晨薇出场 + "你爸还活着" |
| **S4 镜中人** | 做了一件和李振北当年对他做过的一模一样的事，承认自己与敌人相似 | 李振东（魔都房产）、段晨薇（法与情）、鬼组 | 五大家族邀请函 + 秦老头名字首次出现 |
| **S5 棋子** | 以为自己是玩家，发现是秦老头 20 年前就留下的棋子 | 五大家族（陈林苏杨张）、鬼组高层、跨境武装 | 四女失联五千万勒索 + 李振北终局 + 沈知微怀孕 |
| **S6 回家** | 拒绝顶级后台 offer，收缩天下会成合法生意主动退离 | 鬼组最高层、五大家族顽固派、秦老头考验 | 江边与沈知微牵小女孩相逢，和开篇同一座龙王桥 |

## 后台揭示节奏（反对一次性揭底）

```text
S1: 海哥眼神异常（可疑）
S2: 林老爷子神秘资金
S3: 林青朝（中层后台）身份揭示
S4: 鬼组（敌对后台）正式出场 + 父辈线索
S5: 白立国（顶层之一）+ 父亲身份揭一半（与秦老头有关）
S6: 秦老头完整现身，但只给条件不替主角做决定
```
