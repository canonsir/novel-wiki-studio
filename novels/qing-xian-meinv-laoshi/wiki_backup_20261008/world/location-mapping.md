# 地点虚构化映射

## 目的

本文档将原稿中出现的真实城市名、具体街区名和道路名替换为虚构化名称，避免直接指向现实中的可定位地点，同时保留原有的地理意象、空间关系和叙事功能。

> 虚构化名称不是"随便换个名"，而是保留原型城市/街区的核心特征（气候、地貌、生活质感），让虚构读者仍能感知到故事发生在"一个川渝背景的湿润都市"，但无法精确到真实坐标。

## 映射规则（严格执行）

| 类型 | 处理原则 | 示例 |
|---|---|---|
| 城市名（真实） | 替换为通用都市别称或古称 | 成都→蓉城，上海→魔都 |
| 国家名（真实） | 替换为古称或模糊化处理 | 泰国→暹罗 |
| 通用地理术语 | 保留 | 金三角 |
| 虚构城市别称（帝都） | 保留 | 帝都 |
| 具体桥名/地标（真实） | 换名保留意象 | 龙王桥→望龙桥 |
| 具体街区/巷名（真实） | 换名保留街区质感 | 建设巷→柳巷 |
| 具体小区名（真实） | 换名保留社区类型 | 翠园→紫薇小区 |
| 具体道路名（真实） | 换名保留功能属性 | 双华路→锦城路 |
| 虚构场所名 | 保留，不改动 | 红屋咖啡厅、海迪会所、老张家烧烤摊 |
| 虚构场所通用名 | 保留，不改动 | 大专校园、神龙基地 |

## 重写时的替换优先级

1. **正文写作时直接用虚构名**：不要先写真实名再全局替换，避免遗漏。
2. **Wiki 实体页面标题同步更新**：如 `loc-chengdu.md` 标题改为"蓉城"，但文件 ID 可以保留 `loc-chengdu` 不变（文件 ID 是系统引用键，不影响正文展示）。
3. **涉及真实地名的旧 Wiki 内容**：在重写任务（第二阶段）中逐步替换，不在本次映射文档创建时批量改动现有 Wiki。
4. **原稿引用中的真实地名**：原稿引用（如"第X章《XX》"）中的地名不替换，保留原稿原貌——映射表只用于重写的正文。
