# dec-20261009-002｜恢复原稿高潮与商业爽点

- Status: accepted
- Context: 用户认为当前 S1 改稿过度移除敏感内容，导致宾馆破门、报复升级、
  强制染毒、拘留结识海哥、海迪救场、关系升温等高潮链断裂，故事退化为单纯升级叙述。
- Options:
  1. 继续当前低敏重写；
  2. 回到原稿因果链，保留高潮与成人向张力，只对表达尺度和违规风险做收敛；
  3. 原样恢复原稿。
- Decision: 采用方案 2。以原稿事件链为重构骨架，恢复艳遇、受辱、反杀、复仇、
  兄弟义气、势力入场和后台揭示等商业发动机；不原样复制低俗、露骨和教程化内容。
- Rationale: 爽点来自“压迫累积—主动选择—地位逆转—情绪回报”，不是来自露骨描写本身。
  保留事件功能并重建人物动机、因果与后果，可以同时提高商业强度、原创度和合规性。
- Consequences:
  - 当前 S1 第1–18章不再作为可继续扩写的标杆稿，统一标记为 `rework-required`；
  - S1 恢复原稿第1–30章的主要因果顺序，不再提前引入李振东、天悦集团、果园霜害等后段线；
  - 保留宾馆暧昧与破门、李振北诱捕报复、强制染毒创伤、拘留结识海哥、
    海迪绝境救场、罗莉关系升温、皇城追债、徐苗苗/阿光情报节点和白姐登场；
  - 情色采用成年人、明确同意、非露骨或淡出处理；性暴力只作为威胁和创伤，
    不作情色化展示；
  - 毒品、绑架、刀具和黑帮行动保留结果、代价与恐惧，不提供可复制步骤；
  - 主角允许好色、冲动、占有欲和复仇欲，但叙事不替其越界背书，越界必须产生关系、
    法律或人格后果；
  - 后续扩写与重构强制调用 `.trae/skills/chinese-novelist/`，方案与正文验收前使用
    `.trae/skills/grill-me/` 做逻辑压力测试。
