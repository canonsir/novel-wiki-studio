# 主时间线

原稿缺少统一年月，以下采用“故事阶段 + 因果顺序”记录。明确时间为确认事实，推算时间需要在深度重构时再次核验。

## 阶段一：大学新学期

1. 新学期开学约一个月，陈照南仍是大二学生。
2. 陈照南通过微信漂流瓶与陌生女性约见。
3. 对方被发现是新教师夏梓妍。
4. 两人前往宾馆，李振北闯入。
5. 陈照南反击李振北，建立核心仇恨。
6. 夏梓妍家庭债务、父亲问题和李振北逼婚逐渐暴露。
7. 李振北通过暴力、毒品、警方和校园关系报复陈照南。
8. 张星、罗莉、徐苗苗被卷入冲突。

连续性要求：

- 陈照南与主要学生角色均为成年人；
- 夏梓妍仍具有教师身份，感情线必须处理权力边界；
- 毒品和伤势不能在数日内无后果消失。

## 阶段二：进入海迪

1. 陈照南寻求地方势力帮助。
2. 吕润海、白姐、雷哥和王亮等人进入主线。
3. 陈照南接受考验并参与地方冲突。
4. 他通过策反、谋划和战斗帮助海迪击败飞猫。
5. 吕润海公开称其为“南哥”。
6. 陈照南开始经营狼舞并建立自己的班底。
7. 夏梓妍、罗莉和徐苗苗关系互相影响。

时间锚点：

- 陈照南向夏梓妍表白时，双方相识约数月；
- 狼舞经营与春节返乡发生在同一早期阶段；
- 第98、100、102章来源缺失，重构版已补足返城、狼舞危机和刘园园证据链。

## 阶段三：狼舞危机与接班

1. 狼舞发生死亡事件并被查封。
2. 陈照南调查死者家庭、假酒和阿龙盛典。
3. 刘园园与陈照南正式建立哥哥妹妹关系。
4. 陈照南处理分局局长和场所危机。
5. 海迪旧成员开始怀疑吕润海扶持陈照南的目的。
6. 陈照南扩张个人班底，逐步离开学校。
7. 夏梓妍离开，校园线进一步弱化。
8. 陈照南退学。

连续性要求：

- 场所停业时间、收入损失和员工去留需要量化；
- 陈照南退学前后的学籍、住宿和家庭反应需要补场；
- 刘园园此阶段为未成年，不能进入成人关系。

## 阶段四：吕润海死亡与天下会成立

1. 海迪内外敌对势力加剧。
2. 吕润海死亡，组织出现权力真空。
3. 王亮牺牲，陈照南受到重大打击。
4. 陈照南争夺龙头位置。
5. 罗莉失踪等事件迫使陈照南进一步越界。
6. 林老爷子和鬼组线开始进入主线。
7. 赵半闲、林青朝等高阶人物出现。
8. 第220章天下会正式建立。

连续性要求：

- 吕润海死亡真相、扶持动机和白姐立场必须回收；
- 王亮死亡后，陈照南和班底的创伤需要持续；
- 新组织成立需要处理人员、资产、堂口和公开身份。

## 阶段五：城南扩张

1. 天下会举行建立仪式并面对祭旗风波。
2. 地方势力开始试探或攻击天下会。
3. 陈照南培养徐苗苗成为谋士。
4. 天下会与狂刀帮、黄旗会、百乐赌场等连续冲突。
5. 赵半闲以“破军”身份归位。
6. 天下会建立堂口和执行力量。
7. 李振北、张晟威和帝都来人重新进入冲突。
8. 陈照南控制更多城区。

连续性要求：

- 每次吞并必须记录新增地盘、人员和管理成本；
- 受伤、枪战和警方行动必须有时间间隔；
- 不能在同一短周期完成过多大规模战役。

## 阶段六：上海与身世线

1. 陈照南再赴上海并与夏梓妍重逢。
2. 张晟威和鬼组制造追杀。
3. 夏梓妍中枪并被救活。
4. 苏柒柒、修罗、雨姐等高阶人物集中出现。
5. 陈正坤、陈家和父辈身份开始揭露。
6. 林老爷子讲述忠信帮与陈守信历史。
7. 帝都五大家族成为明确世界层级。

连续性要求：

- 夏梓妍中枪后的恢复周期必须长期记录；
- 上海追杀与成都堂口战事的通信、交通时间需要统一；
- 身世揭露不能直接替代主角此前的个人努力。

## 阶段七：警匪与成都统一

1. 天下会与血狼帮、青帮持续作战。
2. 段晨薇发现陈照南真实身份，关系转为法律对抗。
3. 赵半闲重伤，雨姐进入成都救治。
4. 夏梓妍提出建立保安公司，尝试合法化组织成员。
5. 飞鸿帮、白袍会和商业集团进入最终城市竞争。
6. 南天集团成立，宋胡冰负责商业扩张。
7. 林老爷子、白立国等高层人物遭遇暗杀与布局。
8. 陈照南最终统一成都或成为实际权力中心。

连续性要求：

- 保安公司不能自动洗白历史犯罪；
- 赵半闲头部重伤需要明确后遗症；
- 成都统一后必须有资产、人员和治理场景；
- 段晨薇的警察身份不能因感情失效。

## 阶段八：跨境、家族与三颗星

1. 陈照南进入泰国、金三角等跨境舞台。
2. 哈察将军、蛇王组织、修罗和夜叉等人物参与冲突。
3. 老道士的贪狼、破军、七杀预言逐渐兑现。
4. 赵半闲对应破军。
5. 宋胡冰被怀疑对应七杀。
6. 天下会与青花会面临合并和更高层敌人。
7. 陈照南父母、陈家、苏家和杨家关系进一步揭露。

连续性要求：

- 三星设定是命理象征还是客观超自然规则必须统一；
- 跨境交通、武器和人员不能瞬间到达；
- 海外资源必须附带交易与风险。

## 阶段九：终局前告别

1. 成都局势暂时稳定。
2. 陈照南安排天下会、鬼组、商业集团与主要关系人物。
3. 刘园园、张星、曹姐、周颖等支线收束。
4. 陈照南与夏梓妍完成阶段性告别。
5. 苏越、杨一催促陈照南进入神龙部队。

连续性要求：

- 每位核心关系人物需要明确当时地点、关系状态和知情程度；
- 组织权力交接不能只靠一句命令；
- 进入神龙部队前要明确陈照南为何愿意暂时离开成都。

## 阶段十：神龙部队

1. 陈照南进入神龙部队。
2. 经历基础体能、极限跑、公开区和天字班规则。
3. 蒋雨薇、肖院长、杨志锴等人物进入主线。
4. 陈照南通过挑战赛和生存规则提高能力。
5. 道家十二段锦与一级药剂形成能力升级。
6. 秦老头出现，以钓鱼、下棋和谈话检验陈照南。
7. 陈照南面对天赋瓶颈和“认命”问题。
8. 秦老头提供终极帮助，帝都敌人与家族问题快速收束。
9. 陈照南重新定义荣耀并选择最终生活。

连续性要求：

- 训练日数、身体恢复和积分消费需要建立表格；
- 药剂副作用必须持续；
- 成都旧线不能在神龙阶段全部失联；
- 秦老头的帮助必须保留边界，避免包办高潮。
