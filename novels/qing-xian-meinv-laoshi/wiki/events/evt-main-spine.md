## 关键关系事件

### 沈雪瑶线

约见错位 → 共同受困 → 陈浩南救援 → 教师/学生边界冲突 → 分离与重逢 → 家族和疾病压力 → 终局关系确认。

### 林悦线

危机陪伴 → 成为女友 → 沈雪瑶等关系引发信任裂缝 → 分手/复合循环 → 主角势力升级造成生活分岔 → 终局是否接受多关系规则。

### 徐甜线

校园敌对 → 被卷入计划 → 利益合作 → 亲密关系 → 经营和谋略能力获得承认 → 成为组织制衡者或附庸的分岔。

### 兄弟线

周斌代表普通青春；张亮代表热血忠诚与牺牲；郑半闲代表高阶搭档与有效异议。三者共同检验主角是否只需要服从者。

## 后台揭示节拍

1. 海哥异常关注普通学生。
2. 林老爷子/林寒证明地方之上还有成熟网络。
3. 父辈异常和鬼组入口将主角连接到家族历史。
4. 苏云、卜立国等人揭示组织与家族层。
5. 神龙部队证明权力之外还有资格与使命。
6. 秦老头揭示世界顶层，但只压住不公平变量，不替主角完成选择。

## 短剧事件选择标准

- 优先保留同时推动两条以上增长曲线的事件。
- 重复绑架、住院、醉酒和救美只保留第一次、最贵的一次和导致关系改变的一次。
- 每次大胜之后必须有“资产变化镜头”和“关系后果场”，避免胜利悬空。
- 任何后台出手都要有前置痕迹和后续交换。
